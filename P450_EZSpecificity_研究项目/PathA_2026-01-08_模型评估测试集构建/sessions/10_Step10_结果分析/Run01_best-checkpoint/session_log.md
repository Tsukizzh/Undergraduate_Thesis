## 第一部分：论文背景与实验设计

在分析我们的P450测试结果之前，必须先理解EZSpecificity论文中的实验设计和基准测试含义。

### 1.1 EZSpecificity是什么

EZSpecificity是一个预测"酶-底物特异性"的深度学习模型，发表于Nature 2025（Cui et al.）。其核心功能是：**给定一个酶和一个底物，预测这个酶能否催化这个底物的反应**。

模型架构包含三个关键组件：
1. **ESM-2编码器**：将蛋白质序列转换为1280维向量表示
2. **SE(3)-等变图神经网络**：编码酶-底物对接复合物的3D结构信息
3. **交叉注意力层**：捕获酶的氨基酸与底物原子之间的相互作用

### 1.2 ESIBank训练数据集

EZSpecificity在ESIBank（Enzyme-Substrate Interaction Bank）数据集上训练：

| 项目 | 数值 | 说明 |
|------|------|------|
| **总数据量** | 323,783对 | 酶-底物配对的总数 |
| **正样本** | 34,417对 | 来自BRENDA数据库的已验证催化关系 |
| **负样本** | 287,525对 | 通过随机采样生成 |
| **唯一酶数** | 8,124个 | 来自UniProt的酶序列 |
| **唯一底物数** | 34,417个 | 来自BRENDA的底物SMILES |
| **正负比例** | 约1:8.4 | 负样本远多于正样本 |

### 1.3 论文中负样本的生成方式（关键）

**这是理解我们结果的关键点。**

论文的负样本生成方式是：对于每一个正样本（酶A催化底物B），生成负样本的方法是：
- 随机选择5个**不同的酶**（酶C、D、E、F、G），与**同一个底物B**配对
- 随机选择5个**不同的底物**（底物X、Y、Z...），与**同一个酶A**配对

这意味着：
- **负样本的本质**：错误的酶-底物匹配（这个酶和这个底物没有已知的催化关系）
- **模型学到的能力**：区分"哪个酶催化这个底物"或"哪个底物被这个酶催化"

### 1.4 论文的四种测试场景

论文Figure 3a展示了四种测试场景，难度依次递增：

| 场景 | AUROC | 含义 | 测试集特点 |
|------|-------|------|-----------|
| **Random** | 0.8927 | 随机切分 | 测试集中的酶和底物在训练时都可能见过 |
| **Unknown substrate** | 0.8297 | 未知底物 | 测试集中的底物在训练集中从未出现 |
| **Unknown enzyme** | 0.7976 | 未知酶 | 测试集中的酶在训练集中从未出现 |
| **Unknown enzyme + substrate** | 0.7198 | 未知酶+底物 | 酶和底物在训练集中都从未出现 |

**场景解读**：
- **Random（0.8927）**：最简单，因为模型在训练时已经"见过"测试集中的酶和底物，只需要判断它们是否匹配
- **Unknown enzyme + substrate（0.7198）**：最难，酶和底物都是全新的，模型必须泛化到从未见过的数据

## 第二部分：我们的P450测试集与论文的差异

### 2.1 测试集构成

我们的P450测试集：
- 来源：RCSB PDB数据库中的P450-配体复合物晶体结构
- 正样本：酶的已知底物（能被催化的分子）
- 负样本：酶的抑制剂或产物（能结合但不能被催化的分子）
- 总数：517条预测（292个酶条目，436个底物）

### 2.2 数据重叠查证（已验证）

以下结论经过实际数据比对验证（Claude Code + Codex双方查证）：

#### 酶的重叠情况

| 数据集 | 唯一酶数 | 来源 |
|--------|---------|------|
| **我们的P450测试集** | 148个UniProt ID | RCSB PDB实验结构 |
| **ESIBank训练集中的P450** | 389个UniProt ID | BRENDA数据库 |
| **交集** | **0个（0%）** | 完全不重叠 |

**0%重叠的原因**：
1. 数据来源不同：ESIBank的P450来自BRENDA（文献记载的酶-底物催化关系），我们的来自RCSB PDB（实验解析的蛋白-配体共晶结构）
2. 数据集构建时明确排除了ESIBank中的条目以避免数据泄漏

**结论：我们测试集中的所有酶对模型来说都是"未知酶"。**

#### 底物的重叠情况

| 数据集 | 唯一底物数 | 来源 |
|--------|---------|------|
| **我们的P450测试集** | 436个SMILES | PDB配体 |
| **ESIBank P450底物** | 2,886个SMILES | BRENDA P450底物 |
| **交集（精确SMILES匹配）** | **47个（10.8%）** | 下限估计 |

**说明**：
- 47/436 = 10.8% 是下限（不同SMILES规范化方式可能隐藏更多匹配）
- 这只与ESIBank中P450的2,886个底物比较，ESIBank总共有34,417个底物
- 如果与ESIBank全部底物比较，重叠比例只会更高
- 因此底物并非全部"未知"

#### 我们的测试场景定位

基于以上验证，我们的测试场景准确描述为：

**"未知酶（0%重叠） + 部分已知底物（至少10.8%重叠） + 不同的负样本定义"**

这不完全对应论文中的任何一个场景：
- 比"Unknown enzyme"（0.7976）更难：因为我们还有负样本定义差异
- 比"Unknown enzyme + substrate"（0.7198）稍容易：因为部分底物是已知的
- 但负样本定义差异（抑制剂 vs 随机配对）增加了额外难度

### 2.3 关键差异：负样本定义不同

| 维度 | ESIBank（论文） | P450测试集（我们） |
|------|----------------|-------------------|
| **负样本是什么** | 随机配对的酶-底物（通常没有催化关系） | 抑制剂/产物（能结合但不能被催化） |
| **负样本的酶-底物关系** | 酶和底物之间通常"无关" | 酶和配体之间有明确的结合关系 |
| **区分难度** | 相对容易（酶和底物可能完全不匹配） | 相对困难（抑制剂可能与底物化学结构相似） |

### 2.3 这导致了什么

**模型被训练来回答的问题**：
- "这个酶和这个底物是正确的匹配吗？"（vs 随机配对的错误匹配）

**我们让模型回答的问题**：
- "这个配体能被这个酶催化吗？"（vs 只能结合但不能被催化的抑制剂）

这是两个不同的分类任务。模型在训练时没有学过如何区分"能催化的底物"和"只能结合的抑制剂"。

## 第三部分：我们的测试结果

### 3.1 核心指标汇总

| 指标 | 我们的结果 | 含义 |
|------|-----------|------|
| **AUC-ROC** | 0.6636 | 模型的排序能力（详见3.2） |
| **AUC-PR** | 0.6360 | 精确率-召回率曲线下面积 |
| **Accuracy** | 0.5164 | 在默认阈值0.5下的分类准确率 |
| **Precision** | 0.6341 | 预测为正的样本中，真正是正样本的比例 |
| **Recall** | 0.0996 | 真正的正样本中，被正确预测为正的比例 |
| **Specificity** | 0.9414 | 真正的负样本中，被正确预测为负的比例 |
| **F1 Score** | 0.1722 | Precision和Recall的调和平均值 |
| **MCC** | 0.0759 | Matthews相关系数 |

### 3.2 AUC-ROC = 0.6636 的含义

**AUC-ROC（Area Under the Receiver Operating Characteristic Curve）**衡量的是模型的排序能力。

**计算方式**：随机抽取一个正样本和一个负样本，计算模型给正样本打分高于负样本的概率。

**数值解读**：
- AUC-ROC = 1.0：完美区分，所有正样本的分数都高于所有负样本
- AUC-ROC = 0.5：等同于随机猜测
- **AUC-ROC = 0.6636**：模型有66.36%的概率给正样本打分高于负样本

**结论**：模型具有一定的区分能力，但不够强。在66.36%的情况下能正确排序，但仍有33.64%的情况会"判断错误"。

### 3.3 与论文基准的对比

| 场景 | AUROC | 与我们的差异 |
|------|-------|-------------|
| **我们的P450测试** | 0.6636 | 基准 |
| 论文 - Random | 0.8927 | +22.9% |
| 论文 - Unknown substrate | 0.8297 | +16.6% |
| 论文 - Unknown enzyme | 0.7976 | +13.4% |
| **论文 - Unknown enzyme + substrate** | **0.7198** | **+5.6%** |

**分析**（基于第二部分的数据重叠查证）：
- 酶重叠：0% → 所有酶对模型都是"未知"的
- 底物重叠：至少10.8%（仅与P450底物比较；与全ESIBank比较只会更高）
- 因此我们的场景介于"Unknown enzyme"（0.7976）和"Unknown enzyme + substrate"（0.7198）之间
- 我们的AUC-ROC（0.6636）比最接近的论文场景（0.7198）低约5.6%
- 这5.6%的差距主要来自于**负样本定义的差异**：我们使用抑制剂/产物作为负样本（难以区分），而论文使用随机配对（容易区分）

### 3.4 为什么Recall极低（0.0996）

**Recall = 0.0996 意味着**：在261个真正的正样本中，模型只正确识别了约26个。

**原因分析**：

模型输出一个分数（logit），需要选择一个阈值来做二分类决策。默认阈值是0.5。

我们的数据统计：
- Logit均值：-4.01
- 概率均值：0.142（14.2%）

这意味着模型对所有样本（无论正负）都倾向于给出很低的分数。当使用默认阈值0.5时：
- 几乎所有样本的预测概率都低于50%
- 因此几乎所有样本都被预测为"负"
- 导致大量正样本被错误分类（False Negative）

### 3.5 阈值问题

| 项目 | 值 |
|------|-----|
| 默认阈值 | 0.5（概率50%） |
| 最优阈值（Youden's J） | 0.0379（概率3.79%） |
| Youden's J统计量 | 0.2657 |

**最优阈值0.0379的含义**：如果将判断标准从"概率>50%才算正"降低到"概率>3.79%就算正"，可以获得更好的Recall。

**为什么阈值差异这么大**：
1. 模型在P450数据上的概率输出存在系统性偏低
2. 这种偏低可能源于训练数据与测试数据的分布差异（domain shift）
3. 模型对"从未见过"的酶-底物组合倾向于保守地给低分

### 3.6 混淆矩阵（阈值=0.5）

| 预测\真实 | 正样本 | 负样本 | 总计 |
|----------|--------|--------|------|
| 预测为正 | 26 (TP) | 15 (FP) | 41 |
| 预测为负 | 235 (FN) | 241 (TN) | 476 |
| 总计 | 261 | 256 | 517 |

- **True Positive (TP)**: 26个，正确预测的正样本
- **True Negative (TN)**: 241个，正确预测的负样本
- **False Positive (FP)**: 15个，把负样本错误预测为正
- **False Negative (FN)**: 235个，把正样本错误预测为负（主要问题）

- X轴：Recall（检出率）

- 虚线：随机基准（正样本占比）

## 第五部分：根因分析总结

### 5.1 主要原因：任务不匹配

| ESIBank训练任务 | P450测试任务 |
|----------------|-------------|
| 区分正确的酶-底物匹配 vs 随机配对 | 区分能催化的底物 vs 只能结合的抑制剂 |
| 负样本：酶和底物通常"不相关" | 负样本：抑制剂能结合到活性位点 |
| 难度：相对容易 | 难度：相对困难 |

### 5.2 次要原因

| 原因 | 说明 | 影响 |
|------|------|------|
| **酶完全未知** | 148个测试酶中0个在ESIBank训练集中出现（已验证） | 模型必须泛化到未见过的酶 |
| **域偏移** | PDB配体集合（以抑制剂为主）与BRENDA底物集合的化学空间不同 | 模型对未见过的结构预测不准 |
| **概率校准失效** | 最优阈值0.04远低于默认0.5 | 不能直接用输出概率做决策 |
| **标签歧义** | 部分抑制剂在特定条件下可能是底物 | 降低理论最高AUC |
| **样本量有限** | 仅517条，部分酶只有1-2个样本 | per-enzyme分析方差大 |

### 5.3 这个结果是否"正常"

**是的，在预期范围内。**

经过查证（Claude Code + Codex 协作验证），确认：
1. 我们测试集中的酶100%是"未知酶"（0%与ESIBank训练集重叠）
2. 底物至少10.8%是"已知底物"（与ESIBank P450底物重叠）
3. 负样本定义与训练时完全不同（抑制剂 vs 随机配对）
4. 论文中"Unknown enzyme + substrate"场景的AUC-ROC为0.7198

我们获得0.6636的AUC-ROC（比论文低约5.6%）是合理的结果，不代表模型"失败"。

## 第六部分：实际使用建议

### 6.1 阈值调整

**不要使用默认阈值0.5**。根据分析，将阈值降至约0.04可以获得更好的Recall。

### 6.2 用于排序而非绝对判断

模型适合用于**排序候选**：
- 对多个底物按预测分数排序
- 优先实验验证高分的底物
- 不建议直接用预测概率做最终决策

### 6.3 后续改进方向

| 优先级 | 建议 | 说明 |
|--------|------|------|
| 高 | 创建与ESIBank格式一致的测试集 | 使用"随机配对错误酶"的方式生成负样本，公平对比 |
| 高 | 阈值校准 | 在P450验证集上重新选择最优阈值 |
| 中 | Fine-tune | 用P450数据对模型进行微调 |
| 中 | 标签复核 | 确认负样本（抑制剂）确实不是底物 |

## 附录：常见问题

### Q1: AUC-ROC 0.66是不是很差？

0.66意味着模型有66%的概率能正确区分一对正负样本。这比随机猜测（50%）好，但不算强。考虑到任务差异，这个结果在预期范围内。

### Q2: 为什么我们不能达到论文的0.89？

论文的0.89是在"Random"场景下测得的，该场景下：
- 测试集中的酶和底物在训练时都可能见过
- 负样本是随机配对，相对容易区分

我们的场景是：
- 酶和配体都是P450特有的，大多不在训练集中
- 负样本是抑制剂，与底物可能化学结构相似
- 更接近论文的"Unknown enzyme + substrate"场景（0.72）

### Q3: 如何判断某个预测是否可信？

1. 不看绝对概率，看相对排序
2. 高分预测优先实验验证
3. 考虑该酶在训练集中的相似酶数量（有相似酶则预测更可靠）
