## 一、任务背景

### 1.1 为什么需要抽检？

在Step 3.01配体分类审核中，每条记录根据分类依据的可靠性被标记为不同置信度：

| 置信度 | 含义 | 数量 |
|--------|------|------|
| HIGH | 分类依据充分，可直接使用 | ~400条 |
| MEDIUM | 分类依据一般，可能存在边界模糊 | 131条 |
| LOW | 分类依据不足，需要人工审核 | ~50条 |

**MEDIUM置信度记录**虽然没有触发高风险标记（`needs_human_review=False`），但仍有可能存在分类错误。为确保数据集质量，需要进行**抽检**。

### 1.2 抽检策略

由于MEDIUM记录数量较大（131条），采用**分层抽样**策略：

```

抽样方式: 分层抽样

优先包含: 含有陷阱标记的记录
```

```python
def stratified_sampling(records, sample_size=75):
    # 1. 优先包含陷阱检测记录
    trap_records = [r for r in records if has_trap_flag(r)]
    # trap_flags: substrate_product_confusion, probe_molecule_risk等

    # 2. 按分类比例随机抽样剩余配额
    remaining = sample_size - len(trap_records)
    non_trap_records = [r for r in records if not has_trap_flag(r)]

    # 按SUBSTRATE:INHIBITOR:PRODUCT:EXCLUDE比例分层
    class_distribution = get_class_distribution(non_trap_records)
    sampled = stratified_random_sample(non_trap_records, remaining, class_distribution)

    return trap_records + sampled
```

#### 2.2.3 Claude最终决策

**决策逻辑**:
```python
def make_final_decision(codex_result, gemini_result=None):
    if codex_result['assessment'] == 'CONFIRM':
        return 'CONFIRM', original_class

    elif codex_result['assessment'] == 'SUSPICIOUS':
        return 'SUSPICIOUS', original_class  # 保留原分类

    elif codex_result['assessment'] == 'WRONG':
        if gemini_result is None:
            # 未进行Gemini验证（不应发生）
            return 'SUSPICIOUS', original_class

        if gemini_result['verdict'] == 'AGREE':
            # Gemini确认Codex建议
            return 'CHANGED', codex_result['suggested_class']

        elif gemini_result['verdict'] == 'DISAGREE':
            # Gemini否定Codex建议，保留原分类
            return 'CONFIRM', original_class
```

### 4.3 REC_0297：全氟化脂肪酸 + BM3 (SUBSTRATE → INHIBITOR)

**基本信息**:
| 字段 | 值 |
|------|-----|
| 酶 | CYP102A1 (P450 BM3) |
| 配体 | N-(高度氟化链) 全氟化脂肪酸 |
| 原分类 | SUBSTRATE |

**Codex快速判断**:
```
Assessment: WRONG
Reason: Perfluoroalkyl motifs are generally non-oxidizable due to
the extreme stability of C-F bonds. The "substrate" label is a red flag.
These molecules can bind like substrates but cannot be hydroxylated.
Suggested: INHIBITOR
```

**Gemini文献验证**:
```
Verdict: AGREE with Codex

Literature evidence (PMID: 11983072, J. Am. Chem. Soc.):
- Title: "Perfluorinated Fatty Acids as Probes of Cytochrome P450 BM3"
- Key finding: Perfluorinated fatty acids act as "DECOY MOLECULES"

Mechanism:
1. Bind to active site like normal fatty acid substrates
2. Trigger spin state shift (Type I binding)
3. CANNOT be hydroxylated (C-F bond too strong)
4. Results:
   - Stimulate futile NADPH oxidation (uncoupling)
   - Competitively inhibit real substrates

Conclusion: These are DECOY MOLECULES / COMPETITIVE INHIBITORS
```

**最终决策**:
| 项目 | 值 |
|------|-----|
| 原分类 | SUBSTRATE |
| 新分类 | **INHIBITOR** |
| 置信度 | HIGH |
| 证据等级 | A |
| 决策理由 | C-F键极稳定，无法被氧化。是"诱骗分子"——能诱导自旋态转变但导致无效循环，竞争性抑制真实底物 |

## 九、经验总结

### 9.1 二方协作效果评估

| 角色 | 贡献 | 优势 |
|------|------|------|
| **Claude** | 整合协调、抽样策略、最终决策 | 全局把控 |
| **Codex** | 批量快速审核、技术判断 | 高通量处理（75条/批） |
| **Gemini** | 针对性文献验证 | 精准证据（仅6条） |

**效率对比**:
- 03a三方全面协作：15条/session
- 03b二方快速协作：75条/session
- **效率提升：5倍**

### 9.2 关键学习

1. **探针分子的识别**: 雌三醇案例展示了结晶学探针易被误标为底物
2. **诱骗分子（Decoy molecules）**: 全氟化脂肪酸等可诱导构象变化但不被催化
3. **底物类似物抑制剂**: CYP121 DKP类似物展示了结构微小差异导致的功能转变
4. **反离子伪影**: 环己基铵离子提醒注意盐形式的数据注释错误
5. **MEDIUM置信度的价值**: 36%的存疑记录表明MEDIUM标记有效反映了不确定性

### 9.3 后续建议

1. **27条存疑记录**: 可在后续研究中进一步验证，但不影响当前数据集使用
2. **陷阱标记优化**: REC_0318和REC_0378的substrate_product_confusion陷阱需要完整SMILES才能判断
3. **文献覆盖**: 部分非典型底物（如PikC类似物）需要更深入的文献调研
