#### 2.1.5 决策逻辑：分类判断的完整规则树

当Gemini和Codex返回结果后，Claude的决策流程：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    Claude决策规则树                                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   【决策起点】接收Gemini和Codex结果                                      │
│           ▼                                                             │
│   第1步: 一致性检查                                                      │
│           Gemini分类 == Codex分类 ?                                     │
│           │                                                             │
│           ├── 【是：分支A】                                              │
│           │   ├── consensus = True                                      │
│           │   ├── confidence = HIGH                                     │
│           │   └── final_class = 共同分类                                │
│           │                                                             │
│           └── 【否：分支B】进入证据分析                                  │
│               ▼                                                         │
│   Gemini证据评估:                                                        │
│           ├── 有PMID + 定量数据(IC50/Ki/Km) → 等级A (最强)              │
│           ├── 有PMID无定量 → 等级B                                      │
│           └── 无PMID → 等级C/D (弱)                                     │
│                                                                         │
│   Codex证据评估:                                                         │
│           ├── Fe距离<3Å → Type II强证据                                  │
│           ├── 检测到化学修饰(-OH/-O等) → Product强证据                   │
│           ├── Fe距离>10Å → EXCLUDE强证据                                 │
```

|------|------|
| **Decoy分子** | 占据活性位点但不被催化的分子，用于改变酶构象或辅助其他配体结合 |

| **consensus** | Gemini与Codex分类一致 |
