## Q0: 为什么是toy_example格式？（必读）

> **核心问题**: 为什么我们要参考 `data/toy_example/` 的格式，而不是 ESIBank 在 `G:\...\brenda\random_split\testing_datas_0.csv` 的格式？

### 0.1 一句话回答

**因为模型代码写死了只认toy_example格式的列名，ESIBank格式的列名会直接报错。**

### 0.2 通俗比喻

想象你有一台**全自动料理机（模型代码）**：

| 角色 | 现实类比 | 说明 |
|------|---------|------|
| **ESIBank格式** | 📦 原材料采购单 | 上面写着"苹果、面粉、糖"（`enzyme, reaction, label`） |
| **toy_example格式** | 🎫 机器识别工单 | 上面写着"原料ID: 001, 配方ID: 055"（`Enzyme Index, Substrate Index`） |
| **模型代码** | 🤖 全自动料理机 | 只会扫描条形码，看不懂"苹果"这个汉字 |

**关键点**：机器人（模型）的程序里写死了：
```python
ingredient = data["Enzyme Index"]  # 我只找这个名字的列！
```

如果你给它ESIBank格式（列名是`enzyme`），机器人根本找不到`Enzyme Index`这一列，直接崩溃报错（KeyError）。

### ⚠️ 重要澄清

**我们的负样本方法并非"不规范"**，而是测试了**不同的模型能力**：

- **ESIBank负样本**：错误的酶 + 正确的底物 → 测试"酶选择性"（能否区分正确酶 vs 错误酶）
- **我们的负样本**：正确的酶 + 非底物配体（抑制剂/产物）→ 测试"催化能力"（能否区分催化 vs 结合）
- **B7负样本**：正确的酶 + 错误的底物 → 测试"底物特异性"（能否区分可催化 vs 不可催化底物）

三者都是有效的评估策略，取决于研究目标。

### 🆕 B7方案速览

| 维度 | 说明 |
|------|------|
| **概念** | ESIBank式"错底物"采样，固定酶E，随机配对底物S' |
| **潜在规模** | 可生成34,488个新负样本（99.2%组合空间） |
| **核心挑战** | 合成配对(E,S')无真实PDB复合物 |
| **解决方案** | `full_data=True` + RDKit生成配体3D构象（无需对接） |
| **风险** | P450酶promiscuous，假负样本率较高 |
| **建议** | 先完成B3评估，根据结果决定是否实施B7 |

## Q1: 负样本规范性分析

### 1.1 ESIBank的负样本生成算法

**代码位置**: `src/Datasets/utils.py:115`

**核心逻辑**（简化版伪代码）:
```python
def generate_negative_sample(df, same_digits, num_negative_enzyme):
    """
    为每个正样本(酶A, 底物X)生成负样本(错误酶B, 底物X)
    """
    # 步骤1: 构建查找表
    ecnumber_dict = {}  # {EC前缀: [该前缀下的所有酶]}
    reaction_dict = {}  # {底物: {能催化它的酶: True}}

    # 步骤2: 对每个正样本(酶A, 底物X)
    for reaction, enzyme, ecnumber in df:
        # 正样本保留
        add_positive(enzyme, reaction, ecnumber)

        # 负样本生成: 从相同EC前缀池中随机抽取错误酶
        ec_prefix = ecnumber.split('.')[:same_digits]  # e.g., "1.4.3.3" → "1.4"
        candidate_enzymes = ecnumber_dict[ec_prefix]  # 所有EC号以"1.4"开头的酶

        for wrong_enzyme in random.sample(candidate_enzymes):
            if wrong_enzyme NOT in reaction_dict[reaction]:
                add_negative(wrong_enzyme, reaction, fake_ec=wrong_enzyme.ecnumber)
```

**实际代码片段**（`utils.py:161-191`）:
```python
# 确定负样本难度
negative_same_digit = same_digits  # 通常为0-5
current_n_negative_sample = 0
sample_enzymes = ecnumber_dict[".".join(ecnumber.split(".")[:negative_same_digit])]

# 从EC前缀池中随机采样
for negative_enzyme in random.shuffle(sample_enzymes):
    if current_n_negative_sample < num_negative_enzyme:
        if negative_enzyme not in reaction_dict[reaction]:
            data['reaction'].append(reaction)
            data['enzyme'].append(negative_enzyme)
            data['fake_ecnumber'].append(enzyme_dict[negative_enzyme][0])
            data['ecnumber'].append(ecnumber)
            data['label'].append(0)
            current_n_negative_sample += 1
```

**生成策略**:
- **6轮采样**：每个正样本通过6次不同`same_digits`值（0-5）生成6个负样本
- **难度梯度**：`same_digits=0`最简单（完全不同EC类），`same_digits=5`最难（仅末位不同）
- **平均比例**：约6:1（负:正）

**验证证据**:
- Codex分析确认：`src/Datasets/utils.py`的`generate_negative_sample`函数
- 实际数据比例：ESIBank的323,783个样本，正负比约为1:9.36

### 1.2 我们的负样本方法

**策略**: 使用生化功能标注（INHIBITOR/PRODUCT）作为负样本

**理论基础**:
1. **INHIBITOR（抑制剂）**：
   - 能够与酶活性位点结合（Km可测量）
   - **不能被催化**成产物
   - 与底物竞争结合位点
   - **生化意义**：测试模型能否区分"结合"与"催化"

2. **PRODUCT（产物）**:
   - 是催化反应的**结果**而非**反应物**
   - 可逆反应中可能被催化为底物（但热力学不利）
   - 大多数情况下产物-酶亲和力低于底物-酶
   - **生化意义**：测试模型能否理解反应方向性

**与ESIBank方法的对比**:

| 维度 | ESIBank负样本 | 我们的负样本 |
|------|--------------|-------------|
| **生成方式** | 随机采样错误酶 | 文献验证的生化标注 |
| **测试能力** | 酶选择性（正确酶 vs 错误酶） | 催化能力（催化 vs 结合/产物） |
| **数据来源** | 算法生成（低成本） | 实验验证（高成本） |
| **生化真实性** | 人工构造（可能不存在的配对） | 真实观测（PDB实验结构） |
| **评估目标** | 模型能否学到酶-底物映射规则 | 模型能否理解催化反应本质 |

---

### 1.3 规范性判定

**结论**: 我们的方法**并非不规范**，而是**另一种有效的评估策略**。

**理由**:
1. **文献支持**：许多酶学研究使用抑制剂/产物区分催化活性（例如药物筛选）
2. **实验真实性**：我们的负样本来自真实PDB结构，不是算法臆想
3. **互补性**：ESIBank测"选对酶"，我们测"分清催化 vs 结合"
4. **应用价值**：药物开发更关心"能否催化"而非"哪个酶催化"

**潜在问题**:
- **标注噪声**：部分INHIBITOR在特定条件下可能是底物（需文献复核）
- **产物争议**：可逆反应中产物理论上可作为底物（已在Step 3.01讨论，最终归为负样本）
- **数据量小**：仅682条（vs ESIBank的323,783条），统计显著性受限

**Gemini的实用建议**:
> "Your negative samples (INHIBITOR/PRODUCT) are valid but represent 'hard mode' testing. Think of it as:
> - ESIBank tests: 'Can you match the right enzyme to this substrate?'
> - Your test: 'Can you distinguish catalysis from mere binding?'
>
> Both are valuable. ESIBank is easier (wrong enzyme usually has very different active site), yours is harder (inhibitor fits the pocket but can't be catalyzed)."

## Q3: 训练集与测试集

### 3.1 为什么需要相同结构？

**答案**: 因为PyTorch DataLoader需要统一的数据接口。

**代码证据**（`src/Datasets/brenda.py:38-50`）:
```python
def train_dataloader(self):
    data = get_representer(df=self.train_df, config=self.config, ...)

def val_dataloader(self):
    data = get_representer(df=self.val_df, config=self.config, ...)
    return DataLoader(data, batch_size=self.batch_size, ...)

def test_dataloader(self):

    dataloader = DataLoader(data, batch_size=self.batch_size, ...)
    self.test_prediction_df = self.test_df.iloc[data.valid_idx].reset_index(drop=True)
    return dataloader
```

**关键点**:
- 所有三个DataLoader都调用同一个`get_representer`函数

## Q5: B7数据集构建方案分析

### 5.1 B7的概念定义

**核心思想**：将ESIBank的"错酶"负样本改为"错底物"负样本

| 方法 | 固定项 | 随机采样项 | 负样本形式 | 测试能力 |

| ESIBank | 底物S | 错误的酶E' | (E', S) | 酶选择性 |
| **B7** | 酶E | 错误的底物S' | (E, S') | 底物特异性 |

**科学目标**：给定一个P450酶，测试模型能否正确区分它能催化的底物和不能催化的底物。

### 5.2 数据可行性分析

### 5.5 科学有效性风险

#### 假负样本风险 ⚠️

**Codex警告**：
> "B7的新增负样本绝大多数是 assumed negatives（开放世界假设）。P450普遍promiscuous，假负样本风险比一般酶更高。"

**风险点**：
- 我们假设的"酶E不催化底物S'"可能实际上可以催化
- P450酶家族以底物谱广著称
- 会引入"噪音标签"

#### 同一酶多结构问题（关键！）

**问题描述**：
- 同一UniProt可能对应多个Enzyme Index（不同PDB结构）
- 例：P14779（BM3）对应Enzyme Index: 0, 7, 8, 19...

**危险场景**：
```
Enzyme_0 + Substrate_X = 正样本
随机采样生成 Enzyme_7 + Substrate_X = 负样本
→ 强假负样本（同一酶的不同结构！）
```

**解决方法**：按UniProt ID聚合已知正样本

### 5.6 B7负样本生成算法（UniProt聚合版）

```python
# 伪代码：B7负样本生成算法

import random
import pandas as pd

# Step A: 准备集合
df_B3 = pd.read_csv("data.csv")
P = set(zip(df_B3[df_B3['Label']==1]['Enzyme Index'],
            df_B3[df_B3['Label']==1]['Substrate Index']))  # 272个正样本

enzymes_df = pd.read_csv("Enzymes.csv")
UniProt_map = dict(zip(enzymes_df['Enzyme_Index'], enzymes_df['UniProt_ID']))

# 按UniProt聚合已知正样本（避免假负样本）
PosByUniProt = {}
for (e, s) in P:
    u = UniProt_map[e]
    if u not in PosByUniProt:
        PosByUniProt[u] = set()
    PosByUniProt[u].add(s)

# 底物池：使用B3正样本中出现的220个底物
S_pool = {s for (e, s) in P}

# Step B: 为每个正样本生成k个"错底物"负样本
k = 9  # 每个正样本生成9个负样本

negative_samples = []
for (enzyme_idx, substrate_pos) in P:
    u = UniProt_map[enzyme_idx]

    # 候选负底物：排除该酶的所有已知底物（按UniProt聚合）
    Cand = S_pool - PosByUniProt[u]

    # 随机采样k个
    sampled_negatives = random.sample(list(Cand), min(k, len(Cand)))

    for substrate_neg in sampled_negatives:
        negative_samples.append({
            "Enzyme Index": enzyme_idx,
            "Substrate Index": substrate_neg,
            "Label": 0,
            "Dock Index": -1  # dummy值，配合full_data=True使用
        })

# Step C: 合并B3 + 新负样本
B7 = pd.concat([df_B3, pd.DataFrame(negative_samples)])
```

def read_datasets(data):
    """
    读取一个或多个CSV文件并拼接成单个DataFrame
    """
    result = []
    for index, path in enumerate(get_paths(data)):
        df = pd.read_csv(path, sep=',')  # ← 直接读取，原样保留列名！
        result.append(df)

    df = pd.concat(result, ignore_index=True)

    # 仅添加两个管理用的列，不重命名任何原有列
    df['dataset_id'] = dataset_id
    df['tag'] = dataset_id

    return df  # ← 返回原始列名，没有任何映射

### 6.4 LMDB为什么不可跳过

#### 6.4.1 模型架构证据

**文件**: [src/Models/ss.py:53-55](src/Models/ss.py#L53-L55)

```python
class SS(nn.Module):
    def __init__(self, config):
        super().__init__()
        # 蛋白质特征处理：输入必须是1280维ESM嵌入
        self.protein_mlp = nn.Sequential(
            nn.Linear(1280, hidden_dim),  # ← 第一层输入1280维！
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
```

**含义**: 模型的第一层是 `nn.Linear(1280, hidden_dim)`，它**期望输入是1280维的数值向量**，不是氨基酸字符串。

如果你直接传入字符串如 `"MVLSPADKTNVKAAWGKVGAHAGEYGAEALERMFLSFPT..."`，模型会报错。

#### 6.4.2 特征来源验证

| 特征类型 | 原始形式 | 模型期望形式 | 生成工具 | 输出文件 |
|----------|----------|--------------|----------|----------|
| 蛋白质嵌入 | 氨基酸序列字符串 | 1280维float向量 | ESM-2 | `enzyme_features.lmdb` |
| 底物图 | SMILES字符串 | 原子/键/邻居矩阵 | RDKit | `reaction_features.lmdb` |
| Morgan指纹 | SMILES字符串 | 1024-bit向量 | RDKit | `morgan_fingerprint.npy` |
| GROVER嵌入 | SMILES字符串 | 4885维向量 | GROVER | `grover_fingerprint.lmdb` |
| 结构特征 | PDB文件 | 3D坐标张量 | BioPython | `structure_features.lmdb` |

#### 6.4.3 代码中无动态生成

**Codex分析结论**:

> "I searched the ENTIRE codebase for any code that would dynamically generate features from raw sequences or SMILES.
>
> **Finding**: There is NO such code. The model ONLY reads from pre-computed LMDB files.
>
> - No `esm.pretrained` calls in forward pass
> - No `AllChem.GetMorganFingerprint` calls in forward pass
> - No `Chem.MolFromSmiles` calls in forward pass (except in feature generation scripts)
>
> **Conclusion**: LMDB files are MANDATORY. There is NO fallback to generate features on-the-fly."

### 6.9 模型输出解读

#### 6.9.1 score是什么

**score是logit，不是概率**。

| score值 | 含义 | 概率 |
|---------|------|------|
| score > 0 | 模型倾向于预测"能催化" | prob > 0.5 |
| score = 0 | 模型不确定 | prob = 0.5 |
| score < 0 | 模型倾向于预测"不能催化" | prob < 0.5 |

#### 6.9.2 转换为概率

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 示例
score = 2.347
prob = sigmoid(score)  # 0.9127
# 解读：91.27%概率该酶能催化该底物
```

```python
def generate_negative_sample(df, config=None, same_digits=None, num_negative_enzyme=None,
                              random_negative_digit=None, has_positive_sample=True):
    """
    为每个正样本(酶, 底物)生成负样本(错误酶, 底物)

    参数:
        df: 包含'enzyme', 'reaction', 'ecnumber'列的DataFrame
        same_digits: EC编号前缀匹配位数（0-5，越大越难）
        num_negative_enzyme: 每个正样本生成多少个负样本
        has_positive_sample: 是否保留正样本

    返回:
        DataFrame: 包含正负样本的数据集
    """
    if config is None:
        assert same_digits is not None and num_negative_enzyme is not None
    else:
        same_digits = config.data.sampling.same_digits
        num_negative_enzyme = config.data.sampling.num_negative_enzyme

    print("Start generating negative samples!")

    # 构建查找表
    reaction_dict = {}  # {reaction: {enzyme: True}}
    enzyme_dict = {}    # {enzyme: [ecnumbers]}
    ecnumber_dict = {}  # {ec_prefix: [enzymes]}
    negative_dict = {}  # {(enzyme, reaction): True}

    # 填充查找表
    for reaction, enzyme, ecnumber in zip(df['reaction'], df['enzyme'], df['ecnumber']):
        if reaction not in reaction_dict:
            reaction_dict[reaction] = []
        reaction_dict[reaction].append((enzyme, ecnumber))

        if enzyme in enzyme_dict:
            enzyme_dict[enzyme].append(ecnumber)
        else:
            enzyme_dict[enzyme] = [ecnumber]

        # 为0-4位EC前缀建立索引
        for i in range(0, 5):
            chuncked_ecnumber = ".".join(ecnumber.split(".")[:i])
            if chuncked_ecnumber not in ecnumber_dict:
                ecnumber_dict[chuncked_ecnumber] = []
            ecnumber_dict[chuncked_ecnumber].append(enzyme)

    # 转换为集合（去重）
    for key in reaction_dict:
        reaction_dict[key] = {enzyme: True for enzyme, ecnumber in list(set(reaction_dict[key]))}

    # 生成样本
    data = {
        'reaction': [],
        'enzyme': [],
        'ecnumber': [],
        'fake_ecnumber': [],
        'label': []
    }

    for reaction, enzyme, ecnumber in tqdm(zip(df['reaction'], df['enzyme'], df['ecnumber']),
                                            total=df['enzyme'].shape[0]):
        # 添加正样本
        if has_positive_sample:
            data['reaction'].append(reaction)
            data['enzyme'].append(enzyme)
            data['ecnumber'].append(ecnumber)
            data['fake_ecnumber'].append(ecnumber)  # 正样本时fake_ec == 真实ec
            data['label'].append(1)

        # 生成负样本
        if random_negative_digit is None:
            negative_same_digit = same_digits
        else:
            negative_same_digit = random.randint(0, same_digits+1)

        current_n_negative_sample = 0
        sample_enzymes = ecnumber_dict[".".join(ecnumber.split(".")[:negative_same_digit])]
        if len(sample_enzymes) > num_negative_enzyme * 10:
            sample_enzymes = random.sample(sample_enzymes, num_negative_enzyme * 10)
        random.shuffle(sample_enzymes)

        for negative_enzyme in sample_enzymes:
            if current_n_negative_sample < num_negative_enzyme:
                # 确保不是真实配对且未重复采样
                if negative_enzyme not in reaction_dict[reaction] and \
                   (negative_enzyme, reaction) not in negative_dict:
                    data['reaction'].append(reaction)
                    data['enzyme'].append(negative_enzyme)
                    data['fake_ecnumber'].append(enzyme_dict[negative_enzyme][0])
                    data['ecnumber'].append(ecnumber)
                    data['label'].append(0)
                    negative_dict[(negative_enzyme, reaction)] = True
                    current_n_negative_sample += 1

    data = pd.DataFrame(data)
    return data
```

```python
def getitem_with_real_idx(self, idx):
    """
    根据CSV中的索引获取一个样本的所有特征

    流程:
        1. 从CSV读取底物ID、酶ID、标签
        2. 用ID从LMDB查找特征
        3. 组装成PyG Data对象
    """
    # 步骤1: 从CSV读取元数据
    reation_idx = self.df.loc[idx, 'Substrate Index']  # ← 必需列
    enzyme_idx = self.df.loc[idx, 'Enzyme Index']      # ← 必需列
    dataset_id = self.df.loc[idx, 'dataset_id']        # ← 自动添加
    tag = self.df.loc[idx, 'tag']                      # ← 自动添加

    substrate_features = {}

    if self.enzyme_dbs is None or self.reaction_dbs is None:
        self._connect_db()

    # 步骤2: 从LMDB读取底物特征
    with self.reaction_dbs[dataset_id].begin(write=False) as txn:
        key = str(reation_idx).encode()  # 用底物索引作为key
        value = txn.get(key)
        reaction_data = pickle.loads(value)

    # 步骤3: 从LMDB读取酶特征
    with self.enzyme_dbs[dataset_id].begin(write=False) as txn:
        key = str(enzyme_idx).encode()  # 用酶索引作为key
        value = txn.get(key)
        enzyme_data = pickle.loads(value)

    # 步骤4: 读取GROVER特征（如果启用）
    if "grover" in self.config.data.atom_features or \
       "grover_mean" in self.config.data.features:
        with self.grover_dbs[dataset_id].begin(write=False) as txn:
            key = str(reation_idx).encode()
            value = txn.get(key)
            grover_data = pickle.loads(value)
            substrate_features["grover_mean"] = torch.from_numpy(
                grover_data['total_embedding'][np.newaxis, :]
            )
            reaction_data["grover"] = torch.from_numpy(grover_data['embedding'])

    # 步骤5: 读取Morgan指纹（如果启用）
    if "morgan" in self.config.data.features:
        substrate_features["morgan"] = torch.from_numpy(
            self.morgan_dbs[dataset_id][reation_idx][np.newaxis, :]
        )

    # 步骤6: 填充到固定长度
    reaction_data = preprocess_reaction_feature(reaction_data,
                                                 self.config.data.max_substrate_length)
    enzyme_data = preprocess_enzyme_feature(enzyme_data,
                                             self.config.data.max_enzyme_length)

    # 步骤7: 构建PyG Data对象
    data = ReactionData.from_protein_ligand_dicts(
        torchify_dict(reaction_data),
        torchify_dict(enzyme_data),
        label=torch.from_numpy(np.array(self.df.loc[idx, 'Label'], dtype=float)),  # ← Label仅此处用
        tag=tag,
        **substrate_features
    )

    return data
```

**关键观察**:
- `positive_reactions`列**从未被引用**
- `Label`仅在最后构建Data对象时使用（可以是占位符）
- 所有特征都从LMDB读取，CSV仅提供索引
