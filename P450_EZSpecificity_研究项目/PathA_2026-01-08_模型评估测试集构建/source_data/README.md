## 使用指南

### 快速开始

```python
import pandas as pd

# 读取主数据集（682条）
df = pd.read_csv('source_data/01_核心数据/修复后最终版/独立测试集_682条.csv')
print(f"总记录数: {len(df)}")

# 按物种读取
df_bacteria = pd.read_csv('source_data/03_物种分类/按物种分类/修复后最终版/独立测试集_bacteria_426条.csv')
```

### PathA各步骤使用的数据

| Step | 输入数据 | 来源字段 |
|------|----------|----------|
| Step 1 | PDB ID列表 | `独立测试集_682条.csv` 的 `pdb_id` 列 |
| Step 2 | 酶序列 | `独立测试集_682条.csv` 的 `sequence` 列 |
| Step 3 | 配体CCD | `独立测试集_682条.csv` 的 `ligand_ccd` 列 |

**重要**: Step 2应使用CSV的`sequence`字段，而非从PDB文件提取（PDB文件可能缺少未解析的N/C端残基）

### 数据验证

```python
# 验证物种分类总和一致性
df_main = pd.read_csv('.../修复后最终版/独立测试集_682条.csv')
df_bacteria = pd.read_csv('.../修复后最终版/独立测试集_bacteria_426条.csv')
df_fungi = pd.read_csv('.../修复后最终版/独立测试集_fungi_30条.csv')
df_mammals = pd.read_csv('.../修复后最终版/独立测试集_mammals_101条.csv')
df_plants = pd.read_csv('.../修复后最终版/独立测试集_plants_9条.csv')
df_other = pd.read_csv('.../修复后最终版/独立测试集_other_116条.csv')

total = len(df_bacteria) + len(df_fungi) + len(df_mammals) + len(df_plants) + len(df_other)
assert total == 682, f"物种分类总和({total})与主数据集(682)不一致"
```
