# P450-EZSpecificity 研究项目

基于 EZSpecificity 模型的 P450 酶特异性预测研究。

## 项目背景

EZSpecificity 是一个基于交叉注意力机制的 SE(3)-等变图神经网络，用于预测酶-底物特异性（Nature 2025）。本项目专注于 P450 细胞色素酶家族的特异性研究，**路径A已完成全部10个步骤**，完成了从数据准备到模型评估的完整流程。

## 最新进展

- ✅ **Path A 完成**（2026-01-30）：使用PDB实验结构评估EZSpecificity模型
  - AUC-ROC: **0.6636**，AUC-PR: **0.6360**
  - 测试集：517条高质量酶-配体对（148个P450酶，626个PDB结构）
  - 采用抑制剂+产物作为负样本（比论文的随机配对更具挑战性）
- ✅ **三方深度验证**（Claude+Codex+Gemini）：682条记录的配体分类
  - 发现并修正8.5%的标注错误
  - 证据等级A+B达91.2%（有文献支持）
- ✅ **v2数据重构**：按(UniProt+配体)去重，从158条扩展到682条
- 📄 **汇报材料v2**：完整的研究进展报告（见 `毕业设计/组会汇报材料/P450研究项目组会汇报材料_v2.md`）

## 评估结果

**核心指标**：
- **AUC-ROC**: 0.6636（比论文最难场景0.7198低5.6%）
- **AUC-PR**: 0.6360

**差距原因**（三方协作分析）：
1. **任务不匹配**（主因）：我们用抑制剂+产物做负样本，比论文的随机配对更难区分
2. **酶未见过**：测试集148个P450与训练集389个完全不重叠（0%）
3. **域偏移**：PDB配体（可结晶分子）vs BRENDA底物（可催化分子）
