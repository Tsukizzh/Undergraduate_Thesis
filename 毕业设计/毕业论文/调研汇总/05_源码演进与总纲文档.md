## 第一部分：源代码核心模型架构

### 1.1 SE(3)-等变 GNN（EnBaseLayer × 3 层）

**架构概览**：EZSpecificity 采用自研 EGNN（Equivariant Graph Neural Network）作结构通道核心，基于距离不变性的 EnBaseLayer（GVP 在 EXP005 作为实验分支）。

**三层信息流**：
- **输入**：`[B, N_atom, 128]`，N_atom = 底物+口袋蛋白原子总数（通常 300~500）
- **各层处理**：
  ```
  EnBaseLayer_1: h [N, 128] + edges → h [N, 128]
    ├─ 边特征：6(键类型 one-hot) + 1(通道标志) + 32(距离 RBF) = 39 维
    ├─ 节点 MLP：[2×hidden] → [hidden] 处理聚合消息
    └─ 残差连接：h = h + node_mlp(concat[message, h])
  EnBaseLayer_2 & 3：同结构迭代
  ```
- **输出**：`[B, N_atom, 128]` → scatter_mean 聚合为分子级 `[B, 128]`

**等变性机制**：
- 不显式用 3D 坐标做向量化消息传递，通过**距离函数**维持旋转不变性
- 距离 = `norm(pos[i] - pos[j])`，经 Gaussian Smearing 扩展为 32 维
- 边特征：`[bond_one_hot(6), cross_bond(1), dist_feat(32)]` → MLP 处理
- **核心创新**（vs 标准 GCN）：消息是距离和键类型的函数，不依赖坐标系选择

### 1.2 交叉注意力机制（双向）

源码：`src/Models/ss.py` 第 70-72 行、116-119 行

**双向架构**：
```
enzyme_attention:   Q=蛋白 [B, 1450, 128], K/V=底物 [B, 280, 128]
                    → [B, 1450, 128]（蛋白被底物重加权）

reaction_attention: Q=底物 [B, 280, 128], K/V=蛋白 [B, 1450, 128]
                    → [B, 280, 128]（底物被蛋白重加权）
```

**配置**：
- n_head=8，每头 dim = 128/8 = 16
- dropout=0.9（抑制过拟合）
- batch_first=True

**计算**：
```
Attention(Q,K,V) = softmax(Q·K^T / √d) · V
enzyme_att → weighted_sum_pro [B, 128]：mask 后取均值
reaction_att → weighted_sum_reaction [B, 128]：mask 后取均值
padding_mask：反应侧 max 280，酶侧 max 1450
```

### 1.3 预测头 MLP 与嵌入融合

源码：`src/Models/ss.py` 第 85 行 `specificity_header`

**输入维度计算**：
```
input_dim = hidden_dim × (
    2                              # x_pro + x_reaction (均值后)
    + use_attention × 2            # weighted_sum_pro + weighted_sum_reaction
    + use_gnn                      # str_mean (结构通道聚合)
    + len(features)//2             # grover_mean + morgan（全局分子特征）
)

config 示例：
  features = ['morgan', 1024, 'grover_mean', 4885]
  len(features)//2 = 2
  若 use_gnn=True, use_attention=True:
    input_dim = 128 × (2 + 2 + 1 + 2) = 128 × 7 = 896
```

**EXP005 扩展**：新增 `g_res` 第 8 向量拼到末端预测头，header 输入从 **896→1024**，新 128 列块零初始化。

**MLP 结构**：
```
header:
  num_layers: 3
  norm: True (LayerNorm)
  act_fn: relu

伪代码：
  x [B, 896] → Linear(896, 128) + ReLU + LayerNorm
             → Linear(128, 128) + ReLU + LayerNorm
             → Linear(128, 1)  → logits [B, 1]
```

### 2.4 EZSpecificity vs EnzymeCAGE 架构对比

| 维度 | EZSpecificity (Nature 2025) | EnzymeCAGE (Nat Catal 2026) |
|------|:---:|:---:|
| 预测目标 | 酶+**一个底物** → 能否催化 | 酶+**完整反应(底物→产物)** → 能否催化 |
| 酶编码 | ESM-2 全序列 | ESM-2 全序列 |
| 酶口袋 | 无专门提取 | GVP 残基级图（8Å 内） |
| 底物编码 | GROVER+EGNN 原子图 | SchNet 3D 构象 |
| 产物编码 | ❌ 无 | SchNet 3D 构象 |
| 反应中心 | ❌ 无 | ✅ AAM 标注 |
| 特征融合 | 双向交叉注意力 | 未透露 |
| GNN 选型 | EGNN（距离等变） | SchNet + GVP（方向向量） |

**GVP 关键创新**：
```
GVP = 标量特征 + 向量特征
  标量 s：128 维普通向量（旋转不变）
  向量 V：16 个 3D 向量（vx, vy, vz）（旋转等变）
优势：同时编码"大小"和"方向"，化学朝向敏感性
应用：EnzymeCAGE 用 GVP 编码 pocket 残基几何
EXP005 试验：移植 GVP 为新通路 → Test 0.9253 vs 0.9320（-0.007，无增益）
```

### 2.5 GVP 图神经网络核心思想

**为什么 EGNN 不够**：
```
问题：EGNN 只看距离，不看方向
例子：O 原子到中心原子距离都 2.8Å
      O_up（有效朝向）vs O_down（无效朝向）
      EGNN 认为效果相同
P450 催化尤其敏感：底物 C-H 键必须特定朝向 Fe 才反应
```

**GVP 解决方案**：
```
GVP 层 = 标量通道 + 向量通道并行

标量通道：
  普通特征融合，旋转不变
  处理键类型、原子类型等结构无关信息

向量通道：
  3D 方向向量，旋转等变
  物理旋转 → 向量跟着转
  通过不变量交互（点积、范数）与标量融合

参数：
  node_s [B, 128] + node_v [B, 16, 3]
  edge_s [E, 32] + edge_v [E, 1, 3]
```

**EXP005 在相同数据上测试**：0.9320→0.9253（-0.0067），不显著，原因：
1. 基线已很强（0.93）
2. GVP 作并行通路而非替代通路
3. P450 单家族同质性使 GVP 优势空间有限
