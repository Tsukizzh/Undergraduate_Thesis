## 叙事主线：一个完整的科研故事

这是一个典型的**"诊断—改进—再诊断—饱和"**科研闭环。论文的核心吸引力**不仅是一个 0.9320 的 AUC 基线**，更是沿途发现的两次底层数据 bug、三次结构特征"无增益"的负结果、以及由此得出的"**结构通道饱和性**"科学结论。

### 故事的六个章节

```
第一幕：复现与评估（Path A）
  — 用论文模型评 P450 → AUC=0.6636
  — 发现：任务不匹配（论文用随机负样本，我们用抑制剂）

第二幕：诊断崩溃（Path B）
  — 自己做 P450 数据集 + 重训 → AUC=0.517（近随机）
  — E4 分数分解：底物身份 R²=0.37，酶 R²=-0.06（被忽略）
  — E6 七家族对比：P450 唯一崩溃
  — E8 通道消融：P450 靠结构，磷酸酶靠序列（异质性）
  — 结论：P450 是模型弱项，非数据错

第三幕：重建数据集 + 复现论文（Path B-Step10 + Path C1）
  — 发现论文 EdgeConnection 边排序 bug（fixed vs legacy_bug）
  — legacy_bug Test=0.7244 > 论文 0.7198（✓ 复现+超越）
  — fixed 反而下降 → batch_size 是主瓶颈，非边 bug

第四幕：P450 全面数据集 + EXP001-003（Path C2-C3）
  — 5 源合并：RCSB+ESIBank+P450Rdb+PlantP450DB+PCPD
  — 1,622 酶 × 2,125 底物 × 4,751 正样本
  — Uni-Dock 对接 50,180 pairs
  — EXP001(0.7730) → EXP002a/Fe-HEM(0.7816) → EXP002b(0.7889) → EXP003/二面角(0.7914)
  — 阶梯式小幅提升，似乎每个改进都"有效"

第五幕：两次 LMDB Bug 大发现（2026-04-13/14）
  — ESM 错位：len(uniprot_dict) 替代 CSV 行号 → 95.8% 酶错配
  — GROVER 错位：删行未补位 → 99.6% 底物错配
  — 三阶段非破坏修复（enzymes_fixed, fix_flatbin, fix_geom, rekey grover）
  — EXP003_fixed（仅修 ESM）：Test 0.7914 → 0.8943 (+0.1029)
  — 一次训练超过之前所有优化叠加！

第六幕：干净数据上的真实答案 + 饱和发现（AllFix + EXP005）
  — 5 阶段 allfix 非破坏修复，6 套缓存（bare/heme/geom × natural/unified）
  — EXP001_allfix_unified (bare 28 维) → Test=0.9320 ★最优基线
  — EXP002a_allfix_unified (+Fe/HEM) → 0.9270 (-0.005) ⚠️
  — EXP003_allfix_unified (+φ/ψ/χ1) → 0.9300 (-0.002) ⚠️
  — EXP005_dualgraph_2plus (+GVP 残基级双通路) → 0.9253 (-0.0067) ⚠️
  — 三次"结构增补无增益"证据 → 结构通道饱和性结论
  — 外部评估：论文 ckpt 在同 test 上 0.5596 vs 我们 0.9205 (Δ=+0.362)
```

## 论文每章的关键素材速查

### 第一章·绪论

**背景要点**：
- P450 酶超家族广谱多样，活性位体积 190-490 Å³（Johnson & Stout JBC 2013）
- 酶-底物特异性预测是代谢工程、药物代谢、合成生物学核心问题
- 现有方法：传统分子对接（慢、精度有限）vs 深度学习（需大规模训练数据）

**现状对比**：
- **EZSpecificity（Nature 2025）**：三通道（序列+结构+分子）+ 双向交叉注意力，ESIBank 323,783 对训练，AllSplit 最难场景 AUC=0.7198
- **EnzymeCAGE（Nat Catal 2026）**：CLIP 式检索，反应级建模（含产物），GVP 残基口袋，HaloS 家族微调 Top-1=91.7%

**研究缺口**：
1. 论文模型对 P450 家族特别弱（ESIBank P450 内部 AUC=0.638，8 个家族最低）
2. 二分类粒度粗，未充分利用反应中心信息
3. 负样本质量影响巨大（Gate B 实验证实）

**研究目标**：
- 构建面向 P450 的专属数据集与训练管线
- 诊断论文架构在 P450 上的失效模式
- 探索提升方向（结构特征、口袋编码、对比学习）

### 第二章·方法

#### 2.1 EZSpecificity 核心架构复述

```
输入：酶序列 + 底物 SMILES + 对接复合物 PDB
        ↓
┌─ 特征提取 ────────────────────────────────────┐
│ ESM-2 嵌入 (1280→128)                           │
│ GROVER mean (4885) + Morgan (1024) → MLP→128    │
│ 复合物图：底物+10Å 口袋，原子坐标+键连接         │
└───────────────────────────────────────────────┘
        ↓
SE(3)-等变 GNN（EnBaseLayer × 3 层，k=48 邻居）
        ↓
双向交叉注意力（n_head=8, dropout=0.9）
  ├─ enzyme_attention：Q=酶, K/V=底物
  └─ reaction_attention：Q=底物, K/V=酶
        ↓
预测头 MLP（896 维拼接，3 层 FFN）→ logits → sigmoid → [0,1]
```

**关键超参**：
- hidden_dim=128, max_enzyme_length=1450, max_substrate_length=280
- 损失：BCEWithLogitsLoss
- 优化器：AdamW, lr=4e-4（allfix 最终版）, warmup=12 epochs, wd=1e-5

#### 2.2 数据构建

**Path A 独立评估集**（682 条 P450）：
- 来源：RCSB 晶体结构
- 去污染：58 条 Photosystem I（PDB 6ZZX 脚本 bug）
- 配体四分类：SUBSTRATE 271 / INHIBITOR 245 / EXCLUDE 143 / PRODUCT 23
- 三方验证：Claude + Codex + Gemini 交叉审核

**Path C2 训练数据集**（47,510 可用对）：
- 5 源合并：RCSB(272) + ESIBank(806) + P450Rdb(2798) + PlantP450DB(979) + PCPD(1209) = 6,064
- 双键去重：UniProt ID（+282 序列桥接）+ InChIKey → 4,751 正 / 1,622 酶 / 2,125 底物
- 双向负采样：Direction A（换酶）+ Direction B（换底物），1:5 ×2 = 47,503 负
- 4 种 split：random / reaction(底物 0%) / enzyme(酶 0%) / all(双 0%，仅保留 34.8%)
- 对接：Uni-Dock（GPU Vina）50,180 pairs（95.8%）

**底物分类体系**（v6 FINAL，支撑 Path D 预备）：
- 7 类多标签：Terpenoid/Amino_acid/Fatty_acid/Alkaloid/Steroid/Phenylpropanoid/Polyketide
- 五阶段 pipeline：NPClassifier Gold → NPC Superclass → NPC Pathway → AA SMARTS → Other
- 验证：50 样本抽检 95.9% 准确率

#### 2.3 改进策略

**尝试 1：Fe/HEM 编码（EXP002a）**
- 动机：P450 催化依赖血红素铁中心
- 实现：atomic_numbers 加 Fe(26)、HEM_AA_TYPE=21、is_hetero 标志，feature_dim 28→31
- 代码：7 处 protein_ligand.py + 3 处 transforms.py + build_pt_cache.py + pt_dataset.py

**尝试 2：残基几何特征（EXP003）**
- 动机：二面角含蛋白骨架几何信息
- 实现：φ(N-Cα) / ψ(Cα-C) / χ1(Cα-Cβ) 三角的 sin/cos 编码，feature_dim 31→37
- 代码：4 文件改动，Codex 6 轮审核

**尝试 3：GVP 残基级双图（EXP005）**
- 动机：EGNN 只用距离不用方向，GVP 提供 3D 方向向量
- 双出口：(1) h_res 按 UniProt 位置注入回 x_pro（深融合）(2) scatter_mean(h_res) 旁路拼到预测头（浅融合）
- 代码：新增 gvp.py(335)+ss_dualgraph.py(180)+pt_dataset_dualgraph.py(290)，Codex 7 轮审核，L1-L7 smoke test 全过

#### 2.4 训练基础设施

**云服务器**：
- Cloud-2 4×RTX4090 360GB RAM 28 核（主力）
- AutoDL 4×RTX5090（EXP005）

**DDP 关键配置**：
- find_unused_parameters=False（延迟解冻时设 True）
- sync_dist=False + validation/test_epoch_end 手动 all_gather（防 rank 0 only bug）
- effective_batch_size = bs=88 × 4 = 352

**.pt 缓存管线**（迭代 3 次）：
- v1 分片 300MB：0.01 it/s，SSD thrashing
- v2 flatbin+分片 graph：0.5 it/s
- **v3 per-sample .pt：7.56 it/s ✓**（本地）/ 1.8 it/s（云 DDP，含通信）

### 第三章·结果

#### 3.1 Path A 独立评估（0.6636）
- AUC-ROC = 0.6636 vs 论文 Unknown enzyme+substrate = 0.7198（-5.6%）
- 合理性：负样本类型不同（我们抑制剂 vs 论文随机配对），概率校准失效（最优阈值 0.04）

#### 3.2 Path B 诊断系列
- **Gate A**（结构因子 2×2）：EXP01（10Å, noHeme）AUC=0.7115 最优
- **Gate B**（对接管线评估）：AUC=0.5170 ≈ 随机（**崩溃**）
- **E4 分数分解**：底物偏置 R²=0.37，酶偏置 R²=-0.06，残差 AUC=0.509 → 模型完全忽略酶身份
- **E6 七家族对比**：P450=0.517（唯一崩溃），其他家族 0.79-0.93
- **E7 ESIBank P450 内部**：AUC=0.638（8 家族最低）
- **E8v1 通道消融（AUC=0.712）**：关结构 -0.275（P450 依赖结构）
- **E8v2 通道消融（AUC=0.517）**：关任何通道都不显著 → 瓶颈在任务/数据设计

#### 3.3 Path B Step 10 + Path C1 基线复现
- AllSplit 本地：Val=0.7542 / Test=0.7505（ep12）
- AllSplit 云 legacy_bug：Val=0.7224 / **Test=0.7244**（复现并超越论文 0.7198）
- fixed 边修复反而下降（-1.84%）→ batch_size 是主瓶颈
- dropout 消融：Val↑ Test↓（Val-Test gap 扩大 5 倍）

#### 3.5 Bug 发现与修复（论文最有戏剧性的一章）

**ESM 错位 Bug**：
- 发现时间：2026-04-13
- 代码：`phase7_step2_esm.py` 中 `uniprot_dict[str(idx)] = (len(uniprot_dict), 1)`
- 后果：95.8% 样本的酶特征错配
- 修复：fix_enzyme_lmdb → enzymes_fixed.lmdb → flatbin 重建 → geom_cache overlay
- **EXP003_fixed 验证：Test 0.7914 → 0.8943（+0.1029）**，一次训练超过之前全部优化叠加

**GROVER 错位 Bug**：
- 发现时间：2026-04-14 深夜（用户追问触发）
- 代码：`phase7_step5_grover.sh` 删除 `*[H]` 未补位
- 后果：99.6% 底物的 GROVER 嵌入错配
- 修复：`fix_grover_lmdb.py` 规则 `new_int = old if old<8 else old+1`

#### 3.6 AllFix 系列（干净数据真实基线）

```
       EXP001_allfix_unified  Test=0.9320  AUPR=0.6749  ★最优基线
  vs:  EXP002a_allfix_unified Test=0.9270  AUPR=0.6300  (−0.005)
```

**关键反转**：Fe/HEM、残基几何、GVP 双图三次添加结构侧特征均无增益或小幅退步。**EXP001-003 的原始 ablation 结论在干净数据上全部作废**。

#### 3.7 EXP004 外部公平对比（验证泛化真实性）

黑名单过滤 356 个 ESIBank P450 重合酶后：

| 模型 | Test AUC | AUPR |
|------|:---:|:---:|
| **论文 ckpt（过滤）** | **0.5596** | 0.1007 |
| 论文 ckpt（未过滤） | 0.5860 | 0.1124 |
| **我们 EXP001（过滤）** | **0.9205** | **0.6403** |

**三层证据**：
1. 论文对"见过的酶"也仅微弱记忆优势（+0.027）
2. leakage-controlled 下我们领先 +0.362 AUC
3. 我们未过滤→过滤仅降 0.012 → **泛化真实**

### 第四章·讨论

#### 4.1 结构通道饱和性的启示

三次无增益的对照：

| 实验 | 新增信号类型 | 独立贡献 |
|------|------|:---:|
| EXP002a | Fe/HEM 原子标量 | -0.005 |
| EXP003 | 残基二面角标量 | -0.002 |
| EXP005 | 残基 GVP 3D 向量 | -0.0067 |

**结论**：在 AllFix 干净数据 + 1,479 酶 × 44k 样本规模下，**原子级 EGNN + 双向交叉注意力已吃完结构通道信号**。添加任何结构侧特征（标量或向量、浅融合或深融合）均无增益。

**科学意义**：
1. 单家族同质性使结构变异有限，原子级 400+ 维已过剩
2. 残基级补充（37-64 残基压到 64-128 维）反而更稀疏
3. **后续方向必须转向数据侧或交叉注意力容量，非结构特征工程**

#### 4.2 两次 LMDB Bug 的系统教训

**"压缩计数器 key"反模式**：
- ESM：`len(uniprot_dict)` 替代 CSV 行号
- GROVER：顺序计数 key 当数据被删行

**防御原则**：
- 任何 LMDB 的 key 应永久绑定原始数据源行号
- CSV 行号 ↔ LMDB key ↔ flatbin 行号必须一一对应
- 多来源 LMDB 组装要做字节级交叉验证，非仅样本数量对齐

#### 4.3 与 EnzymeCAGE 的互补

EnzymeCAGE 的三大突破在本项目未实现：
1. **反应中心级建模**（AAM 标注）：需要底物→产物→反应中心的完整数据
2. **CLIP 对比学习**：改变训练目标（检索 vs 分类）
3. **GVP 残基级口袋** ← 我们 EXP005 已尝试，但饱和状态下无增益

未来融合方向：**在 EZSpecificity 三通道基础上加反应中心标签 + CLIP 检索损失**。

#### 4.4 工业应用前景

- 药物代谢预测：识别潜在 P450 代谢位点，评估 drug-drug interaction
- 代谢工程：为天然产物生物合成筛选合适 P450 酶
- 植物 P450 改造：基于本数据集 PlantP450DB 子集可支撑植物代谢工程

### 第五章·结论与展望

**核心贡献**：
1. **完整诊断体系**：A→B→C 三路径，系统暴露 EZSpecificity 在 P450 上的失效模式
2. **P450 专属高质量数据集**：47,510 可用对，4 种 split，双向负样本
3. **干净数据基线**：AllFix Test AUC=**0.9320**，外部验证领先论文 ckpt **+0.362**
4. **结构通道饱和性三证据**：为领域提供负结果参考，避免重复结构特征工程
5. **两次 LMDB 对齐 bug 的发现与非破坏修复**：方法学贡献
6. **多图架构 EXP005（GVP 双通路）的完整实现**：EnzymeCAGE 思路在 EZSpecificity 上的首次移植

**后续工作**：
- **Path D 区域选择性预测**（SoM）：利用 S9 PCPD 的 857 张反应图片
- 数据侧扩展：更多家族（植物 P450 为主）、更难负样本（同源酶+手性变体）
- 容量侧扩展：更深交叉注意力、ESM-2 升级到 15B 版本
- **代码开源**：已在 GitHub 管理，可发布 P450 专属 fork

## 写作语气建议

1. **诚实记录负结果**：三次结构特征无增益是本论文最有价值的发现之一，不要掩盖
2. **强调诊断价值**：从 0.6636 到 0.9320 不是简单的模型优化，是一套完整的诊断+修复方法论
3. **突出 bug 发现**：两次 LMDB bug 的发现展示了科研中"怀疑数据"的重要性
4. **避免过度声明**：0.9320 是 P450 单家族 random_split，不能直接和论文 AllSplit 0.7198 比较；要加脚注说明 split 不同
5. **使用对比而非绝对**：论文 ckpt 在同 test 上 0.5596 的对比比我们 0.9320 的绝对值更有说服力
