## 论文目录（最终版 TOC v7）

经服务器端实验事实核查后定稿，已对照《中山大学本科毕业论文（设计）写作与印制规范》。本版砍除一切未实际完成的实验（四种切分、多 fold CV、亚家族/底物类别分析、药学应用案例实验等），仅保留 **random split fold 0** 上已完成的五组实验：清洁数据基线、三种结构特征增强消融、论文预训练模型的外部泄漏控制公平对比。

### 合规与写作边界说明

**内容要素覆盖**（规范二（六））

- 绪论要求"研究设想 / 方法 / 实验设计 / 理论依据 / 范围 / 预期结果" → 1.4 段内多段落覆盖
- 主体要求"总体方案或选题的论证" → 2.4
- 主体要求"各部分设计实现 + 数据获取 + 可行性与有效性处理" → 第三章
- 主体要求"创新见解、创造性成果及其改进与实际应用价值" → 第四、五章
- 结论要求"创造性成果及其在本研究领域中的意义和作用" → 6.1 段内（不设独立"意义"节）

**标题规范**（规范三（七））

- 所有章节标题无标点符号、无特殊字符、无英文实验室代号
- 英文术语（EZSpecificity / ESM / GROVER / GVP 等）在正文首次出现时括号注明，不进入标题
- 模型简标 M0–M3 不作章节标题；只在正文括号与表格/图中使用

**编号规范**

- 正文三级编号 x.y.z，最深不超过规范四级上限 x.y.z.w
- 附录采用"附录A / 附A1"无空格格式（规范三（十六））

**英文摘要标题**：ABSTRACT，Times New Roman 加粗三号全部大写（规范二（四））

**相关科研成果目录**：本科期间无与毕业论文相关的已发表成果，按规范二（八）省略

**写作边界与表述纪律**（基于服务器事实核查）

- **仅采用随机切分 fold 0**：3.4 节写明"本研究采用随机切分（random split）按 EZSpecificity 参考框架标准流程生成训练 22083 / 验证 11008 / 测试 10999 样本"；辅以一行脚注"本研究预先生成了多种切分索引以便后续扩展，本论文仅报告随机切分第一折结果"
- **不声称交叉验证**：单一 fold 0，不提 k-fold CV、多 seed 平均、置信区间
- **数据质量控制段限 150–200 字**：3.6 节提及 LMDB 索引对齐风险、字节级一致性核验、最终数据集通过验证；不展示任何污染版 AUC 数字；不将其作为方法学贡献
- **结构增强措辞保守**：第五章表述为"在相同随机切分和统一测试集条件下，三种结构特征增强模型均未观察到优于基线模型的测试集表现"；禁止使用"饱和""冗余""充分性证明"等机制性措辞
- **不使用的内部代号**：EXP001 / EXP002a / EXP003 / EXP005 / EXP004 / allfix / unified / fe_heme_10A 等一律不出现在论文正文
- **污染前版本实验**（AUC 0.77–0.79）不进正文，附录可一行注明"内部诊断实验未作为正式结果报告"

**论文真实定位**（codex 核定）

> 基于真实可核验的 P450 专属数据集，在单一随机切分条件下复现并评估参考模型；通过泄漏控制公平对比，证明领域数据构建与严格评估协议对 P450 底物特异性预测的核心价值。

**迭代记录**：目录历经 v1–v7 七版。v5 前偏结构合规与重复消除；v6 退回纯已有数据；v7 为服务器事实核查后的最终版本，删除所有未实际开展的实验声明。
