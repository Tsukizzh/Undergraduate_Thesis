## 论文目录（最终版 TOC v7）

经服务器端实验事实核查与 2026-04-22 组会汇报 PDF 口径对齐后定稿，已对照《中山大学本科毕业论文（设计）写作与印制规范》。本版砍除一切未实际完成或内部探索未报告的实验（四种切分、多 fold CV、亚家族/底物类别分析、Fe/HEM 原子编码、残基二面角增强、药学应用案例实验等），仅保留 **random split fold 0** 上实际完成且写入汇报的三类结果：原架构基线训练、双图架构改进训练、参考论文预训练模型的外部泄漏控制公平对比。

**装订顺序**（规范一）：封面 → 扉页 → 学术诚信声明 → 摘要 → 目录 → 正文 → 参考文献 → 附录（如有）→ 致谢。前置三项不进入目录。

**页码**（规范三（四））：摘要至绪论前用大写罗马数字（Ⅰ/Ⅱ/Ⅲ…），绪论至结尾用阿拉伯数字（1/2/3…）。

**模型命名约定**：章节标题保持纯中文语义（如"双图架构改进模型"）；正文首次出现时以括号注名简标（如"原架构模型（M0）""双图架构模型（M1）"）；表格与图例使用 M0 / M1 简标以节省版面。实验室内部代号（EXP001 / EXP005 / allfix / unified 等）不进入论文正文。

### 合规与写作边界说明

**内容要素覆盖**（规范二（六））

- 绪论要求"研究设想 / 方法 / 实验设计 / 理论依据 / 范围 / 预期结果" → 1.4 段内多段落覆盖
- 主体要求"总体方案或选题的论证" → 2.4
- 主体要求"各部分设计实现 + 数据获取 + 可行性与有效性处理" → 第三章
- 主体要求"创新见解、创造性成果及其改进与实际应用价值" → 第四、五章
- 结论要求"创造性成果及其在本研究领域中的意义和作用" → 6.1 段内（不设独立"意义"节）

**标题规范**（规范三（七））

- 所有章节标题无标点符号、无特殊字符、无英文实验室代号
- 英文术语（EZSpecificity / ESM / GROVER / GVP 等）在正文首次出现时括号注明，不进入标题
- 模型简标 M0 / M1 不作章节标题；只在正文括号与表格/图中使用

**编号规范**

- 正文三级编号 x.y.z，最深不超过规范四级上限 x.y.z.w
- 附录采用"附录A / 附A1"无空格格式（规范三（十六））

**英文摘要标题**：ABSTRACT，Times New Roman 加粗三号全部大写（规范二（四））

**相关科研成果目录**：本科期间无与毕业论文相关的已发表成果，按规范二（八）省略

**写作边界与表述纪律**（基于服务器事实核查）

- **仅采用随机切分 fold 0**：3.4 节写明"本研究采用随机切分（random split）按 EZSpecificity 参考框架标准流程生成训练 22083 / 验证 11008 / 测试 10999 样本"；辅以一行脚注"本研究预先生成了多种切分索引以便后续扩展，本论文仅报告随机切分第一折结果"
- **不声称交叉验证**：单一 fold 0，不提 k-fold CV、多 seed 平均、置信区间
- **数据质量控制段限 150–200 字**：3.6 节提及 LMDB 索引对齐风险、字节级一致性核验、最终数据集通过验证；不展示任何污染版 AUC 数字；不将其作为方法学贡献
- **双图架构措辞**：第五章表述为"在相同随机切分和统一测试集条件下，双图架构相对原架构在 Test AUC 指标上观察到 +0.0008 的**微幅**提升，同时在 Test AUPR 指标上观察到 −0.0275 的回落"；允许将 AUC 提升作为"方向信息感知设计的**初步可行性探索**"叙述，但禁止使用"显著""证明""胜出""大幅领先""一致性提升"等强主张词汇；AUPR 回落必须与 AUC 提升**并列、对称**报告，禁止在讨论中弱化或选择性引用；贡献应定位于"架构设计与工程实现"而非"性能超越"
- **不使用的内部代号**：EXP001 / EXP005 / allfix / unified / dualgraph_2plus 等一律不出现在论文正文，以 M0 / M1 或"原架构""双图架构"指代
- **未报告的内部探索实验**：Fe/HEM 原子编码（feature_dim 28→31）与残基二面角 sin/cos 编码（31→37）两组结构增强实验因未展现稳定收益未写入汇报，本论文正文不报告，附录可一行注明"其他内部探索实验未纳入本论文正式结果"
- **污染前版本实验**（AUC 0.77–0.79）不进正文，附录可一行注明"内部诊断实验未作为正式结果报告"

**论文真实定位**（三方核定 + 2026-04-22 组会 PDF 对齐）

> 以 Nature 2025 发表的 SOTA 模型 EZSpecificity（UIUC 赵惠民课题组）为参照，选择该模型训练集 ESIBank 中覆盖稀少（389/25225 = 1.5%）但应用价值极高的 P450 超家族作为泛化能力试金石：首先构建整合五个来源的 P450 专属基准数据集；其次通过泄漏控制公平对比揭示 SOTA 模型在稀缺家族上的 zero-shot 泛化瓶颈；最后提出双图架构改进，在原架构基础上引入残基级 GVP 几何向量感知通路，在单 fold 评估下观察到 Test AUC 一致性提升。

**迭代记录**：目录历经 v1–v8 八版。v5 前偏结构合规与重复消除；v6 退回纯已有数据；v7 为服务器事实核查版；v8 依据 2026-04-22 组会汇报 PDF 对齐数字与叙事，Ch5 由"三次结构增强消融"调整为"双图架构改进"，创新点由三点扩为四点。

## 第一章 绪论（3800-4500 字）

### 子节

1.1 研究背景与意义（酶底物特异性作为酶功能核心属性 / 活性位点三维结构与反应过渡态耦合 / P450 超家族在药物代谢（约 75% 临床药物 I 相代谢）、天然产物生物合成、农药降解中的核心地位）

1.2 国内外研究现状评述（酶底物特异性预测的传统方法综述 / 深度学习方法 CLEAN / ESP / CPI 的局限 / **EZSpecificity (Nature 2025, UIUC 赵惠民课题组) 作为当前 SOTA：构建首个结构级酶-底物复合物数据库 ESIBank（323,783 对）、SE(3) 等变 GNN 编码活性位点、ESM-2 序列表征、双向交叉注意力机制；卤化酶湿实验 Top-1 准确率 91.7% 远超既往 SOTA（ESP 58.3%）；声称通用可跨家族预测**）

1.3 通用预测模型在 P450 上的局限与待解决问题（**EZSpecificity 验证的 6 代表性家族（酯酶、糖基转移酶、硝酸酶、磷酸酶、硫解酶、DUF 蛋白）加卤化酶在 ESIBank 训练集中均有充分数据覆盖** / **但 P450 在 ESIBank 中极为稀缺：经 InterPro 结构域严格验证，25,225 个酶中真正的 P450 仅 389 个，占比 1.5%，与全球已知 30 万条 P450 序列形成巨大反差** / **一个自然追问：对于训练集中稀缺但应用极重要的酶家族，SOTA 模型的"通用性"能否成立？** / 数据泄漏与公平评估的普遍性挑战）

1.4 研究目标实验设计与预期结果（段内多段落覆盖规范二（六）1 的"研究设想 / 方法 / 实验设计 / 理论依据 / 范围 / 预期结果"。**研究设想**：以 P450 作为 SOTA 泛化能力试金石；**方法**：构建 P450 专属数据集 + 泄漏控制公平对比 + 双图架构改进；**预期结果**：揭示 EZSpecificity 在 P450 上的 zero-shot 局限，并通过领域专属训练与架构改进突破该局限）

## 第五章 双图架构改进与效果分析（4500-5500 字）

### 子节

5.1 原架构对方向信息的局限性（原架构以 SE(3)-等变 EGNN 处理对接复合物，**仅捕获原子间距离、不编码空间方向**：距离为 2.8 Å 的两个氧原子无论在底物上方还是下方 EGNN 均视作等价 / P450 催化的物理特性：以 Heme-Fe 为中心的深长底物通道，C-H 键朝向差 30° 即可改变反应位点 / 对方向敏感的 P450 底物特异性预测任务需要具备方向感知能力的几何表征）

5.2 双图架构设计动机与原理（在原子级 EGNN 通路之外并列残基级几何向量通路 / **GVP（Geometric Vector Perceptron）作为 SE(3)-等变几何编码器，同时处理标量与向量**：旋转整个口袋时向量输出跟随旋转而不被打乱 / 每个口袋残基打包为"一组标量 + 一组向量"：标量由 φ/ψ/ω 三个骨架二面角的 sin/cos 编码共 6 维表达"骨架怎么折"；向量由 Cα→N、Cα→C、Cα→Cβ 三个 3D 方向表达"骨架朝哪儿、侧链指哪儿" / 残基节点间的边取最近邻 30 个残基，附带距离 RBF 特征与 Cα-Cα 方向向量）

5.3 残基级几何向量感知模块的实现（GVP encoder 3 层，借鉴 EnzymeCAGE 工程实现 / 输出每残基 256 维特征，作为残基级几何中枢 h_res / **双出口融合设计**：出口一"深融合"将 h_res 线性压至 128 维后回灌到序列特征（**权重零初始化**，训练起步贡献为 0，仅在需要时逐步开启深融合）；出口二"浅旁路"对 h_res 做残基均值池化后直接拼接入预测头，将原 7 个 128 维向量扩为 8 个，综合向量由 896 维扩至 1024 维 / **延迟解冻策略**：step 0 时 GVP 分支梯度为 0、训练起步严格等价基线（L5 baseline 等价性测试 max abs diff 4e-8），step 1 开始激活；DDP 训练使用 `find_unused_parameters=True` 兼容此设计）

5.4 双图架构训练与测试结果（训练配置：**4×RTX5090，bs=88/4 卡，57 epoch 早停，56.8 分钟完成** / 原架构（M0，ep43）：Val AUC=0.9250、**Test AUC=0.9302、Test AUPR=0.6749** / 双图架构（M1，ep41）：Val AUC=0.9262、**Test AUC=0.9310、Test AUPR=0.6474** / 测试样本 10,999（984 正 / 10,016 负），正负比 1:10.2 / **ΔAUC=+0.0008（微幅提升）、ΔAUPR=−0.0275（回落）** / 两项指标并列、对称报告，不作方向性选择；不做任何"一致性""稳健"论断）

5.5 结果讨论与方法学启示（AUC 微幅提升方向与"对方向敏感的 P450 催化需要方向感知表征"的物理假设方向一致，可视为双图设计**架构工程层面**的初步可行性探索 / AUPR 在极度不平衡数据（1:10.2）下对稀有正样本打分分布更敏感，本研究中的回落可能源于：未经充分超参调优情况下残基级通路导致的轻度过拟合、少数类打分分布的扰动、或单 fold 评估本身的方差；**诚实陈述该回落并承认这是空间分辨率与优化难度之间的 trade-off 信号** / 严格限定为单 random fold 评估下的观察，+0.0008 AUC 提升幅度处于单 fold 噪声边缘，且 AUPR 反向变化，**本研究不声明性能超越，仅作为架构可行性初步探索报告**；稳健性结论需多 seed × 多 fold 交叉验证 + 超参调优 + 显著性检验方可得出 / 本章观察对未来在 P450 领域设计几何感知模型的方法学启示：方向编码（GVP 类模块）作为纯距离编码之外的补充路径值得进一步探索、标量-向量联合建模的工程可行性已验证、AUPR 在极不平衡任务上需与 AUC 并列评估）
