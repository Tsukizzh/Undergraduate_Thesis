# P450 批量虚拟对接完整操作手册

> **本文档目的**：从零开始完成"路径1：随机配对负样本验证"的批量对接任务。
> **适用场景**：验证 EZSpecificity 模型在随机负样本下的性能。
> **预计耗时**：首次配置 2-3 小时，实际对接 6-8 小时（16核并行）。

---

## 零、先搞清楚为什么要对接

### 问题背景

当前测试集用的负样本是**抑制剂和产物**（来自晶体结构）。模型对 P450 完全陌生，给**所有样本**（包括正样本）都打了很低的分数：

- 正样本平均得分：-2.99 logit (约 5% 概率)
- 负样本平均得分：-5.05 logit (约 0.7% 概率)

**真阴性率高达 94%**，说明模型能区分大部分负样本。但问题是**正负样本得分分布重叠严重**（都挤在低分区间），导致 AUROC 只有 0.6636。

**路径1的假说**：如果换成**随机配对负样本**（跟训练集一样），随机负样本和酶完全无关，得分会更低（预计 -7 ~ -8 logit），拉开与正样本的间距，AUROC 预计升到 ~0.72。

### 为什么必须对接？

EZSpecificity 模型需要**酶-底物复合物的 3D 结构**作为输入：
- 正样本：有天然的晶体结构（从 PDB 下载的）
- 随机负样本：**没有天然结构**（酶 A + 底物 B 从来没在一起出现过）

**如果不对接会怎样？**
- 模型输入时，正样本有"口袋+配体"的完整结构图，负样本只有孤立的配体
- 模型会学到一个作弊规则："有口袋信息=阳性，没有=阴性"
- AUROC 虚高但毫无意义

**所以必须对接**：给每个随机负样本也生成一个"假装的"复合物结构，让正负样本的输入格式完全一致。

### 2.1 生成随机配对表

**目标**：生成 ~2,500 个随机的（酶，底物）配对，确保不与现有正样本重复。

**脚本位置**（新建）：
`P450_EZSpecificity_研究项目/PathA_2026-01-08_模型评估测试集构建/scripts/PathA_路径1_随机配对验证/step0_generate_random_pairs.py`

**代码**：

```python
import pandas as pd
import random
import os

# 设置随机种子（保证可复现）
random.seed(42)

# 读取数据
base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data"
enzymes = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "Enzymes.csv"))
substrates = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "Substrates.csv"))
b3_data = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "B3_data.csv"))

# 提取正样本集合
positive_pairs = set(
    zip(b3_data[b3_data['Label'] == 1]['Enzyme Index'],
        b3_data[b3_data['Label'] == 1]['Substrate Index'])
)

print(f"正样本数: {len(positive_pairs)}")
print(f"酶总数: {len(enzymes)}")
print(f"底物总数: {len(substrates)}")

# 生成随机负样本
num_negatives = int(len(positive_pairs) * 9.36)  # 保持 1:9.36 比例
print(f"目标负样本数: {num_negatives}")

enzyme_indices = enzymes.index.tolist()
substrate_indices = substrates.index.tolist()

random_pairs = []
attempts = 0
max_attempts = num_negatives * 10  # 防止无限循环

while len(random_pairs) < num_negatives and attempts < max_attempts:
    e_idx = random.choice(enzyme_indices)
    s_idx = random.choice(substrate_indices)

    if (e_idx, s_idx) not in positive_pairs:
        random_pairs.append({
            'Dock Index': 1000 + len(random_pairs),  # 从 1000 开始编号，避免与现有冲突
            'Enzyme Index': e_idx,
            'Substrate Index': s_idx,
            'Label': 0
        })

    attempts += 1

if len(random_pairs) < num_negatives:
    print(f"警告：只生成了 {len(random_pairs)} 个负样本（目标 {num_negatives}）")

# 保存
output_dir = os.path.join(base_path, "PathA_路径1")
os.makedirs(output_dir, exist_ok=True)

random_df = pd.DataFrame(random_pairs)
random_df.to_csv(os.path.join(output_dir, "random_pairs.csv"), index=False)

print(f"已保存到: {os.path.join(output_dir, 'random_pairs.csv')}")
print(f"最终负样本数: {len(random_pairs)}")
```

## 三、准备受体（酶 PDB → PDBQT）

### 3.1 找到每个酶对应的 PDB 文件

**问题**：我们的数据里有 292 条酶序列（对应 148 个 UniProt），但每个 UniProt 可能对应多个 PDB。对接时，每个酶只需要选**一个代表性 PDB** 即可。

**策略**：
- 优先选择分辨率最高的 PDB
- 必须包含 HEM（heme 辅因子）

**脚本**：`step1_map_enzyme_to_pdb.py`

```python
import pandas as pd
import os
from Bio.PDB import PDBParser

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data"
pdb_dir = os.path.join(base_path, "01_Step1_PDB文件")

# 读取数据
enzymes = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "Enzymes.csv"))
b3_data = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "B3_data.csv"))
dock_mapping = pd.read_csv(os.path.join(base_path, "04_Step4_格式修正后数据", "dock_index_mapping.csv"))

# 合并数据，获取每个 Enzyme Index 对应的 PDB
merged = b3_data.merge(dock_mapping, on='Dock Index')
enzyme_to_pdb = merged.groupby('Enzyme Index')['pdb_id'].first().to_dict()

# 检查每个 PDB 是否有 HEM
parser = PDBParser(QUIET=True)

def has_heme(pdb_file):
    try:
        structure = parser.get_structure('protein', pdb_file)
        for model in structure:
            for chain in model:
                for residue in chain:
                    if residue.get_resname() == 'HEM':
                        return True
        return False
    except:
        return False

# 构建映射
enzyme_pdb_mapping = []
unique_enzymes = pd.read_csv(os.path.join(base_path, "PathA_路径1", "unique_enzymes.csv"))

for e_idx in unique_enzymes['Enzyme Index']:
    if e_idx in enzyme_to_pdb:
        pdb_id = enzyme_to_pdb[e_idx]
        pdb_file = os.path.join(pdb_dir, f"{pdb_id}.pdb")

        if os.path.exists(pdb_file):
            has_hem = has_heme(pdb_file)
            enzyme_pdb_mapping.append({
                'Enzyme Index': e_idx,
                'pdb_id': pdb_id,
                'pdb_file': pdb_file,
                'has_heme': has_hem
            })
        else:
            print(f"警告: 酶 {e_idx} 的 PDB 文件 {pdb_id}.pdb 不存在")
    else:
        print(f"警告: 酶 {e_idx} 没有对应的 PDB")

mapping_df = pd.DataFrame(enzyme_pdb_mapping)
mapping_df.to_csv(os.path.join(base_path, "PathA_路径1", "enzyme_pdb_mapping.csv"), index=False)

print(f"成功映射: {len(mapping_df)} 个酶")
print(f"含 HEM: {mapping_df['has_heme'].sum()} 个")
print(f"缺 HEM: {(~mapping_df['has_heme']).sum()} 个")
```

**运行后检查**：
- 打开 `data\PathA_路径1\enzyme_pdb_mapping.csv`
- 如果"缺 HEM"数量 > 0：**这些酶没法对接**，因为 P450 必须有 heme 才能定义对接中心

**如果缺 HEM 怎么办？**
1. 检查 PDB 文件是不是被错误下载了（有的 PDB 有 apo 结构和 holo 结构，我们要 holo）
2. 去 RCSB 重新下载，确保下载的是"含配体"的结构
3. 实在找不到：这些酶只能放弃，从随机配对中删掉

### 3.2 批量准备受体 PDBQT

**脚本**：`step1_prepare_receptors.py`

```python
import pandas as pd
import os
import subprocess
from pathlib import Path

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data\PathA_路径1"

# 读取映射
mapping = pd.read_csv(os.path.join(base_path, "enzyme_pdb_mapping.csv"))

# 只处理有 heme 的
mapping = mapping[mapping['has_heme'] == True]

# 创建输出目录
receptor_dir = os.path.join(base_path, "receptors")
os.makedirs(receptor_dir, exist_ok=True)

failed = []

for idx, row in mapping.iterrows():
    pdb_file = row['pdb_file']
    pdb_id = row['pdb_id']
    output_pdbqt = os.path.join(receptor_dir, f"{pdb_id}_receptor.pdbqt")

    # 使用 Meeko 准备受体
    cmd = [
        "python", "-m", "meeko.mk_prepare_receptor",
        "-i", pdb_file,
        "-o", output_pdbqt,
        "--keep_nonstandard_residues"  # 保留 HEM
    ]

    try:
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=60)

        if result.returncode == 0 and os.path.exists(output_pdbqt):
            print(f"✓ {pdb_id}")
        else:
            print(f"✗ {pdb_id}: {result.stderr}")
            failed.append(pdb_id)
    except Exception as e:
        print(f"✗ {pdb_id}: {e}")
        failed.append(pdb_id)

print(f"\n成功: {len(mapping) - len(failed)}/{len(mapping)}")
if failed:
    print(f"失败: {failed}")
    with open(os.path.join(base_path, "receptor_prep_failed.txt"), 'w') as f:
        f.write("\n".join(failed))
```

### 3.3 提取 Heme Fe 坐标

**为什么要提取？**
对接时需要指定"对接盒子"的中心坐标。P450 的对接中心就是 heme 铁原子（Fe）。

**脚本**：`step2_extract_heme_coords.py`

```python
import pandas as pd
import os
from Bio.PDB import PDBParser

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data\PathA_路径1"

mapping = pd.read_csv(os.path.join(base_path, "enzyme_pdb_mapping.csv"))
mapping = mapping[mapping['has_heme'] == True]

parser = PDBParser(QUIET=True)

heme_coords = []

for idx, row in mapping.iterrows():
    pdb_file = row['pdb_file']
    pdb_id = row['pdb_id']

    try:
        structure = parser.get_structure('protein', pdb_file)

        fe_coord = None
        for model in structure:
            for chain in model:
                for residue in chain:
                    if residue.get_resname() == 'HEM':
                        for atom in residue:
                            if atom.get_name() == 'FE':
                                fe_coord = atom.get_coord()
                                break
                    if fe_coord is not None:
                        break
                if fe_coord is not None:
                    break
            if fe_coord is not None:
                break

        if fe_coord is not None:
            heme_coords.append({
                'Enzyme Index': row['Enzyme Index'],
                'pdb_id': pdb_id,
                'fe_x': fe_coord[0],
                'fe_y': fe_coord[1],
                'fe_z': fe_coord[2]
            })
        else:
            print(f"警告: {pdb_id} 有 HEM 但找不到 FE 原子")

    except Exception as e:
        print(f"错误: {pdb_id}: {e}")

coords_df = pd.DataFrame(heme_coords)
coords_df.to_csv(os.path.join(base_path, "heme_coords.csv"), index=False)

print(f"成功提取: {len(coords_df)} 个酶的 Fe 坐标")
```

**运行后检查**：
打开 `data\PathA_路径1\heme_coords.csv`，应该看到每个酶的 Fe 坐标（x, y, z），数值通常在 -50 到 50 之间。

**如果坐标看起来很奇怪**（比如 x=500）：
- 可能 PDB 文件有问题
- 用 PyMOL 打开 PDB，输入命令：
  ```
  select heme, resn HEM
  select fe, name FE
  show spheres, fe
  ```
- 如果看不到 Fe 球体：说明这个 PDB 真的没有 Fe，放弃这个酶

### 4.2 批量生成配体 PDBQT

**脚本**：`step3_prepare_ligands.py`

```python
import pandas as pd
import os
from rdkit import Chem
from rdkit.Chem import AllChem
from meeko import MoleculePreparation

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data\PathA_路径1"

ligands = pd.read_csv(os.path.join(base_path, "ligand_smiles.csv"))

# 创建输出目录
ligand_dir = os.path.join(base_path, "ligands")
os.makedirs(ligand_dir, exist_ok=True)

failed = []

for idx, row in ligands.iterrows():
    s_idx = row['Substrate Index']
    smiles = row['Substrate_SMILES']
    output_pdbqt = os.path.join(ligand_dir, f"substrate_{s_idx}.pdbqt")

    try:
        # SMILES → RDKit Mol
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            raise ValueError("无效的 SMILES")

        mol = Chem.AddHs(mol)

        # 生成 3D 构象（ETKDG v3）
        params = AllChem.ETKDGv3()
        params.randomSeed = 42  # 保证可复现

        result = AllChem.EmbedMolecule(mol, params)
        if result == -1:
            raise ValueError("3D 嵌入失败")

        # 力场优化
        AllChem.MMFFOptimizeMolecule(mol, maxIters=500)

        # Mol → PDBQT
        preparator = MoleculePreparation()
        mol_setups = preparator.prepare(mol)

        pdbqt_string = mol_setups[0].write_pdbqt_string()

        with open(output_pdbqt, 'w') as f:
            f.write(pdbqt_string)

        print(f"✓ substrate_{s_idx}")

    except Exception as e:
        print(f"✗ substrate_{s_idx}: {e}")
        failed.append(s_idx)

print(f"\n成功: {len(ligands) - len(failed)}/{len(ligands)}")
if failed:
    print(f"失败: {failed}")
    with open(os.path.join(base_path, "ligand_prep_failed.txt"), 'w') as f:
        f.write("\n".join(map(str, failed)))
```

**运行**：
```powershell
python step3_prepare_ligands.py
```

**常见失败原因**：
1. **"3D 嵌入失败"**：
   - SMILES 有问题（比如包含无法生成 3D 的基团）
   - 分子太大或太复杂
   - 解决：用 Open Babel 试试

### 5.2 批量对接（并行版）

**脚本**：`step4_batch_docking.py`

```python
import pandas as pd
import subprocess
import os
from multiprocessing import Pool
from tqdm import tqdm

VINA_PATH = r"D:\autodock\vina.exe"

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data\PathA_路径1"

tasks = pd.read_csv(os.path.join(base_path, "docking_tasks.csv"))

def run_vina(row):
    """单个对接任务"""
    dock_idx = row['Dock Index']
    receptor = row['receptor_pdbqt']
    ligand = row['ligand_pdbqt']
    output = row['output_pdbqt']
    log_file = row['log_file']

    # 对接盒子中心（heme Fe 上方 3Å）
    center_x = row['fe_x']
    center_y = row['fe_y']
    center_z = row['fe_z'] + 3.0  # 铁上方 3Å

    cmd = [
        VINA_PATH,
        "--receptor", receptor,
        "--ligand", ligand,
        "--center_x", str(center_x),
        "--center_y", str(center_y),
        "--center_z", str(center_z),
        "--size_x", "20",
        "--size_y", "20",
        "--size_z", "20",
        "--exhaustiveness", "8",  # 默认值，平衡速度和精度
        "--out", output,
        "--log", log_file,
        "--cpu", "1"  # 每个 Vina 任务占用 1 核
    ]

    try:
        result = subprocess.run(
            cmd,
            capture_output=True,
            text=True,
            timeout=600  # 单个任务最多 10 分钟
        )

        if result.returncode == 0 and os.path.exists(output):
            # 提取打分
            with open(log_file, 'r') as f:
                log_content = f.read()
                if "VINA RESULT:" in log_content:
                    score_line = [l for l in log_content.split('\n') if 'VINA RESULT:' in l][0]
                    score = float(score_line.split()[3])
                    return dock_idx, "success", score

        return dock_idx, "failed", None

    except subprocess.TimeoutExpired:
        return dock_idx, "timeout", None
    except Exception as e:
        return dock_idx, f"error: {e}", None

# 并行执行
if __name__ == "__main__":
    num_cores = 16  # 根据你的 CPU 核心数调整

    print(f"开始对接 {len(tasks)} 个任务，使用 {num_cores} 核并行...")

    with Pool(processes=num_cores) as pool:
        results = list(tqdm(
            pool.imap(run_vina, [row for _, row in tasks.iterrows()]),
            total=len(tasks)
        ))

    # 统计结果
    results_df = pd.DataFrame(results, columns=['Dock Index', 'status', 'score'])
    results_df.to_csv(os.path.join(base_path, "docking_results.csv"), index=False)

    success = sum(1 for r in results if r[1] == "success")
    failed = sum(1 for r in results if r[1] == "failed")
    timeout = sum(1 for r in results if r[1] == "timeout")

    print(f"\n成功: {success}/{len(tasks)}")
    print(f"失败: {failed}")
    print(f"超时: {timeout}")

    if success > 0:
        scores = [r[2] for r in results if r[2] is not None]
        print(f"\n打分范围: {min(scores):.1f} ~ {max(scores):.1f} kcal/mol")
        print(f"平均打分: {sum(scores)/len(scores):.1f} kcal/mol")
```

**运行**：
```powershell

```

**预期过程**：

- 之后速度会稳定在每个任务 1-3 分钟
- 总耗时：2500 任务 ÷ 16 核 ≈ **5-6 小时**

def check_ligand_near_heme(docked_pdbqt, fe_x, fe_y, fe_z):
    """检查配体质心是否在 heme Fe 的 10Å 范围内"""
    try:
        # 读取 PDBQT（简化版：只取坐标行）
        coords = []
        with open(docked_pdbqt, 'r') as f:
            for line in f:
                if line.startswith("ATOM") or line.startswith("HETATM"):
                    x = float(line[30:38])
                    y = float(line[38:46])
                    z = float(line[46:54])
                    coords.append((x, y, z))

        if not coords:
            return False, 999

        # 计算质心
        centroid_x = sum(c[0] for c in coords) / len(coords)
        centroid_y = sum(c[1] for c in coords) / len(coords)
        centroid_z = sum(c[2] for c in coords) / len(coords)

        # 计算到 Fe 的距离
        dist = ((centroid_x - fe_x)**2 + (centroid_y - fe_y)**2 + (centroid_z - fe_z)**2)**0.5

        return dist < 10, dist

    except:
        return False, 999

near_heme = 0
far_from_heme = 0

for idx, row in merged[merged['status'] == 'success'].iterrows():
    is_near, dist = check_ligand_near_heme(
        row['output_pdbqt'],
        row['fe_x'], row['fe_y'], row['fe_z']
    )

    if is_near:
        near_heme += 1
    else:
        far_from_heme += 1

print(f"远离 heme (>10Å): {far_from_heme}")
print(f"比例: {near_heme/(near_heme+far_from_heme)*100:.1f}%")

if far_from_heme > 0.2 * (near_heme + far_from_heme):
    print("\n⚠️  警告：超过 20% 的配体远离 heme，对接质量差！")
    print("建议：增大 exhaustiveness（比如改成 16），重新对接失败的案例")

import os
import subprocess

base_path = r"C:\Users\Administrator\Desktop\EZSpecificity_Project\毕业设计\P450_EZSpecificity_研究项目\PathA_2026-01-08_模型评估测试集构建\data\PathA_路径1"

            f.write("END\n")

        os.remove(ligand_pdb_tmp)

        if idx % 100 == 0:
            print(f"已转换: {idx}/{len(successful)}")

    except Exception as e:
        print(f"✗ Dock {dock_idx}: {e}")

print(f"完成: {len(successful)} 个复合物")

## 八、常见问题与解决方案

### Q1: Vina 报错 "Could not open receptor"

**原因**：PDBQT 文件格式错误或路径有空格。

**解决**：
1. 打开 PDBQT 文件，检查第一行是不是 `REMARK`
2. 检查文件路径是否包含空格或中文，如果有，用引号括起来：
   ```python
   cmd = [VINA_PATH, "--receptor", f'"{receptor}"', ...]
   ```

---

### Q2: 对接打分全是正值

**原因**：
1. 受体或配体 PDBQT 没有电荷（partial charges）
2. 对接盒子设置错误，配体没进入蛋白

**解决**：
1. 检查 Meeko 准备时是否添加了 Gasteiger 电荷：
   ```python
   preparator = MoleculePreparation(add_charges=True)
   ```
2. 用 PyMOL 检查对接盒子是否覆盖 heme

---

### Q3: 很多任务超时

**原因**：exhaustiveness 太高或配体太复杂。

**解决**：
1. 降低 exhaustiveness（8 → 4）
2. 增加 timeout（600 → 1200 秒）
3. 对于超大配体（>50 个原子），单独处理

---

### Q4: Open Babel 转换后配体坐标错位

**原因**：PDBQT 格式与 PDB 格式的坐标列偏移不一致。

**解决**：
用 Meeko 的 Python API 直接读写：
```python
from meeko import PDBQTMolecule

pdbqt_mol = PDBQTMolecule.from_file(docked_pdbqt)
pdb_block = pdbqt_mol.export_pdb_string()
```

---

### Q5: PyMOL 显示配体在奇怪的位置

**原因**：对接失败，配体没有进入活性位点。

**解决**：
1. 检查 Vina log 文件，看 affinity（打分）
2. 如果 affinity > -5 kcal/mol，说明这个配对本身就不结合，属于正常
3. 如果很多配体都这样，检查对接盒子中心坐标是否正确
