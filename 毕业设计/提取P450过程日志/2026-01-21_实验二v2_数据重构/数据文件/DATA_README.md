## 排除详情

### 排除的非P450记录（58条）

**UniProt IDs**: W8SUA3, W8SY74

**蛋白质**: Photosystem I subunit VII (PsaC)

**PDB来源**: 6ZZX - 高等植物光系统I晶体结构

**配体类型**: 叶绿素、类胡萝卜素、膜脂质

**排除原因**:
- Photosystem I属于光合作用光系统复合体
- 完全不属于细胞色素P450酶家族
- 包含铁硫簇（[Fe-S] cluster），而非P450的血红素辅基
- 分类错误，不应纳入P450研究数据集

**详细记录**: 参见 `05_排除记录/非P450排除记录_58条_Photosystem_I.csv`

### 物种分布影响

58条Photosystem I记录**全部**位于 `other` 分类中：
- **other分类**: 174 → 116条（减少58条）
- **其他分类**: 无影响（bacteria, fungi, mammals, plants保持不变）
