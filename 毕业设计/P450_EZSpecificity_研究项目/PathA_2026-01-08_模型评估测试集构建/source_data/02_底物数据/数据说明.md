# 底物数据说明

> **数据来源**: `提取P450过程日志/2026-01-02_23-00_底物数据整合/`
> **用途**: ESIBank原始训练数据的底物反应信息（**仅供参考，不用于PathA独立测试集**）

---

## 文件列表

| 文件名 | 记录数 | 说明 |
|--------|--------|------|
| `P450酶底物反应详表_完整版.csv` | 12,329行 | 每行一个酶-底物对 |
| `P450酶底物反应详表_汇总版.csv` | 367行 | 每行一个P450酶（汇总） |

---

## 完整版字段说明

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `uniprot_id` | UniProt蛋白ID | A0A059WMF6 |
| `protein_families` | 蛋白家族 | Cytochrome P450 family |
| `ecnumber` | EC编号 | 1.14.14.150 |
| `substrate_smiles` | 底物SMILES结构 | C=C(C(=O)O)... |
| `label` | 正/负样本标签 | 1=正样本, 0=负样本 |
| `has_heme` | 是否含血红素 | True |
| `enzyme` | 酶编号(内部) | 5288 |
| `reaction` | 反应编号(内部) | 9441 |
| `difficulty` | 样本难度 | -1, 0, 1, 2, 3 |
| `sequence` | 蛋白序列 | MEPL... |

---

## 汇总版字段说明

| 字段名 | 说明 |
|--------|------|
| `uniprot_id` | UniProt蛋白ID |
| `positive_substrate_count` | 正样本底物数量 |
| `negative_substrate_count` | 负样本底物数量 |
| `total_pairs` | 总配对数 |
| `positive_substrates_smiles` | 所有正样本底物SMILES（用\|分隔） |
| `sample_positive_substrates` | 采样的正样本底物SMILES |

---

## 重要说明

1. **这些数据来自ESIBank训练集**，是EZSpecificity模型的训练数据
2. **不用于PathA独立测试集构建** - PathA使用的是`独立测试集_740条.csv`
3. 此数据仅供参考，用于理解ESIBank的底物-酶关系
