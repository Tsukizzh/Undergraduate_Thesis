## 摘要

本研究以 EZSpecificity（Nature 2025）为基础模型，系统性地评估并诊断了该模型在 P450 细胞色素酶家族上的预测能力。研究分为四条路径（Path A-D），目前已完成 Path A（模型评估）和 Path B Step 1-9（数据集构建、系统性诊断与训练准备）。

**核心发现**：

1. **Path A**：在 517 个独立 P450 测试样本上，模型 AUC-ROC = 0.6636，比论文最难场景（Unknown enzyme+substrate = 0.7198）低 5.6%，主因是负样本语义差异（抑制剂 vs 随机配对）和 0% 酶重叠。

2. **Path B**：将负样本替换为随机配对后，AUC 从预期的 0.72 暴跌至 **0.5170**（近乎随机猜测）。经 13 个诊断实验（E1-E8v2 + H1-H2）系统性定位根因：
   - 模型退化为**底物身份分类器**（R²(底物)=0.37，R²(酶)=-0.06，残差 AUC=0.509）
   - P450 是 7 个测试家族中**唯一崩溃**的家族（0.517 vs 次低 0.796）
   - 通道重要性呈**家族特异性**：P450 依赖结构通道，磷酸酶依赖序列通道
   - 在崩溃态（AUC≈0.5）下，所有通道消融效果均**不显著**——瓶颈在任务/数据设计
   - ESIBank P450 内部基准 AUC=0.638，难度匹配后与我们的 0.517 仅差 0.032

3. **Step 9**：发现论文原始代码存在**边特征对齐 Bug**（`complex_edge_attr` 与 `complex_edge_index` 顺序不匹配），已完成 AllSplit 训练的性能优化（1.71→4.3 it/s）和结构缓存方案设计。

**关键词**：酶-底物特异性、P450、SE(3)-等变 GNN、交叉注意力、消融实验、通道归因、家族内泛化失败

## 第一章 研究背景

### 1.1 EZSpecificity 模型概述

EZSpecificity 是一个基于交叉注意力机制的 SE(3)-等变图神经网络，用于预测酶-底物特异性（Nature 2025）。模型架构如下：

```
输入：酶序列 + 底物 SMILES + 对接复合物 PDB
       ↓
┌──────────────────────────────────────────────┐
│  特征提取                                      │
│  ├── ESM-2 嵌入（1280→128 维）  [序列通道]     │
│  ├── GROVER 嵌入（原子级+分子级） [分子通道]    │
│  ├── Morgan 指纹（1024-bit）     [分子通道]    │
│  └── 结构特征（口袋+配体 3D 坐标）[结构通道]    │
└──────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────┐
│  SE(3)-等变 GNN（EGNN, k=32, 3 layers）       │
│  └── 消息传递：原子坐标 + 边属性 → 更新嵌入    │
└──────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────┐
│  双向交叉注意力（8 heads）                      │
│  ├── enzyme_attention：酶查询底物               │
│  └── reaction_attention：底物查询酶             │
└──────────────────────────────────────────────┘
       ↓
  MLP → 二分类（特异性 / 非特异性）
```

**模型三通道**：
- **序列通道**：ESM-2 蛋白质语言模型提取的酶序列嵌入
- **分子通道**：Morgan 指纹 + GROVER 分子嵌入，表征底物化学结构
- **结构通道**：SE(3)-EGNN 处理的酶-底物对接复合物 3D 结构

### 1.2 ESIBank 训练数据集

ESIBank 是 EZSpecificity 的训练数据集，核心思路为"关系优先，结构其次"：

| 阶段 | 步骤 | 产出 |
|------|------|------|
| 数据收集 | BRENDA 酶-底物关系 → UniProt 序列匹配 → SMILES 标准化 | 25,225 个酶，56,597 个正样本 |
| 负样本生成 | 单向随机采样（固定底物，随机配对负酶），比例 1:9.36 | 529,918 个负样本 |
| 特征生成 | ESM-2 嵌入 + AlphaFold 预测结构 + AutoDock-GPU 对接 | 完整特征集 |

**训练集中 P450 的分布**：仅 389 个 P450 酶（占 25,225 个酶的 1.5%），是一个极少数族群。

**四折交叉验证场景**：

| 场景 | 酶重叠 | 底物重叠 | AUC-ROC |
|------|:------:|:-------:|:-------:|
| Random split | 有 | 有 | 0.8878 |
| Unknown enzyme | 无 | 有 | 0.7741 |
| Unknown substrate | 有 | 无 | 0.8003 |
| Unknown enzyme+substrate | 无 | 无 | 0.7198 |

### 1.3 P450 酶家族研究意义

细胞色素 P450（Cytochrome P450, CYP）是一类含血红素（Heme）的单加氧酶超家族，在药物代谢、生物合成和异源物质降解中发挥核心作用。P450 具有以下特殊性质：

1. **Heme 辅因子**：铁-卟啉（Fe-porphyrin）是催化核心，Fe 原子直接参与氧活化
2. **底物通道**：深而长的 access channel 决定底物选择性
3. **低杂泛性**：大多数 P450 仅催化少量特定底物（平均杂泛性 ≈1.2）
4. **序列多样性高**：不同 CYP 亚家族间序列相似度可低至 15-20%

### 1.4 研究问题与四路径规划

**核心问题**：EZSpecificity 在 P450 酶家族上的预测能力如何？如果表现不佳，根因是什么？如何改进？

| 路径 | 名称 | 目标 | 状态 |
|------|------|------|:----:|
| **A** | 模型评估测试集构建 | 用 PDB 实验结构评估模型 | ✅ 已完成 |
| **B** | P450 数据集构建与诊断 | 随机负样本 + 系统性根因诊断 | ✅ Step 1-9 |
| C | P450 专属模型训练 | 微调/从头训练 P450 模型 | 🔄 规划中 |
| D | 区域选择性预测 | 预测代谢位点 | ⏳ 待定 |

## 第二章 实验一：ESIBank 中 P450 酶的精确识别

### 2.1 实验目的

确定 ESIBank 训练数据中有多少个真正的 P450 酶，为后续数据泄露排除和内部基准测试提供基础。

### 2.2 问题发现：EC 号筛选的陷阱

**初始方法**：用 EC 号（1.14.14.*）筛选 P450。

**初始结果**：找到 4,121 个"P450"。

**抽样验证发现严重问题**：

```
验证案例：P07327
├── data.csv 中标记为：EC 1.14.14.126（P450 相关 EC 号）
├── UniProt 查询结果：
│   ├── 蛋白名：Alcohol dehydrogenase 1A（醇脱氢酶）
│   ├── 真实 EC：1.1.1.1（不是 1.14.14.126）
│   └── 辅因子：Zn²⁺（锌离子，不是 P450 特征的 Heme）
└── 结论：这根本不是 P450 酶
```

**根本原因**：EC 号分类的是**反应类型**，不是**酶的身份**。同一个酶可催化多种 EC 类别的反应，FAD 单加氧酶、黄素蛋白单加氧酶等都可能有 EC 1.14.14.* 编号。

### 2.3 实验方法：UniProt + InterPro 双重验证

**验证标准**：

| 层级 | 标准 | 说明 |
|------|------|------|
| 主标准 | InterPro 域包含 IPR001128（P450 核心域）或 IPR036396（P450 超家族） | 基于序列特征的蛋白质家族识别 |
| 备用标准 | UniProt `protein_families` 字段包含 "Cytochrome P450" | 数据库注释 |
| 排除条件 | 名称包含 "reductase" | P450 Reductase 是电子传递伙伴，不是 P450 |

**实现过程**：
1. 编写脚本调用 UniProt REST API，对 25,225 个酶进行批量查询（每批 150 个）
2. 使用 SQLite 缓存避免重复查询，支持断点续传
3. 解析返回的 JSON 数据，提取 `protein_families` 和 InterPro 域信息

### 2.4 实验结果

| 类别 | 数量 |
|------|:----:|
| P450 相关（protein_families 含 "P450"） | 410 |
| 其中 P450 Reductase（排除） | 21 |
| **真正的 P450 酶** | **389** |

**补充验证**：
- 随机抽样 100 个被排除酶 → 0 个含 P450 域（假阳性率 ≈0%）
- 额外 InterPro 检查（IPR002397/002403）→ 0 个遗漏
- Pfam PF00067 交叉验证 → 已识别 P450 中 99.7% 含 PF00067

### 2.5 实验结论

| 方法 | 识别数量 | 假阳性率 | 可靠性 |
|------|:-------:|:-------:|:------:|
| EC 号筛选 | 4,121 | ~90% | 不可用 |
| InterPro 验证 | **389** | ~0% | 可靠 |

**结论**：ESIBank 中真正的 P450 仅 **389 个**（占 25,225 个酶的 1.5%）。EC 号筛选的假阳性率高达 ~90%，不可用于 P450 识别。

**Step 8.1-8.2 是我们自己编写的**（论文不需要此步骤），因为：
- 论文训练数据使用 AutoDock 对接产出，已经是"口袋+配体"分离的复合物
- 我们的 PDB 晶体结构是完整蛋白质，需要自行提取口袋和对齐原子

**P450 特异性处理**：当配体有多个实例时，选择最接近 HEM 铁原子（FE）的配体。

#### 4.2.3 模型推理（Step 9-10）

使用模型：`best-checkpoint.ckpt`（random_split fold-0，训练集 AUC-ROC=0.8878）

| 指标 | 值 |
|------|---|
| 使用数据集 | B3 方案 |
| 有效样本 | 517 条（261 正 + 256 负） |
| 检查点场景 | random_split（非 unknown both） |

### 4.3 实验结果

| 指标 | 我们的 P450 | 论文 Unknown both |
|------|:----------:|:----------------:|
| **AUC-ROC** | **0.6636** | 0.7198 |
| AUC-PR | 0.6360 | — |
| Accuracy (阈值=0.5) | 0.5164 | — |
| Recall (阈值=0.5) | 0.0996 | — |
| 最优阈值 (Youden's J) | 0.0379 | — |

**与论文四种场景对比**：

| 场景 | 酶重叠 | AUC-ROC | 与我们的差距 |
|------|:------:|:-------:|:----------:|
| Random split | 有 | 0.8878 | -0.2242 |
| Unknown enzyme | 无 | 0.7741 | -0.1105 |
| Unknown substrate | 有 | 0.8003 | -0.1367 |
| Unknown enzyme+substrate | 无 | **0.7198** | **-0.0562** |
| **我们的 P450** | **0%** | **0.6636** | — |

### 4.4 根因分析（三因素）

| 根因 | 描述 | 贡献估计 |
|------|------|---------|
| **1. 酶重叠率 0%** | 148 个 P450 完全未出现在训练集中 | 基础性因素 |
| **2. 负样本定义不同** | 训练用随机配对（容易区分），我们用抑制剂（难区分） | 贡献 ~5-6% |
| **3. 结构信息差异** | Heme 被排除、晶体 vs 对接结构、口袋截断 | 叠加因素 |

**得分分布分析**：

| 指标 | 正样本 (261) | 负样本 (256) |
|------|:----------:|:----------:|
| 平均 logit | -2.99 | -5.05 |
| 范围 | -14.58 ~ +2.82 | -12.34 ~ +2.20 |
| 间距 | 2.06 logit（过小） | — |

**核心问题**：正负样本 logit 分布严重重叠（-7~-3 区间），约 39% 正样本与 82% 负样本落入重叠区。

### 4.5 Path A 结论

1. AUC-ROC = 0.6636 在预期范围内（比论文最难场景低 5.6%）
2. 差距主要来自任务定义不同（负样本语义差异）
3. 这不代表模型"失败"，而是评估任务与训练任务不同
4. **v2 预期**：改用随机配对负样本 → AUC ≈ 0.72 → 需 Path B 验证

```

             10Å        6Å
      ┌─────────┬─────────┐
无Heme│  EXP01  │  EXP03  │
      │  0.7115 │  0.6678 │
```

### 9.2 E1：标签语义探测

**问题**：EXP01 的 AUC=0.71 是因为模型学会了"结合亲和力"还是"化学指纹差异"？

**方法**：比较模型对抑制剂负样本 vs 随机负样本的 logit 分数。

**结果**：

| 指标 | 抑制剂负样本 | 随机负样本 |
|------|:----------:|:--------:|
| 平均 logit | **-5.25** | -3.28 |
| 标准差 | 3.93 | 3.15 |

化学相似度：底物 vs 抑制剂组间 Tanimoto = 0.084，KS 统计量 = 0.288（p < 1e-14）。

**结论**："结合亲和力假说"被否决。如果模型学的是"能结合=高分"，抑制剂应得更高分，但实际得到最低分（-5.25）。**EXP01 的 0.71 来自指纹分布差异（捷径学习）。**

### 9.3 E2：ESM 嵌入相似度分析

**问题**：P450 家族的 ESM-2 嵌入是否异常聚集？

**结果**：

| 家族 | 酶数 | 平均余弦相似度 | >0.90 比例 | PCA 90%维数 |
|------|:----:|:------------:|:---------:|:----------:|
| 糖基转移酶受体 | 55 | 0.981 | 100% | 10 |
| Duf | 161 | 0.981 | 100% | 17 |
| 硫解酶 | 73 | 0.980 | 99.8% | 16 |
| 腈水解酶 | 18 | 0.975 | 100% | 8 |
| 酯酶 | 146 | 0.950 | 98.2% | 38 |
| 磷酸酶 | 218 | 0.946 | 96.8% | 39 |
| **P450** | **292** | **0.935** | **82.4%** | **15** |

**结论**：P450 实际是 7 个家族中相似度**最低**的（0.935）。ESM-2 各向异性（1280 维中仅约 15 维有效）是全局特性，非 P450 特有。**ESM 压缩是加重因素，但不是 P450 崩溃的特异原因。**

### 9.4 E3：逐底物 AUC 分析

**问题**：AUC=0.52 是 213 个底物均匀失败，还是少数底物拉低？

**结果**（筛选条件：≥1 正 + ≥5 负，共 213 个底物）：

| 区间 | 底物数 | 比例 |
|------|:-----:|:----:|
| AUC > 0.75（表现好） | 65 | 30% |
| AUC < 0.35（完全反向） | 57 | 27% |
| 标准差 | — | 0.317 |

**结论**：失败高度不均匀。根源是模型给不同底物打了不同的固定基线分——**底物身份决定了分数，而非酶-底物交互。**

### 9.5 E4：分数分解（核心实验）

**问题**：模型分数中，酶信息、底物信息、酶-底物交互信息各贡献多少？

**方法**：Leave-One-Out (LOO) 分解，将模型分数拆解为底物偏置、酶偏置、残差（交互项）。

**结果**：

| 成分 | R² | AUC |
|------|:--:|:---:|
| 仅用酶偏置 | **-0.06** | 0.530 |
| 仅用底物偏置 | **0.37** | 0.498 |
| 两者相加 | 0.32 | 0.522 |
| **残差（交互项）** | — | **0.509** |

**E4 核心结论**：
- 底物身份解释 37% 的分数变化（R²=0.37）
- 酶身份贡献为负（R²=-0.06，比用均值猜还差）
- 去掉两者后残差 AUC = 0.509 → 交互信号为零
- **模型完全退化为"底物身份分类器"**：忽略酶的存在，仅根据底物分配固定分数

### 9.6 E5：指纹分类器基线

**问题**：底物化学特征（Morgan 指纹）能否直接预测标签？

**方法**：1024-bit Morgan 指纹 + LR/RF 分类器，StratifiedGroupKFold（按底物分组，杜绝泄漏）。

| 分类器 | CV 方式 | AUC-ROC |
|--------|--------|:-------:|
| LR | GroupKFold | **0.503** |
| RF | GroupKFold | **0.504** |

**结论**：Direction A 采样下（固定底物、换酶），底物指纹对分类毫无帮助。底物信息不是通过化学指纹直接区分标签，而是通过模型的固定底物偏置间接决定分数。

#### 7 家族 AUC 排名

| 4 | 磷酸酶 | 32.9 | 0.877 | in-dist |

**P450 是唯一崩溃的家族。** 第二低的 Duf（0.796）仍远高于 P450（0.517），差距达 0.279。

#### 杂泛性-AUC 相关性

### 10.2 通道关闭技术

**关闭方法**：在 Linear 投影层**之后**将 128 维输出清零。

```
原因: 输出 = 权重 × 输入 + 偏置
     若在输入端清零，偏置仍存在，无法真正静默通道
     在输出端清零 → 完全静默
```

当酶序列或底物分子+结构通道被完全关闭时，交叉注意力输出也同步清零。

## 第十一章 实验十：假说验证（H1 + H2）

### 11.1 假说 1：负样本难度不匹配 — ✅ 已确认

**核心问题**：ESIBank P450 的 AUC=0.638 是否被简单负样本（EC 号距离远的酶）拉高？

**方法**：对 E7 的 1,359 条预测按 `difficulty`（EC 号匹配深度）分层计算 AUC。

| 难度 | 含义 | 负样本数 | AUC |
|:---:|------|:------:|:---:|
| 0 | 完全随机 | 306 | 0.731 |
| 1 | 同 EC 第 1 位 | 297 | 0.657 |
| 2 | 同 EC 前 2 位 | 297 | 0.629 |
| **3** | **同 EC 前 3 位** | **278** | **0.540** |
| **≥3** | **难度匹配区间** | **~353** | **0.549** |

```
ESIBank P450 混合难度:  AUC = 0.638
          ↓ 仅保留难度 ≥ 3
ESIBank P450 难度匹配:  AUC = 0.549
我们的 P450 (≈全部难度3): AUC = 0.517
                                ↓
                        剩余差距仅 0.032
              可被酶泄漏(100% vs 0%) + 结构来源(AlphaFold vs Vina) 解释
```

**结论**：ESIBank P450 负样本中约 48% 属于难度 0-1（容易区分），这些简单负样本将整体 AUC 从 0.549 拉高至 0.638。排除后，两个数据集的差距从 0.121 缩小至 0.032。

### 11.2 假说 2：训练/测试场景不匹配 — ✅ 部分确认

| 维度 | 发现 |
|------|------|
| 公开检查点 | 仅有 `random_split` 场景（4 折 × 1 模型） |
| 我们的测试场景 | `unknown both`（最难场景） |
| Google Drive 数据 | 有 4 种分割数据，但无对应训练好的模型 |
| 从头训练成本 | 65GB 数据 + 单卡 2-4 周 |

**结论**：场景不匹配是叠加因素（解释 0.549→0.517 的 0.032 差距）。进入 Step 9 从头训练 AllSplit 模型。

### 11.3 两个假说的关系

```
0.638 (ESIBank P450 整体)
  ↓ 假说1: 排除简单负样本
0.549 (ESIBank P450 难度≥3)    ← ΔAUC = 0.089 (主因)
  ↓ 假说2: 场景不匹配 + 酶泄漏 + 结构来源
0.517 (我们的 P450)            ← ΔAUC = 0.032 (叠加因素)
```

### 12.6 重大发现：论文原始代码边特征对齐 Bug

**经 Codex 4 轮深度验证确认**，`src/Datasets/Structure/transforms.py` 的 `EdgeConnection.__call__` 中存在**边属性与边索引顺序不匹配 Bug**：

```python
# 属性顺序
complex_edge_attr = cat([knn边属性, 真实键边属性])    # [knn, real]

# 索引顺序
complex_edge_index = cat([真实键边索引, knn边索引])    # [real, knn]

# → 边 i 的属性不对应边 i 的索引！
```

**后果**（严重程度：高）：
- 真实化学键（单键/双键/芳香键）丢失键类型身份，被分配 knn 的 type-5 属性
- 真实键距离（~1-2Å）被替换为随机 knn 距离
- 交叉边标志（cross_bond）被污染
- 典型样本中 Ek >> Er（k-NN k=48 生成的边远多于化学键），大多数边被错配
- EGNN 注意力门控使用被污染的消息，进一步放大错误

**模型为何仍能工作**：通过下调/抑制结构分支来"补偿" Bug，非图通道（ESM、GROVER、Morgan）提供主要信号。

**与 Step 8 诊断的关系**：这可能**解释了 E8v2 中结构通道变化不显著的现象**——结构通道从一开始就在被错误数据训练，模型学会了忽略/抑制它。

**修复方案**：
- **Option A（复现 Bug）**：安全，与论文可比
- **Option B（修复 Bug）**：结构模块可正确学习 ← **主训练方案**
- 分区缓存设计，一次构建同时支持两种模式

**创新价值**：发现并修复论文原始代码中的架构级 Bug，可作为毕业设计创新贡献点。

### 14.1 已发现的创新点

| # | 创新点 | 解决的失败模式 | 难度 | 优先级 |
|---|--------|--------------|:----:|:-----:|
| 1 | 硬负样本重构（同 EC 前 3 位） | 底物身份捷径 + 难度不匹配 | 中 | **高** |
| 2 | 对比学习检索范式（CLIP-style, InfoNCE） | 二分类退化 + 坐标噪声 | 中 | **高** |
| 3 | 反平衡批次设计（Anti-Shortcut Batching） | R²(底物)=0.37 捷径 | 低-中 | **高** |
| 4 | Heme 中心口袋/通道编码器 | 结构信号稀释 | 中 | 中 |
| 5 | 蛋白质原子词汇表加入 Fe | Heme Fe OOD (主效应 -0.2322) | **低** | 中 |
| 6 | 酶原子级结构特征聚合（scatter_mean） | 架构不对称 | 低-中 | 中 |
| 7 | 边特征对齐 Bug 修复 | 结构通道被抑制 | **低** | **高** |

### 14.2 重点创新详解

#### 创新 1：硬负样本重构

**问题**：ESIBank 训练集用 EC 层级混合难度负样本（0-5），我们的 P450 测试全部 ≈ 难度 3。H1 已证明难度 0-1 的简单负样本将 AUC 从 0.549 拉高至 0.638。

**方案**：重构负样本，使训练时正确匹配难度分布。对 P450，负样本酶应来自同 EC 前 3 位（同亚家族）。

**参考**：EnzymeCAGE (Nat Catal 2026) 使用类似的硬负样本策略。

#### 创新 7：边特征对齐 Bug 修复

**问题**：`transforms.py:130-147` 中 `complex_edge_attr`=[knn, real] 而 `complex_edge_index`=[real, knn]，导致边 i 的属性不对应边 i 的索引。

**修复**：分区存储 real/knn 边，运行时按正确顺序组装。代码改动量小，但需重新训练。

**影响**：修复后 SE(3)-EGNN 结构模块可正确学习边-属性对应关系，预期结构通道贡献显著提升。

## 第十五章 Path C 规划：P450 专属微调

### 15.1 总体方向

```
起点: random_split 或 all_split 检查点
核心: 修复任务/数据设计 → 小规模 pilot → 全量微调
验证: 用 E4 分数分解 + E8 通道消融验证改进效果
```

### 15.2 具体规划

| 步骤 | 内容 | 优先级 |
|------|------|:-----:|
| C1 | 构建合理负样本（Direction A+B 混合，匹配难度） | **高** |
| C2 | 小规模 pilot：对比 SEQ-only / SEQ+MOL / SEQ+STR | **高** |
| C3 | 全量微调（基于 pilot 确定的最优配置） | 高 |
| C4 | 验证：E4 分数分解 + E8 通道消融 + 7 家族对比 | 高 |

### 15.3 通道配置选择依据（综合 E8v1 + E8v2）

- E8v2 核心发现：崩溃态下所有通道效果不显著，E8v1"结构通道最关键"不可直接推广
- 仅序列在 E8v2 有最高点估计（AUC=0.550），虽不显著，但作为探索性暗示
- 分子通道优先级最低（E8v1 和 E8v2 一致）
- 结构通道在修复边排序 Bug 后可能恢复作用，值得 pilot 验证

### 15.4 论文参考：HaloS 卤化酶 Benchmark

| 方法 | AUC-ROC |
|------|:-------:|
| 从头训练（~3,300 对） | 0.87 |
| ESIBank 预训练 → 微调 | 0.80 |
| 直接用预训练模型 | 0.77 |
| CPI（无结构通道） | 0.57 |

卤化酶 CPI（0.57）> 我们 P450（0.517），但卤化酶有 4 个亚类（亚类间序列相似度仅 0.13），序列/分子通道仍有弱信号。**卤化酶 benchmark 支持微调路线。**
