# Q12 — 负样本杂泛性核验

## 老师原话

> 查验负样本中，该底物是否真的不会被该酶催化（由于 P450 的杂泛性，我们的正样本数也许会更多）

## 状态

🔴 **待启动**

## 背景

### 当前负样本生成机制（沿用 EZSpecificity 论文）
- **方法**：单向随机采样（仅采样负酶，保持底物不变）
- **正负比**：1 : 9.36（论文）/ 1 : 9.9（我们 P450 数据）
- **理由**：避免采样到真实正样本对（一个底物可能被多个酶催化）

### 老师指出的问题：P450 的杂泛性
- P450 超家族高度杂泛（promiscuity）：单个 P450 可能催化几十种结构相似底物
- **风险**：当前"随机配的负酶 + 正底物"中，可能有相当比例**实际是正样本但被标记为负**
- **影响**：
  - 拉低模型上限（学不到的"正样本"反向训练）
  - 评估指标偏低（真阳被算成假阳）
  - 训练梯度污染

## 验证策略候选

### Plan A — 文献查证（高成本，最准）
- 对所有 47,503 负样本对查 BRENDA / UniProt / PubMed 是否有催化报道
- 多智能体协作（沿用 PathC 框架）

### Plan B — 分子相似度过滤（快速，启发式）
- 对每条负样本对 (E, S_neg)：
  - 取酶 E 在正样本中的所有真实底物 {S_pos_1, S_pos_2, ...}
  - 计算 S_neg 与每个 S_pos 的 Tanimoto 相似度（Morgan FP 1024-bit）
  - 若 max(Tanimoto) > 阈值（如 0.7）→ 嫌疑负样本
- 输出嫌疑列表，进入 Plan C 复核

### Plan C — Top-N 高嫌疑人工/智能体核验
- Plan B 输出的高嫌疑负样本，调多智能体复核
- 可疑确认 → 改标 / 删除

### Plan D（综合，推荐）
1. **Step 1**：Plan B 跑全量 47,503 → 得到嫌疑分级（low / medium / high）
2. **Step 2**：medium + high 进入 Plan C
3. **Step 3**：根据核验结果重新构造负样本集（剔除 + 重新采样补足）
