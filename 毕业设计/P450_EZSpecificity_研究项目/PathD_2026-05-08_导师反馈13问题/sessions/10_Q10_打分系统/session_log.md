## 待澄清点

1. 老师指 (a)/(b)/(c)/(d)/(e) 哪种？
2. **打分对象**：单对（酶+底物）还是批量（一个酶 vs 一组底物）？
3. **是否需要解释性输出**？
   - attention 权重热图（哪个残基 - 哪个原子最关键）
   - SHAP / Integrated Gradients
   - 结合姿态 PyMOL 展示
4. **输入门槛**：用户是给序列+SMILES？还是给 PDB+SDF？
   - 后者要求他们自己跑对接
   - 前者要内置对接流水线（增加部署复杂度）

## 候选架构（如选 c + e）

```
前端：React + Plotly + 3D 分子查看器（NGL Viewer）
   ↓
后端：FastAPI
   ├→ Stage 1：酶 → 类别先验（快速）
   ├→ Stage 2：酶 + 底物 → 特异性分数（重）
   └→ 对接：Uni-Dock（如用户未提供 PDB）
   ↓
数据库：PostgreSQL（数据查询）+ Redis（缓存）
   ↓
GPU 服务：单卡 4090 推理（部署在实验室服务器）
```
