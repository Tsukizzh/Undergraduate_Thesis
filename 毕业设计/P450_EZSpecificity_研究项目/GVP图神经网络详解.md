## 一、为什么要引入 GVP？原模型的 EGNN 有什么问题

### 1.1 EGNN 的"盲区"

回忆一下原模型的结构通道：**用 EGNN 处理对接复合物的原子图**。EGNN 的优点是简单、快、对旋转不敏感（旋转整个分子，预测结果不变）。但它有一个根本性的**盲区**——它只看距离，不看方向。

```
假设有一个氨基酸残基 A，周围有两个氧原子 B 和 C。
它们到 A 的距离都是 2.8Å。

                B  (距离 2.8Å)
               /
              /
            A
              \
               \
                C  (距离 2.8Å)

在 EGNN 看来，B 和 C 对 A 的作用是一样的——都是距离 2.8Å 的氧原子。
但实际上，B 可能在 A 的"正上方"，C 可能在 A 的"正下方"。
这个方向差异，在化学上往往决定了反应能不能发生。

EGNN 看不到这个差异。
```

### 1.2 P450 催化为什么对方向敏感

P450 酶催化反应时，底物必须以**特定朝向**进入活性口袋：

```
  有效配位（能催化）：                 无效配位（不能催化）：

       底物                                     底物
        │（C-H 键朝向 Fe）                     （C-H 键背向 Fe）
        ▼                                       ▲
     Fe = O                                  Fe = O

  C-H 键朝 Fe→O 伸出去                    C-H 键朝远离 Fe 的方向
  距离合适、方向合适 → 氧化反应能发生        即使距离再近，反应也发生不了
```

EGNN 只能回答"距离 Fe 多少埃"，回答不了"朝向对不对"。这是为什么我们想试试 GVP——**它能同时表达距离和方向**。

### 1.3 想法的来源：EnzymeCAGE 论文

Nature Catalysis 2026 的 EnzymeCAGE 论文里用了 GVP 替代 EGNN 来编码蛋白质口袋，在 P450 等家族上报告了显著提升。我们 EXP005 把它的 GVP 模块移植过来，作为一条**新增的通路**（不替换原 EGNN，而是并行）。

## 二、先理解两种特征：标量 vs 向量

GVP 的核心创新是同时处理两种类型的特征。先看清楚它们的区别。

### 2.1 什么是"标量特征"

**标量**就是一个普通的数字，没有方向，没有坐标系概念。

```
例子：
  原子 A 的原子量 = 16（氧）      ← 标量
  键长 = 1.5Å                   ← 标量
  二面角 φ = 60°                ← 标量
  温度 = 25℃                    ← 标量

EGNN 里的节点特征向量 [0.3, 1.2, -0.5, ..., 0.8]  ← 128 个标量拼成的向量
```

标量的一个关键性质：**旋转坐标系时不变**。

```
不管你把整个分子转到哪个角度，温度还是 25℃，
键长还是 1.5Å，二面角也还是 60°。
```

### 2.2 什么是"向量特征"

**向量**是带方向的量，通常用 3 个数字 (x, y, z) 表示它在 3D 空间中的朝向。

```
例子：
  键的方向：从 C 原子指向 O 原子的单位向量 (0.5, 0.7, 0.5)
  侧链朝向：从 Cα 指向 Cβ 的单位向量 (0.3, 0.1, 0.9)
  速度：(3.0, 0.0, 1.5) m/s

表示法：v = (vx, vy, vz)，总是 3 个数字一组。
```

向量的一个关键性质：**旋转坐标系时，它跟着转**。

```
如果把整个分子绕 z 轴旋转 90°：
  原本指向 (1, 0, 0) 的向量，现在指向 (0, 1, 0)
  数值变了，但它"相对于分子结构的位置"没变
```

### 2.3 关键区别对照

| 属性 | 标量 | 向量 |
|---|---|---|
| 数值形式 | 1 个数字 | 3 个数字 (x, y, z) |
| 旋转坐标系 | 数值不变 | 数值跟着转 |
| 能表达 | 大小、程度 | 大小 + 方向 |
| 化学信息例 | 键长、二面角、温度 | 键的朝向、侧链朝向、原子间相对位置 |

### 2.4 GVP 同时处理这两种

GVP 层的输入不是一个向量，而是一个**元组 (s, V)**：

```
  s：标量部分，128 维普通向量（128 个标量）
  V：向量部分，若干个 3D 向量（比如 16 × 3 = 16 个 3D 向量）

  写成代码里的张量形状就是：
    s.shape = (128,)
    V.shape = (16, 3)     ← 16 个向量，每个占 3 个坐标
```

之所以要设计这种元组形式，是因为要分别对待这两种特征——对标量做什么都行，对向量只能做"保持旋转等变的操作"。

## 三、两个性质：SE(3) 不变 vs SE(3) 等变

这是理解 GVP 为什么和 EGNN 不同的关键。听起来吓人，但其实很简单。

### 3.1 SE(3) 不变（EGNN 的性质）

**定义**：不管你把整个分子怎么旋转或平移，模型的输出都不变。

```
原始分子：
     O
     ║
     C ─ N
    /
   H

模型输出：logits = 0.83

旋转 90° 后：
     H
      \
       C ═ O
       │
       N

模型输出：logits = 0.83 （一模一样）
```

**为什么有这个性质**：EGNN 只用距离（标量）做计算。距离是旋转不变的——不管怎么转，C-O 之间的距离永远是 1.2Å。所以最终输出也不变。

### 3.2 SE(3) 等变（GVP 的性质）

**定义**：如果你旋转输入，输出也跟着旋转相同的角度；但如果输出是标量，就不变。

```
原始输入的某个向量：v = (1, 0, 0)（指向正 x 方向）
通过 GVP 处理后：  v' = (0.5, 0.7, 0.1) （某个新方向）

现在把整个输入旋转 90°（绕 z 轴）：
原始 v = (1, 0, 0)  被旋转为  v_rotated = (0, 1, 0)（指向正 y 方向）

这时 GVP 处理 v_rotated 后输出的向量：
v'_rotated = (−0.7, 0.5, 0.1)

关键：v'_rotated 正好是 v' 旋转 90° 后的结果！
```

换句话说，**旋转操作可以和 GVP 操作交换顺序**：先转再算，和先算再转，结果一样。

### 3.3 为什么等变比不变"更强"

```
  ┌────────────────────────────────────────────────────────┐
  │  SE(3) 不变 (EGNN)                                      │
  │  只能输出标量结果（数字，没有方向）                       │
  │  失去的信息：方向性                                     │
  │                                                        │
  │  例如 EGNN 只能告诉你 "原子 A 受到邻居 3.2 单位的影响"    │
  │  告诉不了你 "影响来自哪个方向"                           │
  └────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────┐
  │  SE(3) 等变 (GVP)                                       │
  │  可以输出标量 + 向量                                    │
  │  标量部分：方向无关的信息（强度、大小）                   │
  │  向量部分：方向相关的信息（朝向、位置关系）               │
  │                                                        │
  │  例如 GVP 可以告诉你：                                   │
  │    "原子 A 受到 3.2 单位的影响（标量），                │
  │     影响来自 (0.3, 0.1, 0.9) 这个方向（向量）"          │
  └────────────────────────────────────────────────────────┘
```

一句话：EGNN 是"没有方向感的神经网络"，GVP 是"有方向感的神经网络"。

## 四、GVP 需要什么输入

### 4.1 和 EGNN 的建图粒度对比

```
EGNN 的建图（原模型）：
  节点 = 原子（底物 + 口袋所有原子，通常 100~200 个）
  粒度细，信息多

GVP 的建图（EXP005 新增）：
  节点 = 残基（口袋的氨基酸残基，通常 30~50 个）
  粒度粗，信息少但带方向
```

GVP 把节点粒度降到残基级（1 个残基 = 1 个节点，哪怕这个残基有 10 个原子），这样可以利用"这个残基朝哪个方向"这种只在残基层面才有意义的信息。

### 4.2 每个残基的节点特征：4 样东西

对于口袋里的每个残基，GVP 需要以下特征：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  一个残基的初始特征 = (标量部分, 向量部分)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  标量部分 node_s [6 维]：
    φ 二面角的 sin 和 cos (2 个标量)
    ψ 二面角的 sin 和 cos (2 个标量)
    ω 二面角的 sin 和 cos (2 个标量)

  向量部分 node_v [3 × 3]：
    Cα → N  方向的单位向量 (3 个坐标)
    Cα → C  方向的单位向量 (3 个坐标)
    Cα → Cβ 方向的单位向量 (3 个坐标)

  (可选) 氨基酸类型 one-hot：20 维
    ALA, CYS, ..., TYR
```

### 4.3 为什么这 4 样东西能完整描述一个残基的方向

回忆一下生物化学：一个残基在 3D 空间中的姿态完全由以下两组信息决定：

```
  ① 骨架走向：
     Cα 是氨基酸的中心碳原子
     Cα → N 告诉你残基的 N 端朝哪
     Cα → C 告诉你残基的 C 端朝哪
     (这两个方向定义了蛋白质骨架的局部弯曲)

  ② 侧链朝向：
     Cα → Cβ 告诉你侧链伸向哪里
     (侧链是决定氨基酸功能的关键)

  ③ 二面角：
     φ, ψ 是骨架的主要二面角
     ω 描述肽键的扭转
     (这些角度捕捉蛋白质骨架的折叠模式)
```

有了这些特征，模型就能区分"A 在 B 的上方"和"A 在 B 的下方"这类 EGNN 区分不了的情况。

### 4.4 残基间的边特征

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  边 i→j 的特征 = (标量部分, 向量部分)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  标量部分 edge_s [32 维]：
    Cα_i 和 Cα_j 之间的距离，经 RBF（径向基函数）展开为 32 维

    RBF 是什么？
      不直接用原始距离 d（一个数字），而是把 d 展开成 32 个参考点的相似度：
      [exp(-(d-2)²), exp(-(d-4)²), exp(-(d-6)²), ..., exp(-(d-16)²)]
      让模型更容易学到 "近距离" vs "中距离" vs "远距离" 的差异

  向量部分 edge_v [1 × 3]：
    Cα_i → Cα_j 的单位方向向量（3 个坐标）
```

### 4.5 建图规则

```
  节点：口袋里的每个残基（约 30~50 个）

  边：每个残基连接最近的 30 个邻居残基（kNN，k=30）
     衡量距离用 Cα-Cα 距离

  边方向：有向图，i→j 和 j→i 是两条不同的边
         （但在 GVPConv 里两个方向都会算，等价于无向图）
```

## 五、GVP 基本单元：一个 GVP 层内部怎么工作

这是整个 GVP 网络最核心的组件。一个"GVP 层"就是一个小神经网络，输入 (标量, 向量) 元组，输出 (标量, 向量) 元组。

### 5.1 GVP 层要做的事

```
  输入：(s_in, V_in)
    s_in：输入标量特征，维度 [n_s_in]       (比如 128)
    V_in：输入向量特征，维度 [n_v_in, 3]    (比如 16 个 3D 向量)

  输出：(s_out, V_out)
    s_out：输出标量特征，维度 [n_s_out]     (比如 128)
    V_out：输出向量特征，维度 [n_v_out, 3]  (比如 16 个 3D 向量)

  约束：整个过程必须 SE(3) 等变
    即：旋转输入的向量部分 → 输出的向量部分跟着旋转，标量部分不变
```

怎么做到？分 4 步。

### 5.2 步骤 1：向量降维（保持方向）

向量部分 V_in 有 n_v_in 个 3D 向量，我们需要把它"降维"到 n_h 个 3D 向量（n_h 通常小于 n_v_in）。

但是——**不能直接用普通线性层处理向量部分**！因为普通线性层会把 (x, y, z) 当成三个独立的标量处理，破坏 SE(3) 等变性。

GVP 的做法是用一个**特殊的向量线性层**：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  向量线性层的计算：V_h = W_h × V_in
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  V_in 形状：[n_v_in, 3]     比如 [16, 3]
  W_h 形状：[n_h, n_v_in]    比如 [8, 16]
  V_h 形状：[n_h, 3]         比如 [8, 3]

  这个矩阵乘法只在"向量通道维度"（16→8）上进行，
  不碰"坐标维度"（3）。

  效果：每个输出向量都是所有输入向量的线性组合。
       比如 V_h[0] = 0.3 × V_in[0] + 0.7 × V_in[1] - 0.2 × V_in[2] + ...
       这些线性组合**整体上会跟着旋转**，所以保持等变性。
```

举个具体例子：

```
假设输入有 2 个 3D 向量：
  V_in = [ [1.0, 0.0, 0.0],     ← 第 1 个向量
           [0.0, 1.0, 0.0] ]    ← 第 2 个向量

W_h = [ [0.5, 0.5] ]    ← 1 × 2 矩阵，输出 1 个向量

V_h = W_h × V_in
    = [ [0.5 × 1.0 + 0.5 × 0.0,
         0.5 × 0.0 + 0.5 × 1.0,
         0.5 × 0.0 + 0.5 × 0.0] ]
    = [ [0.5, 0.5, 0.0] ]    ← 输出 1 个向量

效果：输出向量是两个输入向量的"平均方向"
```

### 5.3 步骤 2：计算向量范数（把向量信息传给标量）

这是 GVP 最巧妙的地方。向量是有方向的，但我们可以算它的"长度"——这个长度**是标量**（旋转不变）。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  从 V_h 计算范数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  对每个 3D 向量算 L2 范数（欧氏长度）：
    ||v|| = sqrt(vx² + vy² + vz²)

  比如 V_h = [ [0.5, 0.5, 0.0],       → ||v₁|| = 0.707
               [0.3, 0.0, 0.8] ]      → ||v₂|| = 0.855

  得到 v_norms = [0.707, 0.855]  ← n_h 个标量
```

**为什么要算这个？**
- 向量的长度告诉我们"这个方向有多重要"
- 比如一个方向向量长度接近 1，说明这个方向强；接近 0，说明这个方向弱
- 把长度作为**额外的标量信息**，给下一步用

### 5.4 步骤 3：标量处理（吸收向量的长度信息）

现在把原本的标量 s_in 和新计算出的向量范数 v_norms **拼接**，再经过普通线性层：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  标量分支
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  s_in         [128]        ← 原始标量
  v_norms      [n_h]        ← 向量范数（比如 16）
       │
       ▼
  拼接 [128 + 16] = [144]
       │
       ▼
  ┌───────────────────────────┐
  │  普通线性层                │
  │  W_s: [n_s_out, 144]      │
  │  b_s: [n_s_out]           │
  └───────────┬───────────────┘
              │
              ▼
      激活函数（ReLU 或其他）
              │
              ▼
         s_out  [n_s_out]
```

这一步的意义：**标量部分"吸收"了向量部分的长度信息**。换句话说，标量现在不仅知道自己以前的值，还知道"那些方向向量的强度分布"。

### 5.5 步骤 4：标量缩放向量（向量的门控）

反过来，我们也让**标量来影响向量**——但只能影响向量的"强度"，不能改变方向。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  向量分支
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  V_h         [n_h, 3]       ← 降维后的向量
       │
       │   基于 s_out 计算"缩放因子"
       │
       ▼
  ┌────────────────────────────────┐
  │  Linear(s_out, n_v_out)        │  取 s_out 的一部分
  │  → gate [n_v_out]              │
  │  → sigmoid(gate) → 每个分量 ∈ [0,1]
  └────────────┬───────────────────┘
               │
               │  另外做一次向量线性层把 n_h 降到 n_v_out
               ▼
  V_降维 = W_2 × V_h     [n_v_out, 3]
               │
               ▼
       按元素相乘：
       V_out[i] = gate[i] × V_降维[i]    (第 i 个向量整体乘以 gate[i])

  最终 V_out 形状 [n_v_out, 3]
```

**关键**：缩放因子是标量（sigmoid 出来的 0~1），对每个向量做整体缩放。这**不改变方向**（向量还是原来的方向），只改变长度。所以 SE(3) 等变性保持。

### 5.6 一个 GVP 层的完整图

把 4 步合起来：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  一个 GVP 层完整流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  输入：(s_in, V_in)，s_in [128]，V_in [16, 3]

       ┌────────────────────────┬────────────────────────┐
       │    标量分支             │     向量分支            │
       │                        │                        │
       │                        │  步骤 1：向量降维         │
       │                        │    V_h = W_h × V_in    │
       │                        │    V_h [16, 3]         │
       │                        │       │                │
       │                        │       ▼                │
       │                        │  步骤 2：算向量范数      │
       │                        │    v_norms [16]        │
       │                        │       │                │
       │   ◄────────────────────┘     (范数传给标量)     │
       │                               │                │
       │  步骤 3：标量 + 范数 → 线性层   │                │
       │    拼接 [128+16=144]          │                │
       │    → W_s → ReLU              │                │
       │    → s_out [128]              │                │
       │       │                      │                │
       │       ├──────────────────────►                │
       │       │  (算缩放因子 gate)    │                │
       │       │                      │                │
       │       │                      ▼                │
       │       │          步骤 4：向量缩放              │
       │       │            V_降维 = W_2 × V_h         │
       │       │            V_out = sigmoid(gate) × V_降维 │
       │       │            V_out [8, 3]               │
       └───────┴──────────────────────┴────────────────┘
                               │
                               ▼
              输出：(s_out, V_out)，s_out [128]，V_out [8, 3]
```

**一个 GVP 层 = 可以保持 SE(3) 等变性的"广义线性层 + 激活函数"**。它是 GVP 网络的**最小单位**，下面要讲的"消息传递层"是由多个 GVP 层搭出来的。

## 六、GVP 消息传递层（GVPConvLayer）

有了基本单元（GVP 层），现在组装成消息传递层。**这和简化版 4.2.2a 里讲的 EGNN 消息传递层，在结构上完全一样**，只是每一步都把"普通线性层"换成"GVP 层"。

### 6.1 类比 EGNN 的五步流程

以残基 A 为例，假设 A 有 3 个邻居（B、C、D）。

**步骤 1：边 GVP — 为每条边计算一条消息**

对 A 的每个邻居（B、C、D），分别做一次下面的计算：

```
A 的特征 (s_A, V_A)，s_A [128]，V_A [16, 3]
邻居特征 (s_nbr, V_nbr)，s_nbr [128]，V_nbr [16, 3]
边特征  (s_edge, V_edge)，s_edge [32]，V_edge [1, 3]

拼接：
  拼接标量：[s_A (128) + s_nbr (128) + s_edge (32)] = [288]
  拼接向量：[V_A (16×3) + V_nbr (16×3) + V_edge (1×3)] = [33, 3]

┌──────────────┐       ┌─────────────┐       ┌──────────────┐
│   拼接输入    │       │  GVP 层 1    │       │  GVP 层 2    │       ┌─────────┐
│ (288, [33,3])│ ─────→│ 降到中间维度  │──────→│ 降到输出维度  │──────→│ 消息 m  │
│              │       │             │       │             │       │(s_m,V_m)│
└──────────────┘       └─────────────┘       └─────────────┘       └─────────┘
```

A 有 3 个邻居，所以得到 3 条消息 m_AB, m_AC, m_AD，每条都是 (s, V) 元组。

**步骤 2：汇总邻居消息**

```
sum_s = s_AB + s_AC + s_AD         ← 标量逐元素相加
sum_V = V_AB + V_AC + V_AD         ← 向量逐元素相加（每个向量的 3 个坐标分别相加）

得到 A 收到的消息总和：(sum_s, sum_V)
```

**注**：GVP 在标准实现里没有 EGNN 那种"注意力门控"（每条边加一个 0~1 权重），直接相加。但也可以加（EnzymeCAGE 的实现里没加）。

**步骤 3：节点 GVP — 更新残基 A 的特征**

```
把消息总和 (sum_s, sum_V) 和 A 的当前特征 (s_A, V_A) 拼接：
  拼接标量：[s_A (128) + sum_s (128)] = [256]
  拼接向量：[V_A (16×3) + sum_V (16×3)] = [32, 3]

送入一个 2 层的 GVP MLP：

┌──────────────┐       ┌─────────────┐       ┌─────────────┐       ┌─────────┐
│   拼接       │       │  GVP 层 1    │       │  GVP 层 2    │       │ 更新量   │
│ (256, [32,3])│ ─────→│             │──────→│             │──────→│(Δs, ΔV) │
└──────────────┘       └─────────────┘       └─────────────┘       └─────────┘

更新量 (Δs, ΔV)：
  Δs 形状 [128]
  ΔV 形状 [16, 3]
```

**步骤 4：残差连接**

```
A 的新特征 s：s_A (新) = s_A (旧) + Δs       [128]
A 的新特征 V：V_A (新) = V_A (旧) + ΔV       [16, 3]

不是替换，是相加——保留原始信息。
```

### 6.2 和 EGNN 消息传递的对比

```
┌────────────────────────────────┬────────────────────────────────┐
│  EGNN 消息传递层                │  GVP 消息传递层（GVPConvLayer）  │
├────────────────────────────────┼────────────────────────────────┤
│  输入：h_i [128]（纯标量）       │  输入：(s_i, V_i)（标量+向量）   │
│  边：edge [39]（纯标量）         │  边：(s_edge, V_edge)           │
│  MLP：普通 Linear + ReLU        │  MLP：GVP 层（保持等变）         │
│  更新：新 h = 旧 h + Δh         │  更新：新 (s,V) = 旧 + (Δs,ΔV) │
│  注意力门控：有（sigmoid）       │  注意力门控：没有（直接求和）    │
│  SE(3) 性质：不变               │  SE(3) 性质：等变              │
└────────────────────────────────┴────────────────────────────────┘
```

### 6.3 一层能"看到"多远

```
第 1 轮后：每个残基的特征融合了直接邻居（1 跳）
第 2 轮后：信息扩散到 2 跳邻居
第 3 轮后：信息扩散到 3 跳邻居
```

EXP005 和 EnzymeCAGE 都用 **3 层**，扩散半径 = 3 跳。由于 kNN 的 k=30，一个残基 3 层后理论上能看到周围最多 30³ = 27000 个邻居信息——但实际上口袋只有 30~50 个残基，所以 3 层足够让任何两个残基互相"看到"。

## 七、GVP 和 EGNN 的详细对比

综合前面所有内容，给出完整对照表：

### 7.1 输入层面

| 项目 | EGNN | GVP |
|---|---|---|
| 节点粒度 | 原子 | 残基 |
| 节点数量 | 100~200 | 30~50 |
| 节点特征 | 纯标量 [128] | 标量+向量 (s, V) |
| 节点特征来源 | 元素 + 氨基酸 + 骨架标志 one-hot | 二面角 sin/cos + 主链方向向量 |
| 边 | 化学键 + kNN 空间近邻 | kNN 空间近邻（只有残基间）|
| 边特征 | 键类型 6 + 距离 RBF 32 + 跨分子 1 = 39 维 | Cα-Cα 距离 RBF 32 + Cα-Cα 方向向量 1 个 |
| 3D 方向信息 | **无** | **有（向量部分）** |

### 7.2 消息传递层面

| 项目 | EGNN | GVP |
|---|---|---|
| 消息 | 标量 [128] | (标量 [128], 向量 [16, 3]) |
| 注意力门控 | 有（sigmoid） | 没有 |
| 节点 MLP | 普通 MLP | GVP MLP（保持等变）|
| 残差连接 | 有 | 有 |

### 7.3 数学性质层面

| 项目 | EGNN | GVP |
|---|---|---|
| 旋转整个分子 → 输出 | 不变 | 标量不变，向量跟着转 |
| 能表达方向 | 不能 | 能 |
| 能处理手性（左右手对映体）| 不能 | 能 |

### 7.4 实现复杂度层面

| 项目 | EGNN | GVP |
|---|---|---|
| 代码行数 | ~150 行 | ~400 行（GVP 基本单元 + GVPConvLayer）|
| 参数量（以 128 维、3 层为例）| ~150K | ~450K |
| 训练速度 | 快 | 慢（多了向量线性层） |

## 八、EXP005 里 GVP 的具体使用

### 8.1 数据流位置

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  EXP005 架构里 GVP 通路的位置（和原模型并行）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原 EGNN 通路（不变）：
    原子图 → EGNN 3 层 → x_str + str_mean → 后续

  🆕 GVP 通路（新增）：
    口袋残基图 → GVP encoder 3 层 → h_res → 两个出口

  GVP encoder 内部：
    第 0 层：初始 (s, V) 转换（标量/向量分别通过 1 个 GVP 层）
    第 1 层：GVPConvLayer（消息传递）
    第 2 层：GVPConvLayer（消息传递）
    第 3 层：GVPConvLayer（消息传递）
    输出层：最后一个 GVP 层把向量部分压到 0 维，输出纯标量 256 维

  最终输出 h_res 形状：[N_pocket, 256]
```

**注意**：EnzymeCAGE 的 GVP encoder 在输出时**故意把向量部分丢掉**，只保留标量部分。这是因为：后续的交叉注意力是标准的 Transformer 结构，无法处理向量。所以 GVP 的"方向感"在内部消息传递时发挥作用，输出时再转成标量。

### 8.2 两个出口的细节

前面 EXP005 讨论文档已经讲过，这里简要重复：

```
出口 1（深融合）：
  h_res 经过 LayerNorm + Linear(256→128) → h_res_proj
  按 pocket_residue_idx 注入回 x_pro 的对应残基位置
  门控 α 控制注入强度（初始 sigmoid(−2.2) ≈ 0.1）

出口 2（浅旁路）：
  对所有残基 h_res 求平均 → g_res [256]
  再经过 Linear(256→128) → g_res_proj [128]
  作为第 8 个向量拼接到预测头输入
```

### 8.3 零初始化

```
所有新引入路径的最后一层 Linear 权重 = 0：
  h_res_proj 的最后 Linear 权重 = 0 → 出口 1 初始无贡献
  预测头第一层新增的 128 列权重 = 0 → 出口 2 初始无贡献

效果：训练第 0 步，EXP005 输出严格等于 EXP001 基线（实测误差 4e-8）
```

## 九、为什么理论上应该有效，但实际失败了

### 9.1 理论预期

```
  如果方向信息有用：GVP 能带来 EGNN 带不来的信号 → AUC 应该上升
  如果方向信息没用：零初始化保证至少不会变差 → AUC 应该不变
```

### 9.2 实际结果

```
  EXP001 基线 Test AUC = 0.9320
  EXP005 双图 Test AUC = 0.9253   (-0.0067)
  EXP005 双图 Test AUPR = 0.6174  (-0.0575)
  参数量增加 +45%
```

AUC 反而**降了 0.007**。这怎么解释？

### 9.3 可能的原因

**原因一：信息冗余**

```
原 EGNN 虽然是 SE(3) 不变的，但由于 kNN 边覆盖了 48 个邻居 × 3 层 = 感知 144+ 原子，
模型可能已经通过 "A 原子到 B、C、D、E... 的全部距离"间接捕获了方向信息。

具体来说：
  要知道 A 相对 B 的方向，严格需要坐标
  但只要知道 A 到 B、C、D、E 所有邻居的距离，
  通过"三角定位"，方向信息就被隐式编码了

所以 GVP 带来的"显式方向"可能和 EGNN 已有的"隐式方向"高度重叠。
重叠的信号 + 增加 45% 参数 → 训练难度上升，但没有新信息 → 反而略降。
```

**原因二：粒度不匹配**

```
EGNN 是原子级，每个原子都能被模型"看到"
GVP 是残基级，一个残基代表 10+ 个原子

EGNN 告诉你："原子 O 距离原子 Fe 2.3Å"
GVP 告诉你："残基 Cys 靠近残基 Heme，且侧链朝向为 (0.3, 0.5, 0.8)"

问题是：P450 催化是原子级反应（C-H 键的羟基化）
       残基级的方向信息对"哪个原子被氧化"没有直接指导
       GVP 提供的信息在当前任务下没那么关键
```

**原因三：架构组合难度**

```
把 GVP 输出注入回 x_pro（出口 1），需要一个映射：
  GVP 节点（残基索引）→ x_pro 位置（UniProt 序列位置）

这个映射涉及序列比对、坐标对齐等多层处理。
任何一步的噪声都会让 h_res 注入"错位置"，引入噪声而不是信号。

实际 EXP005 的映射做到了 99.97% aa_match，但这 0.03% 的错位
加上零初始化带来的"冷启动"，也可能让新分支进入一个
"永远找不到有用梯度方向"的局部最小值。
```

### 9.4 失败不等于无价值

EXP005 的失败和之前的 EXP002a（加 Fe/HEM 特征）、EXP003（加二面角标量）的失败放在一起，形成了一个**连续证据链**：

```
  EXP002a 加标量 Fe 原子特征        → -0.005
  EXP003 加标量残基二面角特征        → vs bare -0.002
  EXP005 加残基级向量方向（GVP 通路） → -0.007

三次不同层次的"几何信号增补"尝试，全部无效或负收益。
这个规律叫"结构通道饱和" —— 在当前数据规模和架构组合下，
结构通道的表达能力已经被原子级 EGNN 吃满了，加什么都挤不出更多。
```

这是一个**扎实的实验结论**，比任何单次提升都更有学术价值——它告诉后续工作"不要再在结构通道做特征工程了"，应该转向数据规模或不同架构范式。

## 十、术语速查表

给不熟悉的读者：

| 术语 | 含义 |
|---|---|
| SE(3) | 特殊欧式群 3D，包含 3D 旋转 + 3D 平移 |
| SE(3) 不变 | 旋转平移输入，输出不变（EGNN 的性质） |
| SE(3) 等变 | 旋转输入，输出跟着旋转（GVP 的性质） |
| 标量 | 没有方向的数字（温度、长度等）|
| 向量 | 有方向的量，通常 3 个坐标 (x, y, z) 表示 |
| 向量范数 | 向量的长度（用 L2 范数算：sqrt(x²+y²+z²)）|
| 二面角 | 蛋白质骨架的旋转角度（φ、ψ、ω 是标准命名）|
| Cα、Cβ、N、C | 氨基酸骨架的主要原子 |
| 元组 (s, V) | GVP 的特征表示，s 是标量部分，V 是向量部分 |
| GVP 层 | 能处理 (s, V) 元组的广义线性层 + 激活 |
| GVPConvLayer | 用 GVP 层搭的消息传递层 |
| kNN 图 | 每个节点连接最近 k 个邻居的图（这里 k=30）|
| RBF（径向基函数）| 把一个标量距离展开成多个参考点上的高斯相似度 |
| 零初始化 | 让新加的模块最后一层权重 = 0，保证训练开始时等价基线 |
| 残差连接 | 输出 = 输入 + 增量，防止网络学坏 |
