### 2026-01-31~02-01 Path A Step 9-10 完成 ✅

**Step 9: 模型推理**
- 在B3数据集（539条，正样本271+负样本268）上运行预测
- 517条样本成功（结构特征可用的高质量样本）
- 使用best-checkpoint.ckpt（论文训练模型）

**Step 10: 结果分析**

核心指标：

| 指标 | 数值 | 说明 |
|------|------|------|
| **AUC-ROC** | 0.6636 | 66.36%概率正确排序正负样本 |
| AUC-PR | 0.6360 | 精确率-召回率曲线下面积 |
| Accuracy | 0.5164 | 默认阈值0.5 |
| Recall | 0.0996 | 极低（阈值不适配） |
| 最优阈值 | 0.0379 | Youden's J法 |

**根因分析（Claude + Codex + Gemini三方协作）**：

1. **任务不匹配（主因）**：
   - ESIBank训练：区分正确匹配 vs 随机配对（容易）
   - 我们测试：区分能催化 vs 只能结合（困难）
   - 抑制剂与底物可能化学结构相似

2. **酶完全未知**：
   - 148个P450 UniProt ID与ESIBank训练集0%重叠
   - 模型必须泛化到从未见过的酶

3. **域偏移**：
   - PDB配体集合（以抑制剂为主）vs BRENDA底物集合
   - 化学空间存在差异

**结论**：
- AUC-ROC 0.6636在预期范围内（论文Unknown enzyme+substrate场景为0.7198）
- 5.6%的差距主要来自负样本定义差异
- 不代表模型"失败"，而是任务定义不同

## 重要发现记录

### ESIBank vs 我们的流程对比

Codex深度分析揭示了根本性区别：

| 方面 | ESIBank | 我们 |
|------|---------|------|
| 数据流 | **关系优先→结构其次** | **结构优先→关系推断** |
| 起点 | BRENDA酶-底物关系（文献验证） | PDB实验结构 |
| 对接 | AutoDock一次一个底物 | 直接使用PDB配体 |
| 配体来源 | 已知是底物 | 可能是底物/产物/抑制剂 |

**ESIBank流程**：BRENDA获取"酶A催化底物X" → AlphaFold预测结构 → AutoDock对接 → 每个复合物只有一个目标配体

**我们的流程**：PDB实验结构 → 直接提取配体 → 可能有多个配体（晶体学实验的产物）

**结论**：我们遇到的"多配体"问题是使用实验结构的**必然结果**，需要通过配体角色标注解决（已在实验二v2完成）。

#### 6. 关键发现：Val Loss ↑ 而 AUC ↑ — Codex 深度分析（2026-03-19）

训练过程中 val_loss 从 ep2 开始上升（0.319→0.393@ep22），但 val AUC 同时上升（0.598→0.722@ep22）。验证集: 161 正 / 1322 负（10.8% 阳性率）。

**根因（Codex 确认非 Bug）**：
- **BCE = 逐点度量**：负样本 logit z=5 → 单样本损失 5.01（vs z=0 → 0.693），几十个 hard 样本主导均值
- **AUC = 成对排序**：ep2→ep22 额外 ~26,500 对正确排序（总 213K 对），对 outlier 鲁棒
- **三阶段**: warmup(ep0-8, LR 5e-6→3e-4, 震荡) → divergence(ep8-22, 排序↑但过度自信) → true overfitting(ep22+, AUC↓ loss↑)
- **LR 不匹配**: ReduceLROnPlateau 监控 aupr（非 auc/loss），warmup 后固定 3e-4 推动 logit 幅度增大

**Codex 建议**: (1) 同 AUC 选低 loss checkpoint, (2) warmup 后加 LR 衰减, (3) 不换 loss, (4) 下游需概率则 temperature scaling

验证：BCEWithLogitsLoss（src/Models/ss.py:159）与论文一致。test AUC=0.7244 > 论文 0.7198，确认模型正确工作。
