# Step 1: 论文模型在 ESIBank P450 测试折上推理

> **对应实验**: Path B Step 7 E7 内部基准
> **日期**: 2026-03
> **详细 log**: `PathB_.../sessions/07_Step7_Tier1_诊断实验/session_log.md`

## 做了什么

用论文训练好的模型（ESIBank 全部 323,783 对，random split checkpoint），在 **ESIBank 自身数据中 P450 家族的测试折** 上推理，作为内部基准。

## 为什么做

验证论文模型对 P450 家族的内在预测能力——如果模型见过这些 P450 酶（酶重叠率 100%），它能做到多好？

## 关键结果

| 指标 | 值 |
|------|-----|
| **AUC-ROC** | **0.638** |
| 酶来源 | ESIBank 训练集内部 P450（389 个酶） |
| 酶重叠率 | **100%**（模型训练时见过这些酶） |
| 底物重叠率 | 高（ESIBank 内部底物） |

## 对比背景

| 排名 | 家族 | AUC-ROC | 说明 |
|------|------|---------|------|
| 1 | 酯酶 | 0.934 | 最优 |
| 2 | 糖基转移酶 | 0.888 | |
| 3 | 硫解酶 | 0.880 | |
| 4 | 磷酸酶 | 0.877 | |
| 5 | 硝酸酶 | 0.859 | |
| 6 | DUF蛋白 | 0.796 | |
| **7** | **P450 (ESIBank内部)** | **0.638** | **最低** |
| 8 | P450 (我们的独立测试) | 0.517 | 酶重叠率 0% |

## 核心发现

**P450 是 ESIBank 中表现最差的家族**，即使在模型见过所有酶的情况下（100% 重叠）也只有 0.638。这说明 P450 家族对模型来说本质上就是困难的——不仅仅是数据不足的问题。
