# Step 4: P450 专属数据集从头训练 (EXP001)

> **对应实验**: C2 Phase 8
> **日期**: 2026-03-26
> **详细 log**: `C2_.../sessions/08_EXP001训练/session_log.md`

## 做了什么

用 C2 从 5 个数据库构建的 P450 专属数据集（4,751 正样本，47,510 可用对），在 random_split 上从头训练 EZSpecificity 模型。

## 为什么做

验证我们构建的 P450 数据集是否能提升模型在 P450 上的预测性能。

## 数据集规模

| 项目 | 值 |
|------|-----|
| 数据来源 | RCSB + ESIBank + P450Rdb + PlantP450DB + PCPD（5 个数据库） |
| 总交互数 | 52,254（4,751 正 + 47,503 负） |
| 酶数量 | 1,622 |
| 底物数量 | 2,125 |
| 可用对（特征完整） | 47,510 |
| 正负比 | 1:9.9 |

## 训练配置

| 项目 | 值 |
|------|-----|
| 服务器 | Cloud-2（4×RTX4090, 360GB RAM） |
| Split | random_split fold0 |
| Train/Val/Test | 23,710 / 11,878 / 11,823 |
| Batch size | 56/GPU × 4 = 224 |
| 预加载 | ~149GB RAM |
| max-epochs | 200（EarlyStopping patience=15） |

## 关键结果

| 指标 | 值 |
|------|-----|
| 总 epochs | 89（early stopped ep88, best=ep73） |
| **Val AUC** | **0.7544** |
| **Test AUC** | **0.7730** |
| Test AUPR | 0.3620 |
| 总耗时 | **49 分钟** |

## 三实验横向对比

| 实验 | 数据 | Test AUC | 提升 |
|------|------|----------|------|
| 论文模型推理 ESIBank P450 | ESIBank 内部 P450 | 0.638 | 基线 |
| AllSplit 从头训练 (ESIBank) | ESIBank all_split | 0.7244 | +0.086 |
| **P450 数据集从头训练** | **P450 专属** | **0.7730** | **+0.135** |

## 核心结论

**P450 专属数据集训练 Test AUC=0.7730**，比 ESIBank 内部 P450 基准 0.638 提升 **+0.135**。证明"更多、更高质量的 P450 专属数据"是提升性能的关键路径。
