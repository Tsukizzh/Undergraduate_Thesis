# 论文模型在 ESIBank P450 上推理结果

## 核心结果

**AUC-ROC = 0.638**

用论文的 random split checkpoint 在 ESIBank 自身数据中 P450 家族的测试折上推理。

## 关键数据

| 指标 | 值 |
|------|-----|
| AUC-ROC | **0.638** |
| 样本数 | 1,359（106 正 / 1,253 负） |
| P450 酶数 | 203 |
| 酶重叠率 | 100%（模型训练时见过） |
| 底物数 | 1,096 |

## 7 个家族对比

| 排名 | 家族 | AUC-ROC |
|------|------|---------|
| 1 | 酯酶 | 0.934 |
| 2 | 糖基转移酶 | 0.888 |
| 3 | 硫解酶 | 0.880 |
| 4 | 磷酸酶 | 0.877 |
| 5 | 硝酸酶 | 0.859 |
| 6 | DUF蛋白 | 0.796 |
| **7** | **P450** | **0.638** |

**结论：P450 是 ESIBank 中表现最差的家族。**
