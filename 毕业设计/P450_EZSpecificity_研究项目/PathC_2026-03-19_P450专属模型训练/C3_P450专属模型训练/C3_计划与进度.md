## 二、已完成的关键实验（按时间顺序）

### Step 1: 论文模型在 ESIBank P450 测试折上推理（Path B E7）

| 项目 | 值 |
|------|-----|
| 日期 | 2026-03 |
| 做法 | 用论文 random split checkpoint 在 **ESIBank 自身的 P450 测试折**上推理 |
| 数据 | ESIBank 内部 P450 子集（389 个酶，酶重叠率 100%） |
| **AUC-ROC** | **0.638** |
| 对比 | P450 是 ESIBank 7 个家族中表现**最差**的（酯酶 0.934, ..., P450 0.638） |
| 结论 | 即使模型见过所有 P450 酶，也只有 0.638——P450 本质上是困难家族 |
| Session | `sessions/01_论文模型推理ESIBank_P450/` |

### Step 2: ESIBank 数据 AllSplit 从头训练（Path B Step 9-10）

| 项目 | 值 |
|------|-----|
| 日期 | 2026-03-12 ~ 2026-03-16 |
| 做法 | 在 ESIBank 原始数据 all_split 上从头训练（Unknown Enzyme+Substrate） |
| 数据 | ESIBank all_split（~7,000 train, 8,841 test） |
| 本地 (fixed) | Val AUC=**0.7667** (ep14 best)，单卡 |
| Cloud-2 (legacy_bug) | Test AUC=**0.7244** (ep27)，2×4090 DDP |
| 论文报告 | Test AUC=0.7198 |
| 结论 | 我们 0.7244 > 论文 0.7198，复现成功。.pt 缓存解决 LMDB thrashing |
| Session | `sessions/02_AllSplit从头训练_ESIBank/` |
| Results | `results/02_AllSplit_ESIBank/` |

### Step 3: fixed 基线与 dropout 消融（C1）

| 项目 | 值 |
|------|-----|
| 日期 | 2026-03-19 ~ 2026-03-21 |
| 做法 | 在 ESIBank all_split 上测试边修复（fixed）和 dropout 调整 |
| fixed 基线 | Val=0.7145, **Test=0.7060**（边修复未提升 AUC） |
| dropout=0.1 | Val=0.7216, **Test=0.6936**（Val↑ 但 Test↓） |
| dropout=0.3 | Val=0.7397, **Test=0.6959**（Val↑ 但 Test↓） |
| 结论 | 边修复和 dropout 调整均未改善 Test AUC，不纳入后续组合 |
| Session | `sessions/03_fixed基线与dropout消融/` |
| Results | `results/03_fixed_dropout/` |

### Step 4: P450 数据集从头训练 EXP001（C2 Phase 8）

| 项目 | 值 |
|------|-----|
| 日期 | 2026-03-26 |
| 做法 | 用 C2 构建的 P450 专属数据集（5 个数据库合并），random_split 从头训练 |
| 数据 | 47,510 可用对（1,622 酶 × 2,125 底物），random_split |
| 服务器 | Cloud-2 (4×RTX4090, 360GB RAM) |
| 训练 | 89 epochs, early stopped ep88, best=ep73, 49 分钟 |
| **Val AUC** | **0.7544** |
| **Test AUC** | **0.7730** |
| vs ESIBank P450 | 0.638 → 0.7730 = **+0.135 提升** |
| 结论 | P450 专属数据集显著提升性能，数据集构建成功 |
| Session | `sessions/04_P450数据集训练_EXP001/` |
| Results | `results/04_EXP001/`（checkpoints 在服务器） |

### 实验横向对比

```
0.638 (论文模型在 ESIBank P450 测试折，酶重叠 100%)
  → +0.086 → 0.7244 (ESIBank AllSplit 从头训练，酶重叠 0%)
    → +0.049 → 0.7730 (P450 专属数据集从头训练)
```

## 三、进行中的工作

### Step 5: 底物分类与验证（2026-03-27 ~ 进行中）

**背景**: 导师要求实现"给定酶，预测它催化哪类底物（萜类？黄酮？生物碱？）"

**Step 5a: 自动分类** ✅
- NPClassifier API 对 2,125 个底物分类 → 15 个化学类别
- Codex 三轮审核映射表和合并规则

**Step 5b: 多工具验证** ✅
- SMARTS 结构规则验证（7 个类别，936 个确认）
- ClassyFire 规则分类器（328 个有结果）
- 11 个 Opus 文献验证 agent（~500 次 PubChem/ChEBI web 调用）

**Step 5c: 修正** 🔄 进行中
- 已发现 ~248 个明确错误
- 主要问题：苯丙素 pathway fallback（67个）、脂肪酸定义过宽（~70个）、合成物被标为天然产物（~30个）
- 与 Codex 讨论修正方案中

**Session**: `sessions/05_底物分类与验证/`
**Scripts**: `scripts/`
**Data**: `data/`
