# C3 创新性分析文档

> **创建日期**: 2026-03-29
> **状态**: 持续更新

本文档记录 C3 阶段发现的创新点和改进方向，每个创新点都经过文献调研和代码确认。

## 创新点 1: Fe/heme 原子词汇表扩展

### 问题发现

P450 酶的活性中心是**血红素辅因子（heme）**，其核心是一个 **Fe（铁）** 原子。Fe 原子直接参与底物的氧化催化反应。然而当前 EZSpecificity 模型**完全忽略了 heme/Fe**。

### 代码确认（2026-03-29）

**断点 1：蛋白质原子词汇表没有 Fe**

文件 `src/Datasets/Structure/transforms.py` 第 23 行：
```python
self.atomic_numbers = torch.LongTensor([1, 6, 7, 8, 16, 34])  # H, C, N, O, S, Se
```
Fe 的原子序数是 26，不在列表里。

**断点 2：PDB 解析器跳过 HETATM 记录**

文件 `src/Datasets/Structure/protein_ligand.py` 第 67 行：
```python
if line[0:6].strip() == 'ATOM':  # 只读 ATOM，跳过 HETATM
```
HEM（血红素）在 PDB 文件中以 HETATM 记录存储，所以被完全跳过。

**数据流程**：
```
对接 PDB（包含 HEM）
    ↓ 提取口袋（10Å 内）
口袋 PDB（HEM 被写入文件）
    ↓ PDBProtein 解析（只读 ATOM）
GNN 输入（HEM 被丢弃，Fe 不存在）
```

### 影响分析

- P450 的催化反应**完全依赖 Fe-oxo 物种**（Compound I），底物的反应位点距离 Fe 原子通常在 4-6Å
- 模型看到的口袋中没有 heme → 缺失了最关键的催化中心信息
- 论文其他模型（如 ESIBank 训练集覆盖 8,124 种酶）的 heme 信息同样缺失

### 修复方案

1. `transforms.py`：蛋白质原子词汇表加入 Fe（原子序数 26）
   ```python
   self.atomic_numbers = torch.LongTensor([1, 6, 7, 8, 16, 26, 34])  # H, C, N, O, S, Fe, Se
   ```
2. `protein_ligand.py`：让解析器也读取 HETATM 中的 HEM 残基
3. 重新生成结构特征 + 重新训练

### 创新性

- 对于 P450 家族来说，heme 是**所有 P450 共有的辅因子**，加入 Fe 特别有意义
- 目前 EZSpecificity 原始论文未提及此问题
- Path B 的 E8 实验发现结构通道对 P450 非常重要（关闭结构 → AUC 暴跌 0.275），加入 heme 可能进一步提升结构通道贡献

## 创新点 2: 两阶段底物类别预测系统

### 问题背景

导师提出的方向：给定一个 P450 酶的序列，预测它催化**哪类**底物（萜类？黄酮？生物碱？）

### 系统设计

**两阶段推理**：

```
阶段1（新增）：酶序列 → 底物类别偏好
    输入：仅 P450 蛋白质序列
    输出：8 个底物类别的概率分布
    用途：快速筛选——"这个酶大概催化什么类型的底物"

阶段2（已有 EXP001）：酶 + 具体底物 → 催化分数
    输入：酶序列 + 底物 SMILES + 对接结构
    输出：0~1 催化概率分数
    用途：精确验证——"这个酶和这个具体底物能不能反应"
```

**实际使用流程**：
```
科研人员发现一个新 P450 序列
    ↓
阶段1：输入序列 → "偏好催化萜类（75%）、甾体（15%）..."
    ↓
从萜类底物库中挑选候选底物
    ↓
阶段2：输入酶+候选底物对 → "化合物A：0.92，化合物B：0.35..."
    ↓
实验验证 top 候选
```

### 阶段1 模型架构

利用 EXP001 已训练好的蛋白质编码器（ESM → protein_mlp → 128维酶向量），冻结这部分参数，在上面加一个新的 MLP 分类头：

```
酶序列 → ESM-2 嵌入(1280维) → protein_mlp(已训练) → 酶向量(128维) → 新MLP(128→8) → 8类概率
         └──────── EXP001 冻结参数 ────────┘         └── 新训练 ──┘
```

### 训练数据

来源：C2 构建的 P450 数据集 + C3 Step 5 的底物分类

```
每个酶催化了哪些底物 → 这些底物属于哪些类别 → 酶的标签

例：
  CYP71A1 催化了 5 个萜类底物 + 2 个生物碱底物
  → CYP71A1 的标签 = [0.71 萜类, 0.29 生物碱]（软标签，按比例）
```

### 8 个底物类别

| 类别 | 中文 | 说明 |
|------|------|------|
| Steroid | 甾体 | 6-6-6-5 四环甾体骨架 |
| Terpenoid | 萜类 | 所有萜类（单萜/倍半萜/二萜/三萜/其他萜） |
| Alkaloid | 生物碱 | 含氮天然产物二次代谢物 |
| Amino_acid | 氨基酸 | 保留完整 AA 骨架的氨基酸衍生物 |
| Fatty_acid | 脂肪酸 | 脂肪酰基类（游离酸/CoA/酰胺/氧化产物） |
| Phenylpropanoid_broad | 苯丙素广义 | 苯丙素+黄酮+香豆素 |
| Polyketide_broad | 聚酮广义 | 聚酮+大环内酯 |
| Other | 其他 | 异源物/合成物/不匹配 |

### 文献调研（2026-03-29，49 次 web 搜索）

搜索了 17 篇相关论文，结论：**没有人做过"从 P450 序列预测底物化学类别"。**

#### 最接近的工作

| 论文 | 做了什么 | 和我们的区别 |
|------|---------|------------|
| **Jinich et al. (JCIM 2023)** "Predicting enzyme substrate chemical structure with protein language models" | 用 ESM 嵌入预测 SDR/SAM-MTase 的底物化学类别（4-5 个粗粒度二分类任务）| 不是 P450；只有 4-5 个粗二分类任务（酚类 yes/no、甾醇 yes/no）而非统一多分类 |
| **DeepP450 (JCIM 2024)** | P450 序列+化合物 → 底物/非底物二分类 | **方向相反**：它是"给定 CYP3A4，某化合物是否为其底物"；我们是"给定未知 P450，预测偏好哪类底物" |
| **CYPstrate (2021)** | 化合物描述符 → 是否为 9 个人 CYP 的底物 | 完全不用酶序列，纯配体侧分类 |
| **ESP (Nat Commun 2023)** | 酶序列+底物 → 二分类 | 是配对打分，不是类别预测 |
| **CLEAN (Science 2023)** | 蛋白质序列 → EC 编号 | 预测反应类型（EC），不是底物化学类别 |
| **EnZymClass (2021)** | 植物酰基-ACP 硫酯酶序列 → 短/中/长链脂肪酸偏好（3 类） | 只有 3 类（碳链长度），仅一个酶家族 |

#### P450 领域的明确空白

2024 年 Frontiers in Microbiology 的细菌 P450 综述明确指出："sequence alone does not consistently predict substrate specificity"（仅靠序列不能一致地预测底物特异性），**没有提出任何 ML 解决方案**。

#### 系统发育层面的已知关联

植物 P450 社区已知不同 CYP clan 与底物类别有关联（Feyereisen 2013, Phil Trans B）：
- Clan 71 → 特化代谢物（生物碱、萜类等）
- Clan 72 → 三萜/二萜
- Clan 85 → 甾醇/油菜素内酯

但这些是**进化分析观察**，没有人将其转化为**可预测的 ML 模型**。

### 创新性总结

1. **核心创新：方向反转** — 现有工作全部是"化合物→能被哪个 CYP 催化"（配体侧分类），我们是"酶序列→偏好哪类底物"（酶侧预测），**在 P450 领域无先例**
2. **最接近的工作 Jinich et al. (2023)**：在 SDR/SAM-MTase 上做了类似的事，但不是 P450，且只有 4-5 个粗粒度二分类任务
3. **两阶段系统**：先粗筛类别再精确打分，实用性远高于"和每个底物都配对试一遍"
4. **迁移学习**：利用 EXP001 已训练好的蛋白质编码器，不需要从头训练
5. **规模**：1,622 个 P450 × 8 类底物分类，覆盖 P450 超家族的广泛多样性
