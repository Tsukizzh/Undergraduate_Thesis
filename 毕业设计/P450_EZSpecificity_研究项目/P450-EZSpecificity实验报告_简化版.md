# P450-EZSpecificity 研究实验报告

> **项目**：基于 EZSpecificity 模型的 P450 酶家族特异性预测研究
> **时间跨度**：2025-12 ~ 2026-03
> **模型**：EZSpecificity（Nature 2025），SE(3)-等变 GNN + 交叉注意力
> **硬件**：RTX 4070 Super 12GB / i5-14600KF / 32GB RAM / Windows 11

---

## 摘要

本研究系统性评估并诊断了 EZSpecificity 在 P450 酶家族上的预测能力。

**核心发现**：

1. **Path A**：独立 P450 测试集 AUC-ROC = 0.6636（比论文最难场景低 5.6%），主因是负样本语义差异和 0% 酶重叠。

2. **Path B**：随机配对负样本后 AUC 暴跌至 **0.5170**（近随机）。13 个诊断实验定位根因：
   - 模型退化为**底物身份分类器**（R²(底物)=0.37，残差 AUC=0.509）
   - P450 是 7 个测试家族中**唯一崩溃**的（0.517 vs 次低 0.796）
   - 通道归因是**任务特异的**：E8v1 结构主导，E8v2 全不显著
   - ESIBank P450 难度匹配后与我们仅差 0.032

3. **Step 9**：发现论文**边特征对齐 Bug**，完成训练优化（1.71→4.3 it/s）。

## 第一章 研究背景

**EZSpecificity 模型架构**：
```
酶序列 + 底物 SMILES + 对接 PDB
  → ESM-2 (序列通道) + GROVER+Morgan (分子通道) + EGNN (结构通道)

**论文四折 CV**：Random=0.8878, UnkEnz=0.7741, UnkSub=0.8003, **UnkBoth=0.7198**。

**四路径规划**：

## 第二章 ESIBank 中 P450 的精确识别

**问题**：EC 号筛选得到 4,121 个"P450"，但抽样发现 ~90% 假阳性。例如 P07327 在 data.csv 中标记为 EC 1.14.14.126，但 UniProt 查证为 Alcohol dehydrogenase（EC 1.1.1.1）。根因：EC 号分类的是反应类型而非酶身份。

**方法**：编写脚本调用 UniProt REST API 批量查询 25,225 个酶（每批 150 个，SQLite 缓存+断点续传），提取 InterPro 域和 protein_families 信息。

| 验证层级 | 标准 |
|---------|------|
| 主标准 | InterPro 域含 IPR001128（P450 核心域）或 IPR036396（超家族） |
| 备用标准 | UniProt protein_families 含 "Cytochrome P450" |
| 排除条件 | 名称含 "reductase"（P450 Reductase 是电子传递伙伴） |

**结果**：410 个 P450 相关 - 21 个 Reductase = **389 个真正的 P450**。补充验证：随机抽样 100 个被排除酶 → 0 个含 P450 域；Pfam PF00067 交叉验证 99.7%。

## 第四章 Path A — 模型评估

**特征生成**（Step 5-8）：

| 步骤 | 特征 | 输出 | 成功率 |
|------|------|------|:------:|
| Step 5 | ESM-2 酶嵌入 | enzyme_features.lmdb (~700MB) | 100% |
| Step 6 | 反应图特征 | reaction_features.lmdb | 100% |
| Step 7 | Morgan + GROVER | morgan.npy + grover.lmdb | 100% |
| Step 8 | 结构特征（自编口袋提取+原子对齐） | structure_features.lmdb | **95.9%** (539→517) |

Step 8 的口袋提取和原子对齐由我们自行编写（论文训练用 AutoDock 产出已分离的复合物）。P450 特异处理：多实例配体选最近 HEM Fe 的。

**有效样本**：517 条（261 正 + 256 负），检查点=random_split fold-0。

| 指标 | 我们的 P450 | 论文 Unknown both |
|------|:----------:|:----------------:|
| **AUC-ROC** | **0.6636** | 0.7198 |
| AUC-PR | 0.6360 | — |

**得分分布**：正样本均分=-2.99，负样本均分=-5.05，间距=2.06（过小）。约 39% 正样本与 82% 负样本落入 -7~-3 重叠区。

**根因**（三因素）：
1. **0% 酶重叠**：148 个 P450 完全未见
2. **负样本定义不同**：抑制剂（难）vs 随机配对（易），贡献 ~5-6%
3. **结构信息差异**：Heme 排除 + 晶体 vs 对接 + 口袋截断

**结论**：差距在预期范围内，不代表模型失败。预期改用随机负样本 → AUC ≈ 0.72。

## 第五章 Path B Step 1-2 — 结构因子实验

**代码改造**：口袋半径从硬编码改为 CLI 参数 `--pocket_radius`；新增 `--include_heme` 开关（Heme 残基集：HEM/HEC/HEA/HEO/DHE/HEB）。Codex 审核发现 `protein_ligand.py` 的 `PDBProtein._parse()` 只解析 ATOM 记录，Heme 的 HETATM 行会被静默丢弃，需修复。

**2×2 因子设计**（516→提取→对齐→质量过滤→495 有效样本）：

|  | 10Å | 6Å |
|------|:---:|:---:|
| 无Heme | **0.7115** | 0.6678 |
| 有Heme | 0.4894 | 0.4257 |

**主效应**：Heme 效应 = **-0.2322**（加入→AUC 暴跌），口袋半径效应 = +0.0537（10Å 略优）。

**Heme 暴跌根因**（Codex 四轮确认）：
```
Heme 加入 → Fe(26) 不在蛋白质原子词汇表 [H,C,N,O,S,Se]
         → Fe 得到全零特征 → HEM 映射为 UNK (index=20)
         → GNN 消息传递扩散 OOD 噪音至整个口袋 → AUC < 0.5
```

**原子词汇表不对称**：蛋白质侧无 Fe，配体侧已包含 Fe——架构级缺陷。

**Gate A: PASS ✅** → 采用 10Å/noHeme (EXP01)。

## 第六章 Path B Step 3-4 — Vina 对接管线

**管线**：6 核心模块 + 5 入口脚本（~1,500 行代码）。

```
grid_locator   → 从PDB读取HEM/FE坐标, 生成22.5Å对接盒子
receptor_prep  → PDB清洗(去水/离子/保留HEM) → MGLTools → PDBQT
ligand_prep    → SMILES → RDKit 3D构象(ETKDGv3+MMFF94) → Meeko → PDBQT
vina_runner    → AutoDock Vina 1.2.7 (exhaustiveness=8, num_modes=9)
postprocess    → Meeko恢复键序 + FE距离QC + NeighborSearch 10Å口袋
negative_sampler → 固定底物, 随机选假酶, 正负比1:9.36
```

**资产准备**：受体 PDBQT 282/292=96.6%（10 个非天然辅因子失败），配体 PDBQT 434/436=99.5%。Pilot 48/50=96%。

**数字推导**：B6 516 条 → 受体可用 282 + 配体可用 250 → 正样本 270 可对接 → 负样本 270×9.36=2,527 → 总 manifest=2,797。

**全量对接**：首次 2,530/2,797=90.5%（4.9h, 12 workers）→ 三层重试（FE QC 阈值 2.0→1.5Å / timeout 300→600s / exhaustiveness 8→4）→ **2,766/2,797 = 98.9%**。
- 不可恢复 31 个：30 个 CoA 长链（23-26 旋转键），1 个原子重叠。
- 最终正负比 1:9.44。

## 第八章 Path B Step 6 — 消融实验与 Causal DAG

**Phase 1（正负比排查）**：仅改变负样本数量，固定身份（随机）和结构（Vina），每组 5 个随机种子取中位数。

| 实验 | 正负比 | AUC-ROC | 95% CI |
|------|:------:|:-------:|:------:|

| ABL-02 | 1:3 | 0.5132 | [0.4731, 0.5533] |

最大差异仅 0.004，置信区间高度重叠。**正负比不是主因。**

**Phase 2（分离结构来源 vs 负样本身份）**：构建桥梁实验 ABL-04（用 Vina 重新对接 EXP01 的抑制剂负样本，222/242=91.7% 成功）。

```
EXP01 ──(仅改结构)──→ ABL-04 ──(仅改负样本)──→ Step 5
0.7115               0.6885                0.5170
    ← 0.0230 (11.8%) →    ← 0.1715 (88.2%) →

## 第九章 Path B Step 7 — Tier 1 诊断（E1-E7）

### E1：标签语义探测
抑制剂得分最低（-5.25），否决"结合亲和力假说"。**EXP01 的 0.71 来自指纹分布差异（捷径学习）。**

### E2：ESM 嵌入相似度
P450 平均余弦相似度 0.935（7 家族中**最低**）。ESM 各向异性是全局特性，非 P450 特有。

### E3：逐底物 AUC
30% 底物 AUC>0.75，27% 底物 AUC<0.35。**失败高度不均匀——底物身份决定分数。**

### E4：分数分解（核心）

**方法**：Leave-One-Out (LOO) 分解，将模型分数拆解为底物偏置（该底物所有配对的均分）、酶偏置（该酶所有配对的均分）、残差（交互项）。

| 成分 | R² | AUC |
|------|:--:|:---:|
| 底物偏置 | **0.37** | 0.498 |
| 酶偏置 | **-0.06** | 0.530 |
| 两者相加 | 0.32 | 0.522 |
| **残差（交互项）** | — | **0.509** |

**模型完全退化为"底物身份分类器"**：底物身份解释 37% 分数变化，酶信息贡献为负（比均值猜还差），去掉两者后交互信号为零。

### E5：指纹分类器
**方法**：1024-bit Morgan 指纹 + LR/RF 分类器，StratifiedGroupKFold（按底物分组，杜绝泄漏）。LR AUC=0.503, RF AUC=0.504。Direction A 采样下（固定底物换酶），底物指纹对分类毫无帮助——底物信息不是通过化学指纹直接区分标签，而是通过模型的固定偏置间接决定分数。

### E6：多家族推理（7 家族）

| 家族 | 杂泛性 | AUC-ROC |
|------|:------:|:-------:|
| 酯酶 | 34.6 | **0.934** |
| 糖基转移酶 | 14.3 | 0.888 |
| 硫解酶 | 39.3 | 0.880 |
| 磷酸酶 | 32.9 | 0.877 |
| 腈水解酶 | 2.4 | 0.859 |
| Duf | 16.1 | 0.796 |
| **P450** | **1.2** | **0.517** |

**P450 唯一崩溃。** 腈水解酶杂泛性同级但 AUC=0.859，否定单因素假说。

### E7：ESIBank P450 内部基准

**设计**：使用 ESIBank random_split test fold 0（100% 酶泄漏 + AlphaFold 管线）。2,023→1,359 有效。

| 指标 | ESIBank P450 | 我们的 P450 |
|------|:----------:|:--------:|
| 有效配对数 | 1,359 | 2,766 |
| 酶泄漏率 | 100% | 0% |
| AUC-ROC | **0.638** | **0.517** |
| R²(底物) | 0.08 | 0.37 |
| **残差 AUC** | **0.612** | **0.509** |
| 方向 B 占比 | 61% | — |

**两种不同失败模式**：我们=底物身份分类器（零交互信号），ESIBank=存在配对特异信号（方向B=61%，模型利用酶信息）但 P450 仍是最低家族。

**E5'（ESIBank 指纹分类器）**：LR AUC=0.765, RF AUC=0.751。BRENDA 化学捷径：负底物来自全库（含糖类、氨基酸等 P450 不催化的分子），化学类型差异大。

## 第十章 Path B Step 8 — 通道消融（E8v1 + E8v2）

**关闭方法**：在 Linear 投影层**之后**将 128 维输出清零（输入端清零偏置仍存在，无法真正静默）。当酶序列或底物分子+结构通道被完全关闭时，交叉注意力输出同步清零。共 8 种条件（全开/关序列/关分子/关结构/只留序列/只留分子/只留结构/全关）。

### E8v1（EXP01，n=495，基线=0.712）

| 通道 | P450 ΔAUC | 磷酸酶 ΔAUC |
|------|:---------:|:----------:|
| 关结构 | **-0.275** ✓ | -0.110 ✓ |
| 关序列 | -0.154 ✓ | **-0.300** ✓ |
| 关分子 | -0.014 ✗ | -0.152 ✓ |

**通道重要性完全逆转**：P450=结构主导，磷酸酶=序列主导。全关=0.500（完美校验）。

**门控悖论**：关结构→AUC 暴跌至 0.437（正负差距反转），但"只留结构"仅 0.451。结构通道不是独立信息源，而是**门控/上下文调节者**。

### E8v2（Step 5，n=2766，基线=0.517）— 关键更新

| 通道 | P450 ΔAUC | 95% CI | 显著？ |
|------|:---------:|:------:|:-----:|
| 关结构 | -0.028 | [-0.070,+0.013] | **否** |
| 关序列 | +0.011 | [-0.032,+0.055] | **否** |
| 关分子 | +0.023 | [-0.026,+0.073] | **否** |

**所有 7 种消融条件的 95% CI 均包含 0，全部不显著。** 磷酸酶对照与 E8v1 完全一致（方法论验证通过）。

**Logit 行为诊断**：关结构→logit 标准差=15.12（爆炸，偏离训练分布）；只留结构→logit 标准差=0.45（被压缩）。

**核心洞察**：E8v1"结构通道最关键"是 EXP01 任务特异的，不可推广。崩溃态下通道归因失去意义——就像分析一台完全坏掉的收音机哪个零件最重要。**瓶颈在任务/数据设计。**

**E9 废弃**：分子通道仅贡献 1.4%，预期 +0.014 AUC，成本 8-12 小时，性价比极低。

## 第十二章 Path B Step 9 — AllSplit 训练

**训练配置**：all_split fold 0，数据集 = BRENDA + 6 小家族（~176,843 有效训练样本，~22,292 batches/epoch）。主要特征文件：enzyme_features.lmdb (50.2GB)、grover.lmdb (8.9GB)、morgan.npy (310MB)。

**关键代码修复**：CSV 列名大小写不匹配、LMDB map_size 硬编码 10GB→readonly 128GB、Windows spawn 无法 pickle LMDB handles（worker 延迟重连）、PL 1.9.0 precision 格式。

### 性能优化（方法 1）

| 参数 | 优化前 | 优化后 |
|------|:------:|:-----:|
| batch_size | 4 | **8** |
| accumulate_grad_batches | 8 | **4**（effective=32 不变） |
| num_workers | 2 | **6**（32GB RAM 极限） |
| prefetch_factor | 2 | **4** |

| 指标 | 优化前 | 优化后 |
|------|:------:|:-----:|
| 速度 | 1.71 it/s | **4.3 it/s** (+2.5×) |
| GPU 利用率(avg) | 8% | **29%** |
| VRAM | ~8GB | **11.4GB (93%)** |
| 50 epochs | ~15 天 | **~3 天** |

GPU 呈脉冲模式：646 次活跃段（avg 2.0s, ~60% util）+ 646 次空闲段（avg 2.1s），瓶颈仍在 CPU 数据加载（EdgeConnection k-NN 计算占 50-70%）。

方法 2（结构缓存）：预计算 k-NN 图到 LMDB（~90-140GB，构建 2-4h），运行时仅做噪声增强。预期 8-12 it/s，50 epochs ≈ 1-1.5 天。设计完成，待实施。

### 重大发现：边特征对齐 Bug

`transforms.py` 中 `complex_edge_attr`=[knn, real] 而 `complex_edge_index`=[real, knn]，**边属性与边索引顺序不匹配**。

- 真实化学键（单键/双键/芳香键）丢失键类型身份，被分配 knn 的 type-5 属性
- 真实键距离（~1-2Å）被替换为随机 knn 距离
- 典型样本中 Ek >> Er（k-NN k=48 生成的边远多于化学键），大多数边被错配
- 模型通过下调/抑制结构分支来"补偿" Bug，非图通道（ESM/GROVER/Morgan）提供主要信号
- **可能解释 E8v2 中结构通道不显著**——结构通道从一开始就在被错误数据训练
- Codex 4 轮验证确认。修复方案：Option A（复现 Bug，安全可比）/ Option B（修复，主训练方案）

## 第十三章 诊断全景总结

### 五大核心发现

| # | 发现 | 关键证据 |
|---|------|---------|
