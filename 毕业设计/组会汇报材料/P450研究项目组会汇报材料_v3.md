### 2.2 Step 2：2×2 因子实验（2026-02-20~28）

#### 实验设计

控制两个结构因子，在相同的 **495 个有效样本** 上测试四种组合：

```
                    口袋半径
                 10Å        6Å
          ┌─────────┬─────────┐
无 Heme   │  EXP01  │  EXP03  │
          │  0.7115 │  0.6678 │
          ├─────────┼─────────┤
有 Heme   │  EXP02  │  EXP04  │
          │  0.4894 │  0.4257 │
          └─────────┴─────────┘
```

数据漏斗：516 条 → 提取 → 对齐 → 质量过滤 → **495 条有效**。

#### 核心结果

| 实验 | Heme | 口袋半径 | AUC-ROC | AUC-PR |
|------|:----:|:-------:|:-------:|:------:|
| **EXP01** | 无 | 10Å | **0.7115** | **0.7356** |
| EXP03 | 无 | 6Å | 0.6678 | 0.6990 |
| EXP02 | 有 | 10Å | 0.4894 | 0.5492 |
| EXP04 | 有 | 6Å | 0.4257 | 0.4973 |

#### 主效应分析

| 因素 | 效应值 | 解释 |
|------|:------:|------|
| Heme 效应 | **-0.2322** | 加入 Heme → AUC 暴跌至 0.5 以下 |
| 口袋半径效应 | +0.0537 | 10Å 略优于 6Å，但影响较小 |

#### Heme 效应根因（Codex 四轮确认）

```
Heme 加入 → Fe(26) 不在蛋白质原子词汇表中
         → Fe 原子得到全零特征向量
         → HEM 残基映射为 UNK (index=20)
         → GNN 消息传递扩散 OOD 噪音至整个口袋
         → AUC < 0.5（预测方向完全颠倒）
```

**原子词汇表不对称**：蛋白质侧 = [H, C, N, O, S, Se]（无 Fe！），配体侧已包含 Fe。这是一个**架构级缺陷**。

#### 关键代码修复（共 7 个 bug）

最重要的修复：HETATM 解析（`line[0:6].strip() in ('ATOM', 'HETATM')`）。

#### 不扩展至 15/20Å 的决策依据

1. 口袋半径效应（+0.0537）远小于 Heme 效应（-0.2322）
2. 10Å 已被论文及同类方法广泛验证
3. GNN 计算量随原子数 O(N²) 增长
4. 当前瓶颈在负样本质量而非口袋半径

#### Gate A 决策

```
┌──────────────────────────────────────────┐
│  Gate A: PASS ✅                          │
│  采用配置: 10Å / noHeme (EXP01)           │
│  AUC-ROC = 0.7115                        │
│  进入 Step 3: Vina 对接管线搭建           │
└──────────────────────────────────────────┘
```

**注意**：EXP01（0.7115）与 Path A（0.6636）使用不同数据集（495 vs 517 样本），不可直接声称"+4.79%"是真实改进。四实验间的内部比较是严格公平的。

## 五、Step 6：消融实验与 Causal DAG

### 5.1 目标

拆解 EXP01（AUC=0.7115）到 Step 5（AUC=0.5170）之间 **0.1945 的 AUC gap**，定量归因于三个同时变化的变量。

### 5.2 三变量差异对照

| 变量 | EXP01（AUC=0.7115） | Step 5（AUC=0.5170） |
|------|------|------|
| 正负比 | 1:0.85 | 1:9.44 |
| 3D 结构来源 | PDB 实验晶体 | AutoDock Vina 计算对接 |
| 负样本身份 | 抑制剂 | 随机配对 |

### 5.3 Phase 1：正负比效应排查

**设计**：仅改变负样本数量，固定负样本身份（随机配对）和结构来源（Vina）。每组 5 个随机种子取中位数。

| 实验 | 正负比 | AUC-ROC | 95% CI |
|------|:------:|:-------:|:------:|
| ABL-01 | 1:1 | 0.5154 | [0.4655, 0.5644] |
| ABL-02 | 1:3 | 0.5132 | [0.4731, 0.5533] |
| ABL-03 | 1:9.44 | 0.5170 | [0.4804, 0.5521] |

**结论**：三组 AUC 最大差异仅 **0.0038**，置信区间高度重叠。**正负比不是主因。**

### 5.4 Phase 2：分离结构来源 vs 负样本身份

**设计**：构建桥梁实验 ABL-04（Vina 重新对接抑制剂，222/242=91.7% 成功）。

```
EXP01 ──(仅改结构来源)──→ ABL-04 ──(仅改负样本身份)──→ ABL-01
0.7115                     0.6885                      0.5154

      ←── 0.0230 ──→          ←─── 0.1715 ───→
        (11.8%)                   (88.2%)
```

| 实验 | 负样本身份 | 结构来源 | AUC-ROC |
|------|:---------:|:-------:|:-------:|
| EXP01 | 抑制剂 | PDB 晶体 | **0.7115** |
| ABL-04 | 抑制剂 | Vina 对接 | **0.6885** |
| ABL-01 | 随机配对 | Vina 对接 | **0.5154** |

### 5.5 定量 Gap 分解

| 因素 | 效应值 | 占总 gap 比例 |
|------|:------:|:-----------:|
| 3D 结构来源（Vina vs 晶体） | 0.0230 | **11.8%** |
| 负样本身份（随机 vs 抑制剂） | 0.1715 | **88.2%** |
| 正负比 | ≈0 | ≈0% |
| **总 gap** | **0.1945** | **100%** |

**验证**：匹配队列分析（470 对相同酶-配体对），结构来源效应 = 0.0324，95% CI = [0.0138, 0.0521]，与全集分析一致。

### 5.6 三通道信号分析

**EXP01 中模型为何有效（AUC=0.7115）**：

```
正样本底物: 脂肪酸、类固醇（P450 天然底物）
负样本底物: 酮康唑、氟康唑（药物抑制剂）
              ↓
化学结构完全不同 → Morgan+GROVER 指纹即可区分
              ↓
模型只需识别"指纹类别" → 捷径学习
```

**Step 5 中为何失效（AUC=0.5170）**：

```
分子通道 (信号=0): 同一底物同时在正/负样本中，指纹完全相同
序列通道 (信号≈0): 全部是 P450 单一家族，ESM 嵌入高度聚集
结构通道 (信号不足): Phase 2 已证明仅贡献 11.8%
              ↓
三通道同时沉默 → AUC ≈ 0.5
```

### 5.7 Causal DAG v2

经 Claude + Codex + Gemini 三方深度讨论（各 3 轮，共 9 轮），发现 Phase 1-2 表述中的三个问题：

1. **88.2% 是条件归因而非因果归因**：缺少"晶体+随机"单元格，交互效应不可测
2. **"三通道同时失效"是循环论证**：没有独立验证
3. **遗漏重要因素**：杂泛性、方向 A/B 负采样、checkpoint 场景不匹配等

## 六、Step 7：Tier 1 诊断实验（E1-E7）

### 6.1 总览

Step 7 是整个 Path B 的核心诊断阶段，通过 7 个实验（E1-E7）回答：**模型在 P450 上实际在做什么？为什么失效？**

| 实验 | 名称 | 核心问题 |
|:----:|------|---------|
| E1 | 标签语义探测 | EXP01 的 0.71 是"结合亲和力"还是"指纹分布差异"？ |
| E2 | ESM 嵌入相似度 | P450 的 ESM 嵌入是否特别聚集？ |
| E3 | 逐底物 AUC | 0.52 是均匀失败还是局部分化？ |
| **E4** | **分数分解** | **模型分数由酶、底物、还是交互驱动？** |
| E5 | 指纹分类器 | 底物化学特征能否直接预测标签？ |
| E6 | 多家族推理 | P450 崩溃是否是 P450 特有的？ |
| E7 | ESIBank 内部基准 | 同一模型在训练内 P450 上表现如何？ |

### 6.2 E1：标签语义探测

**问题**：EXP01 的 AUC=0.71 是因为模型学会了"结合亲和力"（底物结合=高分，抑制剂也结合→也应得高分），还是"化学指纹差异"（底物和抑制剂化学结构不同）？

**方法**：比较模型对抑制剂负样本 vs 随机负样本的 logit 分数；计算底物/抑制剂的 Tanimoto 化学相似度。

**结果**：

| 指标 | 抑制剂负样本 | 随机负样本 |
|------|:----------:|:--------:|
| 平均 logit | **-5.25** | -3.28 |
| 标准差 | 3.93 | 3.15 |

化学相似度：底物组内 Tanimoto = 0.131，抑制剂组内 = 0.151，**底物 vs 抑制剂组间 = 0.084**。KS 统计量 = 0.288（p < 1e-14）。

**结论**："结合亲和力假说"被否决。如果模型学的是"能结合=高分"，抑制剂（已知结合 P450）应得更高分，但实际得到最低分（-5.25）。**EXP01 的 0.71 来自指纹分布差异（捷径学习），不是真正的催化能力判断。**

### 6.3 E2：ESM 嵌入相似度分析

**问题**：P450 家族的 ESM-2 嵌入是否异常聚集，导致序列通道无法区分不同 P450？

**方法**：计算 7 个家族酶的 ESM-2 向量（1280 维）两两余弦相似度，PCA 分析有效维度。

**结果**：

| 家族 | 酶数 | 平均余弦相似度 | >0.90 比例 | PCA 90%维数 |
|------|:----:|:------------:|:---------:|:----------:|
| 糖基转移酶受体 | 55 | 0.981 | 100% | 10 |
| Duf | 161 | 0.981 | 100% | 17 |
| 硫解酶 | 73 | 0.980 | 99.8% | 16 |
| 腈水解酶 | 18 | 0.975 | 100% | 8 |
| 酯酶 | 146 | 0.950 | 98.2% | 38 |
| 磷酸酶 | 218 | 0.946 | 96.8% | 39 |
| **P450** | **292** | **0.935** | **82.4%** | **15** |

**结论**：P450 实际是 7 个家族中相似度**最低**的（0.935）。ESM-2 各向异性（1280 维中只有约 15 维有效）是全局特性，非 P450 特有。**ESM 压缩是加重因素，但不是 P450 崩溃的特异原因。**

### 6.4 E3：逐底物 AUC 分析

**问题**：AUC=0.52 是 213 个底物均匀失败，还是少数底物拉低？

**结果**（筛选条件：≥1 正 + ≥5 负，共 213 个底物）：

| 区间 | 底物数 | 比例 |
|------|:-----:|:----:|
| AUC > 0.75（表现好） | 65 | 30% |
| AUC > 0.65 | 88 | 41% |
| AUC < 0.35（完全反向） | 57 | 27% |
| 标准差 | — | 0.317 |

**结论**：失败高度不均匀。约 30% 底物碰巧有利（AUC>0.75），27% 完全反向。根源是模型给不同底物打了不同的固定基线分——**底物身份决定了分数，而非酶-底物交互。**

### 6.5 E4：分数分解（核心实验）⭐

**问题**：模型分数中，酶信息、底物信息、酶-底物交互信息各贡献多少？

**方法**：Leave-One-Out (LOO) 分解，将模型分数拆解为底物偏置、酶偏置、残差（交互项）。

**结果**：

| 成分 | R² | AUC |
|------|:--:|:---:|
| 仅用酶偏置 | **-0.06** | 0.530 |
| 仅用底物偏置 | **0.37** | 0.498 |
| 两者相加 | 0.32 | 0.522 |
| **残差（交互项）** | — | **0.509** |

```
┌──────────────────────────────────────────────────────┐
│  E4 核心结论                                          │
│                                                      │
│  底物身份解释 37% 的分数变化 (R²=0.37)                │
│  酶身份贡献为负 (R²=-0.06, 比用均值猜还差)            │
│  去掉两者后残差 AUC = 0.509 → 交互信号为零            │
│                                                      │
│  模型完全退化为 "底物身份分类器"                       │
│  忽略酶的存在，仅根据底物分配固定分数                   │
└──────────────────────────────────────────────────────┘
```

### 6.6 E5：指纹分类器基线

**问题**：底物化学特征（Morgan 指纹）能否直接预测标签？

**方法**：1024-bit Morgan 指纹 + LR/RF 分类器，StratifiedGroupKFold（按底物分组，杜绝泄漏）。

**结果**：

| 分类器 | CV 方式 | AUC-ROC |
|--------|--------|:-------:|
| LR | GroupKFold | **0.503** |
| RF | GroupKFold | **0.504** |
| 随机基线 | — | 0.500 |

**结论**：Direction A 采样下（固定底物、换酶），底物指纹对分类毫无帮助（AUC≈0.5）。这与 E4 的"底物偏置 AUC=0.498"高度一致——**底物信息不是通过化学指纹直接区分标签，而是通过模型的固定底物偏置间接决定分数。**

### 6.7 E6：多家族推理（磷酸酶压力测试 + 7 家族扩展）

**问题**：P450 的崩溃是 P450 特有的，还是所有单一家族推理都会崩溃？

**方法**：在 ESIBank 的 6 个小家族 test fold 上做真实推理，与 P450 对比。

#### 7 家族 AUC 排名

| 1 | 酯酶 | 34.6 | **0.934** | in-dist |
| 2 | 糖基转移酶受体 | 14.3 | 0.888 | in-dist |
| 3 | 硫解酶 | 39.3 | 0.880 | in-dist |
| 4 | 磷酸酶 | 32.9 | 0.877 | in-dist |

| **7** | **P450** | **1.2** | **0.517** | 0% 酶重叠 |

## 七、Step 8：通道消融实验（E8v1 + E8v2）

### 7.1 目标与方法

Step 7 的 E4 是统计层面的"后验分解"（类比：分析收音机的输出信号频谱）。Step 8 是物理层面的"直接干预"（类比：逐个拧掉收音机的旋钮）。两者互补。

#### 通道关闭技术

关闭 = 在 Linear 投影层**之后**（而非之前）将 128 维输出清零。

```
原因: 输出 = 权重 × 输入 + 偏置
     若在输入端清零，偏置仍存在，无法真正静默通道
     在输出端清零 → 完全静默
```

当酶序列或底物分子+结构通道被完全关闭时，交叉注意力输出也同步清零。

#### 8 种消融条件

| 条件 | 序列 | 分子 | 结构 |
|------|:---:|:---:|:---:|
| 全开（基线） | ✓ | ✓ | ✓ |
| 关序列 | ✗ | ✓ | ✓ |
| 关分子 | ✓ | ✗ | ✓ |
| 关结构 | ✓ | ✓ | ✗ |
| 只留序列 | ✓ | ✗ | ✗ |
| 只留分子 | ✗ | ✓ | ✗ |
| 只留结构 | ✗ | ✗ | ✓ |
| 全关 | ✗ | ✗ | ✗ |

## 八、假说验证

### 8.1 假说 1：负样本难度不匹配 — ✅ 已确认

**核心问题**：ESIBank P450 的 AUC=0.638 是否被简单负样本（EC 号距离远的酶）拉高？

**方法**：对 E7 的 1,359 条预测按 `difficulty` 分层计算 AUC。

| 难度 | 含义 | 负样本数 | AUC |
|:---:|------|:------:|:---:|
| 0 | 完全随机 | 306 | 0.731 |
| 1 | 同 EC 第 1 位 | 297 | 0.657 |
| 2 | 同 EC 前 2 位 | 297 | 0.629 |
| **3** | **同 EC 前 3 位** | **278** | **0.540** |

```
ESIBank P450 混合难度: AUC = 0.638
          ↓ 仅保留难度 ≥ 3
ESIBank P450 难度匹配: AUC = 0.549
我们的 P450 (≈全部难度 3): AUC = 0.517
                                ↓
                        剩余差距仅 0.032
                  可被酶泄漏(100%vs0%) + 结构来源(AlphaFold vs Vina) 解释
```

**结论**：ESIBank P450 的 0.638 中约 48% 是难度 0-1 的简单负样本拉高的。难度匹配后，两个数据集的差距从 0.121 缩小到 0.032。

### 8.2 假说 2：训练/测试场景不匹配 — ✅ 部分确认

| 维度 | 发现 |
|------|------|
| 公开检查点 | 仅有 `random_split` 场景（4 折 × 1 模型） |
| 我们的测试场景 | `unknown both`（最难场景） |
| Google Drive 数据 | 有 4 种分割数据，但无对应训练好的模型 |
| 从头训练成本 | 65GB 数据 + 单卡 2-4 周 → 不现实 |

**结论**：场景不匹配是叠加因素（解释 0.549→0.517 的 0.032 差距）。Path C 应从现有 random_split 检查点微调，而非从头训练。

### 8.3 两个假说的关系

```
0.638 (ESIBank P450 整体)
  ↓ 假说1: 排除简单负样本
0.549 (ESIBank P450 难度≥3)    ← ΔAUC = 0.089 (主因)
  ↓ 假说2: 场景不匹配 + 酶泄漏 + 结构来源
0.517 (我们的 P450)            ← ΔAUC = 0.032 (叠加因素)
```

## 十一、创新点与改进方向

### 11.1 已记录的创新方向（11 个）

基于诊断实验揭示的失败模式，提出以下改进方向：

| # | 创新点 | 解决的失败模式 | 难度 | 优先级 |
|---|--------|--------------|:----:|:-----:|
| 1 | 硬负样本重构（同 EC 前 3 位） | 底物身份捷径 + 难度不匹配 | 中 | **高** |
| 2 | 对比学习检索范式（CLIP-style, InfoNCE） | 二分类退化 + 坐标噪声 | 中 | **高** |
| 3 | 反平衡批次设计（Anti-Shortcut Batching） | R²(底物)=0.37 捷径 | 低-中 | **高** |
| 4 | Heme 中心口袋/通道编码器 | 结构信号稀释 | 中 | 中 |
| 5 | 反应中心感知标签（SoM 代谢位点） | 二分类粒度不足 | 高 | 低 |
| 6 | 蛋白质原子词汇表加入 Fe | Heme Fe OOD (AUC -31%) | **低** | 中 |
| 11 | 酶原子级结构特征聚合（scatter_mean） | 架构不对称 | 低-中 | 中 |

### 11.2 重点创新详解

#### 创新 1：硬负样本重构

**问题**：ESIBank 训练集用 EC 层级混合难度负样本（0-5），我们的 P450 测试全部 ≈ 难度 3。

**方案**：重构负样本，使训练时正确匹配难度分布。例如对 P450，负样本酶应来自同 EC 前 3 位（同亚家族）。

**参考**：EnzymeCAGE (Nat Catal 2026) 使用类似的硬负样本策略。

#### 创新 6：Fe 原子词汇表扩展

**问题**：蛋白质原子词汇表 `transforms.py:23` 中为 [H, C, N, O, S, Se]（6 种），无 Fe。而 Fe 是 P450 Heme 辅因子的核心金属原子。

**方案**：添加 Fe(26) 到蛋白质原子词汇表。代码改动量极小（一行），但需重新训练。

**影响**：Step 2 已证明 Fe OOD 导致 AUC 下降 0.2322（31%）。

#### 创新 11：酶结构特征聚合（最新发现，2026-03-10）

**问题**：底物侧同时拥有结构特征（EGNN 输出）和分子特征，而酶侧的 EGNN 原子级特征在 `structure.py` 中被 `ligand_mask` 直接丢弃，仅保留 ESM 序列嵌入。

```
架构不对称:
  底物侧: 分子指纹 + EGNN 原子特征 (双通道)
  酶  侧: ESM 序列嵌入 (仅单通道，EGNN 蛋白原子被丢弃)
```

**方案**：通过 `scatter_mean` 将蛋白原子特征按残基聚合后与 ESM 嵌入拼接。`protein_atom_to_aa_type` 映射已存在于 `transforms.py`，改动量小。

### 11.3 Codex 推荐的优先实验顺序

```
① 硬负样本替换（直接针对 R²=0.37 捷径）
② 对比学习 + 反平衡批次（改变训练范式）
③ Heme 口袋编码器（结构通道增强）
```
